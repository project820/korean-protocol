# Korean Protocol

Korean Protocol은 LLM이 한국어로 사실·조건·행동·불확실성을 분명하게 전달하도록 만드는 표현 규약입니다. 한국어의 어휘 의미와 결합, 문장 구조, 지시·보고·경고의 작성 기준을 함께 정의합니다.

프로젝트명은 **Korean Protocol**, 저장소명은 **`korean-protocol`**입니다. 현재 버전은 전체 규칙·통제 어휘·판정 사례·지속 설치 도구를 갖춘 **0.2 연구·개발 초안**입니다. [전체 목차](docs/spec/toc.md)와 [체계 구조](docs/spec/architecture.md)에서 설계를 확인할 수 있습니다.

## 왜 만드는가

LLM의 답변은 문법에 맞아도 읽기 어려울 수 있습니다. 같은 내용을 되풀이하거나, 간단한 행동을 추상적인 말로 풀어 쓰거나, 실제로 한 일과 앞으로 할 일을 구분하지 않으면 독자는 다시 해석하고 물어야 합니다.

Korean Protocol은 독자가 LLM의 표현을 다시 해석해야 하는 부담을 줄이기 위해 시작했습니다. ASD-STE100의 간결하고 단정한 기술 문체에서 출발해, 한국어의 어휘·조사·생략·어순·종결표현에 맞는 규칙을 연구합니다.

처음 적용할 대상은 한국어 LLM 답변과 업무·기술 문서입니다. 지시, 보고, 경고, 설명의 목적에 맞게 표현을 고릅니다.

## 어떤 표현을 지향하는가

**필요한 뜻을 남기고, 그 뜻을 전하는 말을 정돈합니다.**

| 원문 | 다듬은 문장 또는 판단 |
| --- | --- |
| 결과에 대한 확인을 수행했습니다. | 결과를 확인했습니다. |
| 이 기능을 사용하는 것이 가능합니다. | 이 기능을 사용할 수 있습니다. |
| 문제가 있을 수 있습니다. | 무엇에 관한 경고인지 문맥에서 알 수 있으면 그대로 씁니다. |
| 설정이 저장되었습니다. | 저장 상태를 알리는 문장이므로 그대로 씁니다. |
| 오류를 적절히 처리하세요. | 처리 기준이 공유되어 있는지 확인합니다. 기준이 없으면 행동을 임의로 덧붙이지 않습니다. |

위 예시는 초안의 방향을 설명하기 위해 구성했습니다. 대체문은 같은 사실과 문맥을 전제로 하며, 독자 실험으로 효과를 검증한 문장은 아닙니다.

## 규약의 구성

[한국어 세부 규칙](docs/spec/korean-rules.md)은 적용 조건·예외·양호 및 부적합 용례·유지해야 할 반례를 기록합니다. [통제 어휘](docs/spec/lexicon.md)는 단어의 허용·금지 여부보다 뜻·결합·분야·독자를 기준으로 사용을 판정합니다.

- 같은 개념에는 같은 이름을 쓰고, 독자에게 익숙하면서 뜻이 정확한 말을 고릅니다.
- 행동은 서술어로 직접 나타내고, 수식 관계와 조건·순서를 분명하게 연결합니다.
- 문맥에서 알 수 있는 주체는 생략하되, 주체가 바뀌거나 대상이 헷갈리면 밝힙니다.
- 가능성·허락·의무와 시작·진행·완료의 차이를 유지합니다.
- 지시에는 필요한 행동을, 보고에는 필요한 결과를 담습니다. 설명의 양은 독자의 목적에 맞춥니다.

문장을 짧게 만들기 위해 뜻을 바꾸지 않습니다. 한자어·전문어·피동문·가능성 표현도 실제 기능을 살펴서 판단합니다.

## ASD STE100과의 관계

ASD-STE100은 작성 규칙과 통제 어휘를 결합한 영어 기술문서 규격입니다. Korean Protocol은 그 원리를 참고해 한국어 표현 규칙을 독립적으로 작성합니다. ASD-STE100의 번역본이나 공식 한국어판은 아닙니다. [ASD 공식 설명](https://www.asd-ste100.org/about.html)

영어의 단어 수 제한을 한국어 어절 수로 옮기지 않습니다. 한국어 문장의 길이와 구조는 한국어 독자의 이해를 기준으로 검토합니다.

- [검증 상태](docs/status/requirements.md)는 완료한 작업과 미검증 항목을 구분합니다.

- [연구 근거와 검증 계획](docs/research-basis.md)은 각 규칙의 근거와 확인 범위, 다음 검증 방법을 설명합니다.
- [상세 연구 보고서](research/2026-10-12/research-report.html)는 한국어학·군사 의사소통·통제언어의 선별 문헌을 정리합니다. HTML 파일은 내려받아 브라우저에서 읽을 수 있습니다.

## 대응 목표와 검증 상태

ASD-STE100 Issue 9의 작성 기능 53개 중 49개가 기능 대응 검토를 통과했습니다(92.45%). 나머지 4개는 부분 대응입니다. 이 비율은 규약 전체의 완성도나 사전 충족률, LLM 정답률을 뜻하지 않습니다.

한국어 규칙 72개와 사전 뜻 항목 193개를 작성했습니다. 작성 사례는 규칙 257개·어휘 454개이며, 별도 기능 검토에는 독립 사례 83개와 공통 회귀 1개를 사용했습니다. 통합 자동 테스트 134개가 통과했습니다.

[별도로 고정한 어휘 문맥 40개](evaluation/lexicon-independent/report.md)에서는 사전의 표적 뜻과 직접 연결한 항목이 19개(47.5%)였습니다. 미연결 19개와 미확정 2개를 분모에 남겼습니다. 이는 해당 합성 표본의 사전 수록 범위이며, 규약의 문장 허용률이나 실제 업무 전체의 어휘 충족률은 아닙니다. 식별자·단위의 미등재와 일반 용어의 뜻 정의 공백을 구분합니다.

[사전 보완 후 개발 점검](evaluation/lexicon-refinement-20261012/report.md)에서는 같은 40개 문맥 중 33개가 연결됐습니다. 미연결 5개와 미확정 2개를 그대로 남겼으며, 이 수치는 공백을 보고 보완한 뒤 같은 입력으로 확인한 결과입니다. 새로운 독립 평가 점수로 사용하지 않습니다.

[한국어 독립 사례 보완](evaluation/korean-independent/report.md)에서는 31개 중 30개가 교차 검토를 통과했고, 해석이 갈린 1개는 근거에서 제외했습니다. 8개 범주의 정상·오용·원문 유지 사례를 연결했습니다. 그 후 진행·결과 상태와 사동·피동의 역할 보존을 규칙 두 개에 보완했습니다. 최소 사례의 충족을 전체 한국어 구문의 검증으로 확대하지 않습니다. 이 사례 검토는 실제 LLM 실행 시험과 구분합니다.

[실제 모델 평가](evaluation/llm/candidate-validation-report.md)의 새 12개 사례에서 원래 평정의 의미 보존 만점은 미적용 12개·적용 11개였습니다. 다만 적용 결과 1개의 제한 명령형을 감점한 근거에 [교차 검토 이견](evaluation/llm/permission-adjudication.md)이 있어 확정된 의미 오류나 성능 저하로 단정하지 않습니다. 알려진 생성 12개·편집 26개 회귀의 통과를 새 독립 검증의 성공으로 합산하지 않습니다.

[정제 프로필의 후속 실행](evaluation/llm/rule-refinement-20261012/report-ko.md)은 Sol 서비스 제한 뒤 네 조건을 Opus/high로 전환했습니다. 편집 26개와 생성 12개는 의미를 보존했고 생성 2개에는 간결성 보완점이 남았습니다. 보완 6개는 미적용·적용 모두 통과했습니다. 재사용 입력과 조건을 아는 검토자의 평정이므로 독립 효능이나 모델 간 성능 차이를 입증하지 않습니다. 이 실행에서 모델은 사전 전체를 읽지 않았습니다.

한 번 설치한 규약은 로컬에 보존하고, 네트워크나 업데이트 서버가 없어도 기존 내용을 사용할 수 있게 설계합니다. 자동 갱신은 검증된 콘텐츠만 교체하며, 실패하면 기존 버전을 유지합니다. 호스트별 지침 저장 방식과 제한이 달라 지원 범위는 [호스트 지원표](docs/distribution/host-support.md)에 따릅니다.

이전 프로필을 사용한 임시 사용자·프로젝트 환경에서 실제 Codex 지침 로딩과 오프라인 실행을 확인했습니다. [과거 검사 재현 안내](docs/status/historical-verification.md)는 당시 원본과 현재 원본을 구분합니다. [임시 HTTPS 시험](docs/distribution/https-transport-verification.md)에서는 서명 확인·호스트 시작 자동 갱신·오프라인 유지를 확인했습니다. 실제 공개 릴리스 운영과 자동 갱신 스케줄 등록은 아직 수행하지 않았습니다.

현재 내용은 연구·개발 초안입니다. 규칙과 사전의 구조 검사는 독자가 더 잘 이해한다는 증거가 아니며, 실제 모델 평가도 시험한 모델·입력 범위 안에서만 해석합니다. 한국어학·군사 전문가의 실제 자문과 독자 비교시험은 수행하지 않았습니다.

규칙을 제안할 때에는 문맥, 원문, 대체문, 유지할 뜻, 적용되지 않는 반례를 함께 제시합니다. 이미 명확해서 고칠 필요가 없는 문장도 사례로 남깁니다.

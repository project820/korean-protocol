# 일반 채팅에서 시작한다

ChatGPT에서 계속 사용할 때는 프로젝트 하나에 규약 파일과 지침을 저장하는 방식을 권한다. 공식 문서에 따르면 프로젝트의 파일과 지침을 그 안의 채팅에서 함께 사용할 수 있다. 프로젝트 밖의 채팅이나 다른 LLM 앱에 자동 적용되는 방식은 아니다. [ChatGPT 프로젝트 안내](https://learn.chatgpt.com/docs/projects)

## 처음 한 번 설정한다

1. 배포 ZIP을 풀고 `KOREAN-PROTOCOL.md`를 찾는다. 이 파일에는 V7 r2를 채택한 전체 규약 본문과 두 사전의 원본 데이터가 들어 있다.
2. ChatGPT 프로젝트를 만들고 Sources에 `KOREAN-PROTOCOL.md`를 올린다.
3. 프로젝트 지침에 아래 내용을 넣는다.
4. 그 프로젝트 안에서 새 채팅을 시작한다.

```text
한국어 응답에는 첨부한 KOREAN-PROTOCOL.md의 규칙과 사전을 적용한다. 이 지침은 표현을 다듬는 기준이며 사실·수량·행동 주체·조건·허락·의무·불확실성을 바꾸는 근거가 아니다. 공유 문맥에서 이미 명확한 표현은 유지하고, 필요한 결론과 행동을 직접 쓴다. 여러 대상·선택지·조건·수량·기한은 역할과 적용 범위가 보이게 나눈다. 원문보다 짧게 만들기 위해 필요한 뜻이나 구분을 없애지 않는다. 원문에 없는 사실·행동·수치를 덧붙이지 않는다. 파일을 읽지 못하면 전체 규약을 적용했다고 주장하지 않는다. 기존 지침과 현재 사용자 요청을 함께 따른다.
```

위 문구는 전체 규칙을 대신하는 요약본이 아니라 첨부 파일을 사용하도록 하는 시작 지침이다. 파일을 첨부한 것만으로 매 응답에서 사전 전체를 읽거나 모든 규칙을 지킨다고 보장하지 않는다. 사용 중 오류가 있으면 실제 문맥·원문·응답을 함께 남겨 검토한다.

짧게 시험하려면 일반 채팅에 같은 파일을 첨부하고 위 문구를 보낸다. 이 방식은 해당 채팅의 시험이며 다른 채팅에 설치됐다는 뜻이 아니다. Claude·Gemini 등 다른 앱에서도 파일 첨부와 저장 지침 기능을 확인한 뒤 같은 자료를 사용할 수 있지만, 현재 패키지는 그 앱의 설정을 자동 변경하지 않는다.

## 적용 결과를 확인한다

다음 요청은 시험용 예시다. 첫 문장을 불필요하게 늘리거나 두 번째 문장의 기준을 지어내면 그대로 채택하지 않는다.

```text
화면에 표시된 결제 기능을 설명하는 문맥이다. 다음 문장을 필요한 경우에만 다듬고 이유를 짧게 써라.
“문제가 있을 수 있습니다.”
```

```text
처리 절차나 오류 종류는 제공되지 않았다. 다음 지시를 검토하되 실제 절차를 지어내지 마라.
“오류를 적절히 처리하세요.”
```

이 예시는 설치 확인을 돕는 수동 점검이며 효능 평가 통과를 뜻하지 않는다. [규칙과 용례](docs/spec/korean-rules.md)에서 적용 조건과 예외를 함께 읽을 수 있다.

## 기존 파일로 계속 사용한다

저장한 파일은 매번 새로 내려받을 필요가 없다. 새 버전으로 바꾸고 싶을 때만 프로젝트의 기존 파일을 교체한다. 이 패키지는 ChatGPT 프로젝트에 올린 복사본을 자동 갱신하지 않으며, 로컬 코딩 도구의 자동 갱신과 구분한다.

응답 스타일만 모든 채팅에 짧게 지정하려면 ChatGPT 사용자 지침을 이용할 수 있지만, 그 설정에 시작 문구만 넣는 것으로 전체 규약과 사전이 설치되지는 않는다. [ChatGPT 사용자 지침 안내](https://learn.chatgpt.com/docs/personalize)

# ChatGPT에 Korean Protocol 0.7.0을 적용한다

[채팅용 KOREAN-PROTOCOL.md](https://github.com/project820/korean-protocol/releases/download/v0.7.0/KOREAN-PROTOCOL.md)를 프로젝트에 첨부하고 짧은 시작 지침을 저장한다. 이 파일은 V7 r2 규약 본문과 두 사전 데이터를 포함하며 코딩 에이전트 설치나 Python 실행은 필요하지 않다.

## 파일과 적용 범위를 확인한다

공개 [v0.7.0 릴리스](https://github.com/project820/korean-protocol/releases/tag/v0.7.0)의 파일은 원본 `7e01d53`에서 만든 고정 산출물이다. 규약 원본 버전은 0.7.0-draft다. 이후 main의 문서 수정이 첨부 파일에도 들어 있다고 설명하지 않는다.

[SHA256SUMS](https://github.com/project820/korean-protocol/releases/download/v0.7.0/SHA256SUMS)는 파일 손상을 확인하며 서명이나 발행자 인증을 대신하지 않는다. ZIP을 받았다면 그 안의 같은 이름 파일도 사용할 수 있다.

## 처음 한 번 설정한다

1. ChatGPT 프로젝트를 만들고 파일을 추가할 수 있는 영역에 `KOREAN-PROTOCOL.md`를 올린다.
2. 프로젝트 지침에 아래 문구를 저장한다.
3. 그 프로젝트 안에서 새 채팅을 시작한다.

```text
한국어 응답에는 첨부한 KOREAN-PROTOCOL.md의 규칙과 사전을 적용한다. 이 지침은 표현을 다듬는 기준이며 사실·수량·행동 주체·조건·허락·의무·불확실성을 바꾸는 근거가 아니다. 공유 문맥에서 이미 명확한 표현은 유지하고 필요한 결론과 행동을 직접 쓴다. 여러 대상·선택지·조건·수량·기한은 역할과 적용 범위가 보이게 나눈다. 원문보다 짧게 만들기 위해 필요한 뜻이나 구분을 없애지 않는다. 원문에 없는 사실·행동·수치를 덧붙이지 않는다. 파일을 읽지 못하면 전체 규약을 적용했다고 주장하지 않는다. 기존 상위 지침과 현재 사용자 요청을 함께 따른다.
```

프로젝트 파일·지침은 해당 프로젝트의 채팅에서 사용한다. 프로젝트 밖의 채팅이나 다른 앱에 자동 설치되지 않는다. 실제 설정 범위는 [ChatGPT 프로젝트 안내](https://learn.chatgpt.com/docs/projects)를 따른다. 계정의 실제 첨부·저장 UI나 모든 응답의 규칙 준수를 이 안내에서 검증했다고 주장하지 않는다.

짧게 시험하려면 일반 채팅 하나에 같은 파일과 문구를 보낸다. 사용자 지침에 시작 문구만 넣는 것은 전체 규약·사전 첨부와 다르다. [ChatGPT 사용자 지침 안내](https://learn.chatgpt.com/docs/personalize)에서 설정의 적용 범위를 확인한다.

## 응답과 세션 설정을 확인한다

다음은 수동 점검용 요청이며 효능 평가가 아니다.

```text
화면에 표시된 결제 기능을 설명하는 문맥이다. 다음 문장을 필요한 경우에만 다듬고 이유를 짧게 써라.
“문제가 있을 수 있습니다.”
```

```text
처리 절차나 오류 종류는 제공되지 않았다. 다음 지시를 검토하되 실제 절차를 지어내지 마라.
“오류를 적절히 처리하세요.”
```

이미 명확한 경고를 늘리거나 제공되지 않은 절차를 만들면 채택하지 않는다. [규칙과 용례](../docs/spec/korean-rules.md)의 조건·예외와 함께 대조한다.

현재 채팅에서 규약 적용이나 높임말의 전환을 요청할 수 있다. 파일 첨부에는 로컬 `configure` 명령이나 강제 출력 필터가 없으므로 모델의 지침 해석과 구분한다. 이미 읽은 지침을 대화에서 지우려면 첨부·지침을 바꾼 뒤 새 채팅으로 확인한다.

## 같은 파일로 계속 사용한다

첨부한 복사본은 자동 갱신되지 않는다. 새 버전을 선택할 때만 기존 파일을 교체하고 시작 지침을 확인한다. 같은 v0.7.0 파일을 다시 받는 것은 이후 main 문서로 갱신하는 방법이 아니다.

Claude·Gemini 등 다른 앱에서도 파일 첨부와 저장 지침의 실제 지원 범위를 확인한 뒤 사용할 수 있다. 현재 패키지는 그 앱의 계정 설정을 자동 변경하지 않는다.

# Korean Protocol 0.7.0의 사용 경로를 고른다

Korean Protocol은 한국어 답변을 쓰는 규약이다. 현재 코딩 에이전트 배포는 호스트의 사용자 지침에 설치하며 호출형 스킬·별도 모델·출력 후 필터가 아니다. Codex·Claude Code는 설치를, ChatGPT는 파일 첨부와 지침을 사용한다.

## 설치했다면 새 대화에서 평소처럼 요청한다

설치한 Codex 또는 Claude Code에서 새 대화를 시작하고 평소 작업을 요청한다. 매번 규약 이름을 부를 필요는 없다. 규약 ON은 설치한 호스트와 홈 환경에 적용하며 다른 앱이나 별도 홈 환경에 자동 전달되지 않는다. 신규 설치는 규약 ON·높임말 OFF이며 기존 설치의 선택은 유지한다.

설치 대상 에이전트에 다음 중 원하는 요청 하나를 복사한다. 문구는 내장 슬래시 명령이 아니라 에이전트가 상태 조회나 설정 변경을 수행하도록 하는 작업 요청이다.

| 목적 | 복사해서 보낼 요청 |
| --- | --- |
| 상태만 확인한다. | Korean Protocol의 설치 상태를 확인해 줘. 설정은 바꾸지 마. 설치 버전·적용 대상·규약과 높임말의 ON/OFF·파일 검증 결과를 알려줘. 현재 대화의 지침 로딩은 확인 가능한 근거만 보고해줘. |
| 규약을 영구 OFF로 바꾼다. | 이 환경에 설치된 Korean Protocol의 영구 설정만 OFF로 바꾸고 상태를 확인해 줘. 높임말과 자동 갱신 설정은 유지해 줘. |
| 규약을 영구 ON으로 바꾼다. | 이 환경에 설치된 Korean Protocol의 영구 설정만 ON으로 바꾸고 상태를 확인해 줘. 높임말과 자동 갱신 설정은 유지해 줘. |
| 높임말만 영구 ON으로 바꾼다. | 이 환경에 설치된 Korean Protocol의 높임말 영구 설정만 ON으로 바꾸고 상태를 확인해 줘. 규약과 자동 갱신 설정은 유지해 줘. |
| 높임말만 영구 OFF로 바꾼다. | 이 환경에 설치된 Korean Protocol의 높임말 영구 설정만 OFF로 바꾸고 상태를 확인해 줘. 규약과 자동 갱신 설정은 유지해 줘. |

영구 설정을 바꾼 뒤에는 새 대화를 시작한다. “이번 답변만 높임말로 써 줘” 같은 출력 요청은 영구 설정을 바꾸지 않는다. 규약 OFF와 자동 갱신 OFF는 다르다. 관리 명령과 상태 해석은 [적용 설정](application-controls.md)을 따른다.

파일 상태와 실제 응답은 별도로 점검한다. `enabled=true`와 콘텐츠 검증 성공은 모델 로딩이나 모든 규칙 준수의 증거가 아니다. 새 대화의 로딩 정보나 읽기 기록을 확인할 수 있는 범위만 보고하고, 다음 짧은 출력에서 대상·조건·수량·기한을 보존하는지 확인한다.

```text
다음 문장을 뜻과 조건을 유지하며 다듬어 줘.
“승인된 주문만 10월 20일 오후 3시까지 출고한다. 미승인 주문은 출고하지 않는다.”
```

한 번의 샘플은 전체 준수나 언어 효과를 증명하지 않는다. V7 r2는 원문보다 짧게 만들 것을 요구하지 않는다.

## 아직 설치하지 않았다면 사용 경로를 고른다

| 목적 | 시작 경로 | 유지 방식 |
| --- | --- | --- |
| Codex·Claude Code에 서명 설치한다. | 에이전트에 [INSTALL.md](../../INSTALL.md)를 전달한다. | 예약 갱신·시작 wrapper·자동 조회 OFF 중 선택한다. |
| 기존 설치를 0.7.0으로 갱신한다. | 같은 홈·상태 경로에서 [관리 도구를 재설치](../../INSTALL.md#기존-설치의-관리-도구를-먼저-갱신한다)한다. | 규약·높임말은 유지한다. 자동 갱신 옵션은 다시 명시한다. |
| 인터넷 없이 로컬 설치한다. | [ZIP](https://github.com/project820/korean-protocol/releases/download/v0.7.0/korean-protocol-0.7.0-draft.zip)을 풀고 `python3 start.py` 또는 [비대화형 안내](../../distribution/START-HERE.md)를 사용한다. | 미서명 `local-snapshot`으로 설치하며 자동 갱신은 끈다. |
| ChatGPT에서 사용한다. | [KOREAN-PROTOCOL.md](https://github.com/project820/korean-protocol/releases/download/v0.7.0/KOREAN-PROTOCOL.md)를 받고 [채팅 안내](../../distribution/CHAT-START.md)를 따른다. | 프로젝트에 저장한 복사본은 직접 교체한다. |
| 다른 앱에서 사용한다. | 첨부·저장 지침의 실제 지원 범위를 확인한다. | 현재 자동 설치 지원으로 표시하지 않는다. |

## 공개 버전과 원본을 구분한다

서명 콘텐츠는 0.7.0·순번 3이며 관리 엔진 0.2.0 이상을 요구한다. 데이터 schema는 1.0이다. 엔진 0.1.0은 새 콘텐츠를 거부하고 기존 규약을 보존하며 자동 갱신으로 관리 코드를 바꾸지 않는다.

[v0.7.0 릴리스](https://github.com/project820/korean-protocol/releases/tag/v0.7.0)의 ZIP·단독 파일·[체크섬](https://github.com/project820/korean-protocol/releases/download/v0.7.0/SHA256SUMS)은 `7e01d53`의 고정 산출물이다. 최신 main의 안내와 혼동하지 않는다. 미서명 파일의 체크섬과 HTTPS 콘텐츠의 게시자 서명은 서로 다른 검사다.

## 적용과 갱신을 확인한다

설치 상태의 버전·신뢰·대상·규약·높임말·자동 갱신 연결을 확인한다. [규약·높임말 설정](application-controls.md)은 콘텐츠와 독립적으로 저장한다. 서명 재설치에서 `--autoupdate`를 생략하면 OFF로 설정하므로 기존 예약 연결을 무조건 보존한다고 보고하지 않는다.

현재 세션에는 검증된 설치 캐시를 참조하며 호스트의 새 세션 로딩과 모델 준수를 구분한다. ChatGPT 첨부 방식에는 이 Python 관리 명령을 사용하지 않는다. 지원 환경은 [호스트 지원표](host-support.md), 공개 증거는 [0.7.0 발행 기록](public-0.7.0-verification.md), 언어 효과의 한계는 [현재 검증 상태](../status/requirements.md)를 따른다.

# Korean Protocol을 처음 사용한다

원문·KP·STE 정식 비교는 **미완료**다.

**Korean Protocol v0.11.1은 필요할 때 호출하는 한국어 작성 스킬이다.**
원문의 의미와 조건을 유지하며 읽는 형태를 정리한다.
자동 호출은 꺼져 있다.

## 준비: 한 번 설치한다

Codex 또는 Claude Code에 아래 요청을 보낸다.
두 호스트에 설치하려면 둘 다 지정한다.

```text
https://github.com/project820/korean-protocol 의 INSTALL.md를 읽고,
Korean Protocol v0.11.1 스킬을 지금 호스트의 사용자 범위에 설치해줘.
자동 호출은 끄고 다른 프로젝트에서도 호출할 수 있게 해줘.
기존 0.7 상시 설치가 있으면 규약만 OFF로 전환하고 다른 설정은 보존해줘.
설치·스킬 발견·실제 호출 결과를 확인해줘.
```

[설치 안내](../../INSTALL.md)에서 호스트별 위치와 복사 파일을 확인한다.
[수동 설치 명령](on-demand-skill.md#검증한-파일을-복사한다)은 태그와 해시를 검증한다.
설치본은 태그 `v0.11.1`에 고정하며 수동으로 갱신한다.
`SKILL.md`의 SHA-256은 `19ae7744da1d469225552b49e4108e52664f4f931c278d9f667c5ae7a4443604`이다.

## 절차: 새 대화에서 호출한다

1. **호스트에 맞는 호출문을 입력한다.**
   아래 요청 뒤에 원문을 붙이거나 파일을 지정한다.

   | 호스트 | 호출문 |
   | --- | --- |
   | Codex | `$korean-protocol 이 보고서를 정리해줘. 의미와 조건은 유지해줘.` |
   | Claude Code | `/korean-protocol 이 보고서를 정리해줘. 의미와 조건은 유지해줘.` |

2. **필요한 문체를 지정한다.**
   높임말을 원하면 `높임말로 써줘`를 덧붙인다.
   새 글은 `이번 작업의 완료 보고를 작성해줘`처럼 요청한다.
3. **적용 근거와 출력을 확인한다.**
   스킬 목록과 읽기·호출 기록을 확인한다.
   [짧은 예문](on-demand-skill.md#설치와-호출을-확인한다)에서 대상·담당자·기한의 보존을 확인한다.

파일 설치와 모델의 모든 출력 준수는 별개다.
스킬 목록에 없으면 호스트를 다시 시작한다.
사용을 멈출 때는 새 대화에서 호출하지 않는다.
이미 읽힌 규약은 현재 대화에 남는다.

## 기존 v0.11.0 이하 스킬이 있으면 교체한다

기존 설치의 출처·차이·사용자 수정을 확인한다.
폴더를 백업하고 원래 설치 경로를 비운 뒤 v0.11.1 파일을 복사한다.
새 대화에서 호출하고 [설치 결과](on-demand-skill.md#설치와-호출을-확인한다)를 확인한다.

## 기존 0.7 상시 설치가 있으면 전환한다

0.7은 상시 사용자 지침이다.
[상세 전환 절차](../../INSTALL.md#기존-07-상시-지침에서-전환한다)에 따라 같은 설치의 `protocol_off`를 실행한다.
`enabled=false`와 기존 높임말·자동 갱신 설정 보존을 확인한다.
설치가 없으면 새 0.7을 만들지 않는다.

0.7 ZIP이나 `agent_install.py install`은 이 스킬을 설치하지 않는다.
기존 서명 콘텐츠·자동 갱신기는 보존한다.

## 참고

v0.11.1은 L1~L4의 산출물과 참조 읽기 의무를 정의했다.
L2~L4를 선택하면 작성 전에 지정한 참조 파일을 읽는다.

설치 파일은 v0.11.0과 같은 13개다. 바뀐 파일은 5개다.

| 파일 | 역할 |
| --- | --- |
| `SKILL.md` | 코어 지침을 담는다. |
| `references/interactive-html.md` | HTML 작성 지침을 담는다. |
| `references/output-formats.md` | 출력 형식 지침을 담는다. |
| `assets/interactive-explainer.html` | 재사용 HTML 예제를 제공한다. |
| `scripts/check_html.py` | HTML 진단을 수행한다. |

`SKILL.md`는 `o200k_base` 7,243토큰이다.
v0.11.0보다 790토큰·약 12% 늘었다.
[v0.11.1 진단 기록](../../evaluation/kp-v0111-output-formats-20261113/README.md)은 형식 준수 결과다.

[v0.11.0 진단용 파일럿](../../evaluation/kp-lean-pilot-20261113/README.md)에서 사용자가 후보 5를 채택했다.
의미 통과는 17/20이며 실패 3건이 남았다.
사례 5개·반복 1회이며 후보에 유리한 검토 기준의 한계가 있다.

**과거 기록:** v0.10.0은 출력 매체를 추가했고 v0.10.1은 표현 기준을 다듬었다.
두 버전의 정식 비교는 [변경·검증 상태](output-formats-candidate-status.md)에 남겼다.
[v0.9.0 비교](../../evaluation/clarity-20261016-r60/README.md)는 수락 기준을 통과하지 못했다.

로컬 스킬은 다른 기기·원격 호스트·ChatGPT로 자동 전달되지 않는다.
ChatGPT의 기존 0.7 파일은 [채팅 안내](../../distribution/CHAT-START.md)를 따른다.
지원 범위는 [호스트 안내](host-support.md)에서 확인한다.

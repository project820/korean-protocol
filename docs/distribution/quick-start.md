# Korean Protocol을 처음 사용한다

Korean Protocol은 **필요할 때 호출하는 한국어 작성 스킬**이다. 글의 의미와 조건을 유지하면서 대상·판단·기한을 찾기 쉽게 정리한다. 별도 모델이나 자동 교정 필터가 아니다.

## 한 번 설치한다

Codex 또는 Claude Code에 다음을 보낸다.

```text
https://github.com/project820/korean-protocol 의 INSTALL.md를 읽고,
검증한 보완 스킬을 지금 호스트의 사용자 범위에 설치해줘.
자동 호출은 끄고 다른 프로젝트에서도 호출할 수 있게 해줘.
기존 0.7 상시 설치가 있으면 규약만 OFF로 전환하고 다른 설정은 보존해줘.
설치·스킬 발견·실제 호출 결과를 확인해줘.
```

두 호스트 모두 설치하려면 둘 다 요청한다. 기존 스킬 폴더는 출처·차이·사용자 수정을 확인하고 백업하기 전까지 덮어쓰지 않는다. [설치 안내](../../INSTALL.md)는 호스트별 위치와 복사 파일을, [수동 설치 명령](on-demand-skill.md#검증한-파일을-복사한다)은 고정 커밋과 호스트 설정을 설명한다.

## 새 대화에서 호출한다

| 사용하는 도구 | 입력할 요청 |
| --- | --- |
| Codex | `$korean-protocol 이 보고서를 정리해줘. 의미와 조건은 유지해줘.` |
| Claude Code | `/korean-protocol 이 보고서를 정리해줘. 의미와 조건은 유지해줘.` |

원문을 붙이거나 파일을 지정한다. 새 글은 `이번 작업의 완료 보고를 작성해줘`처럼 요청한다. 높임말을 원하면 `높임말로 써줘`를 덧붙인다.

자동 호출은 꺼 둔다. 스킬을 사용하지 않을 때는 새 대화에서 호출하지 않는다. 이미 읽힌 규약은 현재 대화에 남으므로 호출 뒤 “OFF”라는 말로 컨텍스트를 지우지는 못한다. 스킬 목록에 없으면 호스트를 다시 시작한다.

## 기존 0.7 사용자는 먼저 전환한다

0.7은 상시 사용자 지침이며 새 스킬과 다르다. 기존 설치의 `status`로 호스트·홈·상태 경로를 확인한 뒤, 같은 설치의 `protocol_off`를 실행한다. `enabled=false`와 기존 높임말·자동 갱신 설정 보존을 확인하고 새 대화에서 스킬을 호출한다. 설치가 없으면 새 0.7을 만들지 않는다. [상세 전환 절차](../../INSTALL.md#기존-07-상시-지침에서-전환한다)를 따른다.

0.7 ZIP이나 `agent_install.py install`은 이 스킬을 설치하지 않는다. 기존 서명 콘텐츠·자동 갱신기를 스킬 설치로 교체하거나 제거하지 않는다.

## 적용을 확인한다

스킬 목록과 읽기·호출 기록을 확인한 뒤 [짧은 예문](on-demand-skill.md#설치와-호출을-확인한다)을 변환한다. 대상 목록·담당자·기한의 보존을 확인한다. 파일 설치와 모델의 모든 출력 준수는 별개다.

보완본은 [고정 개발 사례](../../evaluation/field-report-20261015/README.md#보완-후보의-검증-범위를-밝힌다)의 의미·구조 검사를 통과했다. 원문보다 항상 짧아지거나 모든 독자가 한 번에 이해한다는 보장은 아니다. 설치본은 검증한 커밋에 고정하며 새 후보로 갱신할 때 직접 교체한다.

로컬 스킬은 다른 기기·원격 호스트·ChatGPT로 자동 전달되지 않는다. ChatGPT에서 기존 0.7 파일을 사용할 때는 [채팅 안내](../../distribution/CHAT-START.md)를 따른다. 지원 범위는 [호스트 안내](host-support.md)에서 구분한다.

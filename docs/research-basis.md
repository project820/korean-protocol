# Korean Protocol 초안의 연구 근거

초기 규약은 2026년 10월 12일의 문헌 조사를 바탕으로 작성했다. 아래의 규칙은 연구에서 도출한 편집 기준이며, 논문이 직접 승인하거나 효과를 검증한 한국어 규격은 아니다.

원문을 확보한 자료와 초록만 확인한 자료를 구분한다. 군 언어 교육자료와 현행 군 작전명령 규정, 한국어 모어 독자 연구와 외국어 학습 교재 연구도 같은 근거로 취급하지 않는다.

현재 V7 r2의 채택은 [사용자가 선택한 가독성](../experiments/v7/adoption.md)에 따른 결정이다. 아래 문헌이 V7의 구조 규칙이나 실제 출력의 의미 보존·독자 이해 효과를 직접 검증한 것은 아니다. 필요한 뜻과 구분을 남기며 원문보다 짧아야 한다는 기준은 두지 않는다.

## 규칙과 근거의 연결

| 규칙 | 근거를 적용한 방식 | 판단의 한계 |
| --- | --- | --- |
| [KP 01](protocol-draft.md#kp-01)은 뜻을 유지한다. | S5의 양태 구별과 S6의 문장 기능 연구를 바탕으로 의미 보존을 우선하는 기준을 두었다. | 의미 보존의 우선순위는 프로젝트의 설계 결정이다. |
| [KP 02](protocol-draft.md#kp-02)는 행동을 직접 서술한다. | S1의 간결한 기술문서 작성 원리에서 출발해 한국어 우회 표현을 줄이는 후보를 만들었다. | 제시한 한국어 대체문은 실험으로 검증하지 않았다. |
| [KP 03](protocol-draft.md#kp-03)은 이름을 일관되게 쓴다. | S1의 용어 일관성 원리를 같은 문서와 대화의 개념 추적에 적용했다. | 한국어 전체의 동의어나 다의성을 금지하는 근거는 아니다. |
| [KP 04](protocol-draft.md#kp-04)는 익숙하고 정확한 말을 고른다. | S3의 단어 빈도 실험을 어휘 선택의 변수로 참고했다. | 친숙도만으로 전문어의 정확성을 대신할 수 없다. |
| [KP 05](protocol-draft.md#kp-05)는 문맥에 따라 생략한다. | S4에서 지시 대상의 연속성에 따른 처리 차이를 확인했다. | 생략이 명시보다 언제나 우수하다는 결과는 아니다. |
| [KP 06](protocol-draft.md#kp-06)은 문장 구조를 정돈한다. | S7의 한국어 관계절 연구를 바탕으로 길이와 구조를 함께 평가한다. | 관형절의 전면 금지나 고정 어절 상한을 도출하지 않는다. |
| [KP 07](protocol-draft.md#kp-07)은 조건과 순서를 연결한다. | S1의 절차문 원리와 S2의 명확한 지시 교육을 참고했다. | 영어 규칙을 그대로 옮기지 않고 한국어 대체문을 검증해야 한다. |
| [KP 08](protocol-draft.md#kp-08)은 가능성과 기능을 구분한다. | S5·S6의 의미 구별과 S2의 모름을 인정하는 소통을 참고했다. | 특정 경고문의 이해 효과를 직접 시험한 근거는 아니다. |
| [KP 09](protocol-draft.md#kp-09)는 행동 기준을 확인한다. | S2의 공유 지식 확인과 S8의 목적·제약 공유를 참고했다. | 세부 절차를 모두 명시하라는 규칙으로 확대하지 않는다. |
| [KP 10](protocol-draft.md#kp-10)은 결과부터 보고한다. | S2의 결론 우선 보고와 사실·의견 구분을 참고했다. | 모든 장르를 군 보고 형식으로 바꾸는 근거는 아니다. |
| [KP 11](protocol-draft.md#kp-11)은 설명의 양을 조절한다. | S8의 상황별 정보량과 S9의 정보성·용이성 구분을 참고했다. | 정보량을 정하는 보편적인 숫자는 제시하지 않는다. |
| [KP 12](protocol-draft.md#kp-12)는 어조를 상황에 맞춘다. | S6의 상황별 종결표현과 S2의 비권위적 의사소통을 참고했다. | 특정 종결형을 모든 독자에게 최적으로 간주하지 않는다. |

## 주요 문헌과 확인 범위

<a id="s1"></a>
### S1 ASD STE100 Issue 9

ASD와 STEMG의 2025년 영어 기술문서 규격이다. 작성 규칙, 통제 어휘, 절차문과 설명문, 용어 일관성을 참고했다. 원문 발췌와 공식 설명을 확인했으며, 규격 전체를 정독한 것으로 표시하지 않는다. [규격 PDF](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf)와 [공식 FAQ](https://asd-ste100.org/STE_faq.html)에서 확인할 수 있다.

이 자료는 영어의 규범 문서이며 한국어의 개별 규칙에 대한 효과 실험은 아니다.

<a id="s2"></a>
### S2 국군 장병의 언어 사용 실태 조사와 교육 자료 개발

박재현 책임연구, 국립국어원, 2016년 보고서다. 공식 PDF에서 인쇄 145–146쪽의 모름을 인정하는 답변, 195쪽의 명확한 지시, 198–200쪽의 보고 원리, 285–287쪽의 과도한 생략을 검토했다. 145·195·199쪽은 렌더링 이미지로도 확인했다. [공식 보고서](https://www.korean.go.kr/front/reportData/reportDataView.do?mn_id=&pageIndex=2&report_seq=910&searchOrder=)에서 원문을 제공한다.

장병의 언어교육 연구자료이며 현행 작전명령 규정은 아니다. 보충자료가 인용한 내용을 이 보고서 자체의 실험 결과로 취급하지 않는다.

<a id="s3"></a>
### S3 우리글 명사 어절에서의 단어 빈도 효과

고성룡·홍효진·윤소정·조병환의 2008년 안구운동 연구다. 공개 원문의 방법·결과·논의를 확인했다. 고빈도 명사와 명사·조사 결합 어절은 저빈도 조건보다 고정·주시 시간이 짧았다. [학술지 원문](https://accesson.kr/cogpsych/assets/pdf/17413/journal-20-1-21.pdf)에서 확인할 수 있다.

어절 전체의 빈도를 사전에 통제하지 못한 한계가 있다. 모든 저빈도 단어나 한자어를 삭제할 근거는 아니다.

<a id="s4"></a>
### S4 생략된 주어가 있는 문장 처리에 담화특출성이 미치는 영향

송현주·윤정은의 2007년 연구다. 학술지 서지와 초록을 확인했다. 생략된 주어가 앞 문장의 주어를 이어받는 경우 이해가 빨랐다고 보고한다. [학술지 페이지](https://accesson.kr/cogpsych/v.19/4/383/17405)에서 확인할 수 있다.

생략문과 명시문 전체의 우열을 직접 비교한 결과는 아니다.

<a id="s5"></a>
### S5 한국어 가능성 양태의 의미

김남길의 2016년 논문은 제목이 “The modality of epistemic and non-epistemic possibility in Korean: -(u)l swu iss and -(u)l ci molu”이며, 가능성·능력·허락과 인식적 용법을 분석한다. KCI 서지와 초록을 확인했다. [KCI 페이지](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002082557)에서 확인할 수 있다.

특정 한국어 경고문을 읽는 독자의 행동을 시험한 연구는 아니다.

<a id="s6"></a>
### S6 한국어 종결표현의 화행 기능과 한국어 모어 화자의 인식에 관한 연구

강현화·홍혜란의 2010년 연구다. KCI 서지와 초록을 확인했다. 같은 종결표현이 여러 기능을 수행하며 상황에 따라 표현 선택과 판단이 달라진다고 보고한다. 여기서 화행은 요청·명령·보고처럼 말을 통해 수행하는 행위를 뜻한다. [KCI 페이지](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART001480489)에서 확인할 수 있다.

종결형 하나를 고르면 모든 문장의 이해가 개선된다는 결과는 아니다.

<a id="s7"></a>
### S7 한국어 관계절 처리의 차이

Kwon·Kluender·Kutas·Polinsky의 2013년 논문 “Subject/object processing asymmetries in Korean relative clauses: Evidence from ERP data”이다. 공개 원문의 초록·방법·참가자·결론을 확인했다. 한국어 관계절의 구조에 따른 처리 차이를 다룬다. [공개 원문](https://pmc.ncbi.nlm.nih.gov/articles/PMC4231604/)에서 확인할 수 있다.

문맥을 제한한 실험이므로 모든 실제 문서의 관형절을 같은 비용으로 평가하지 않는다.

<a id="s8"></a>
### S8 ADP 6-0 Mission Command

미국 육군의 2019년 교리다. 공개 PDF 원문에서 목적과 결과, 적절한 정보량, 공유된 용어·절차를 다룬 부분을 확인했다. [FAS 보존 원문](https://irp.fas.org/doddir/army/adp6_0.pdf)에서 확인할 수 있다.

미군 교리는 한국군의 현행 규정이나 한국어 문체의 실험 근거가 아니다. 임무 수행 방법의 재량을 남기는 명령과 정해진 작업을 수행하는 절차문을 구분하는 데 참고했다.

<a id="s9"></a>
### S9 공공언어 요건 정립 및 진단 기준 개발 연구

민현식 책임연구, 국립국어원, 2010년 보고서다. PDF의 관련 부분을 검색하고 인쇄 317쪽의 최종 진단 기준표 등을 이미지로 확인했다. 정확성과 소통성을 구분하며 정보량·구성·문장 길이·친숙한 용어를 별도 항목으로 다룬다. [공식 보고서](https://korean.go.kr/front/reportData/reportDataView.do?mn_id=207&report_seq=486)에서 원문을 제공한다.

공공언어 평가 체계이며 본 프로젝트의 규칙이나 평가 가중치를 검증한 자료는 아니다.

## 규약의 효과를 검증하는 방법

문장을 짧게 만들거나 금칙어를 줄이는 것만으로 성공을 판정하지 않는다. Guitton 등의 2025년 독일어 법률문 실험에서는 통제언어 조건의 이해 점수가 높아졌지만, 지각된 모호함은 줄지 않았고 사용성 우위도 유의하지 않았다. 출판사 원문의 방법·결과·한계를 확인했다. [논문](https://dl.acm.org/doi/10.1145/3711128)

이 결과를 한국어에 그대로 적용하지 않고, 다음 순서로 검증한다.

1. 실제 한국어 문장과 앞뒤 문맥, 독자, 전달 목적을 함께 수집한다.
2. 후보 규칙으로 문장을 고치고 사실·조건·확실성·문장의 역할을 보존했는지 검토한다.
3. 원문 유지, 간결한 대체문, 필요한 설명을 보충한 문장을 비교한다. 정보가 추가된 조건은 의미 보존 수정과 별도로 분석한다.
4. 독자의 이해 정확도, 읽기 시간, 재독·추가 질문, 자연스러움과 단정함을 각각 측정한다.
5. 검증 결과에 따라 규칙과 적용 조건을 고친다. 효과가 없거나 반대로 작용한 사례도 남긴다.

실험에서는 제시 순서와 같은 내용의 반복 노출을 통제한다. 한국어 모어 독자의 분야 지식도 구분하고, 표본 수는 예비실험의 변동성과 검증할 효과에 따라 정한다.

한국어 통사·의미·화용·어휘 연구자, 기술교범·군사 의사소통 전문가, 심리언어학·인간공학 연구자의 검토가 필요하다. 현재 문헌 조사와 초안 작성은 실제 전문가 자문을 대신하지 않는다.

세부 조사 경로와 추가 문헌은 [상세 연구 보고서](../research/2026-10-12/research-report.html)에 보존했다. 이후 규약의 개정은 초기 조사와 구분해 기록한다.

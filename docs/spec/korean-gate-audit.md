# 한국어 관문 독립 증거 감사

> **과거 기록을 보존한다.** 아래 버전·검증 수치·미완료 항목은 작성 당시의 상태다. 현행 0.7의 사용법은 [설치 안내](../../INSTALL.md), 확인 범위는 [현재 상태](../status/requirements.md)를 따른다. 과거 결과를 0.7의 재검증으로 계산하지 않는다.

이 문서는 새 독립 사례를 추가하기 전의 기존 증거 감사다. 이후 작성·검토한 31개 사례의 결과와 남은 한계는 [보완 보고서](../../evaluation/korean-independent/report.md)에 별도로 기록했다. 아래 14/24 판정을 덮어쓰지 않는다.

한국어 관문은 독립 규범 증거가 부족해 통과하지 못한다. 8범주×3기능의 24칸 중 14칸은 기존 사례·판정으로 뒷받침되며 10칸에는 공백이 있다. 이는 규칙 자체의 언어학적 오류를 입증한 판정이 아니라 제5절 완료 증거의 부족 판정이다.

감사 기준은 `/Users/m5max/.codex/worktrees/korean-protocol-integration/ASD-STE100 Kor`의 실제 파일 바이트이며 감사 시각은 `2026-10-12T13:36:21.432261+00:00`이다. 기준 파일의 작성자 사례 242개는 독립 사례 수에 합산하지 않았다. 후속 작성자 사례가 398개로 늘어도 같은 원칙을 적용한다. 독립 기능 사례 자료 84개 중 `FC-7-3`만 독립이 아니며 나머지 83개가 독립 입력이다.

## 각 셀은 다음 기능을 판정한다.

정상은 독립 사례의 명시 허용 대안 또는 명확한 입력의 정상 관계를 확인한다. 실패는 결함·미확정 관계가 입력 자체에 있고 `revise`/`clarify` 판정을 받은 경로를 확인한다. 원문 유지는 `keep`이며 허용 대안이 입력과 같은 사례를 확인한다. 정상 사례의 거부 대안만으로 잘못된 입력을 처리하는 실패 경로까지 검증했다고 세지 않는다.

같은 사례의 재사용은 기능이 실제로 겹치는 경우에 한하며 JSON의 각 셀에 논항·대상·상태·범위와 유지 예외를 구체적으로 적었다. 정상과 원문 유지에 같은 사례를 쓴 경우 정상 관계 확인과 불필요한 편집 거부를 구별한다. 정상 수정의 허용 대안은 모델 실행 결과가 아니라 독립 기능 설계 검토의 명시 판정이다.

## 공백은 다음 하위 기능에 남아 있다.

- `KG-MISS-NEG-N`는 부정·수량의 정상 기능 공백이다. FC-9-1의 미완료와 FC-5-5-L의 상한은 부정·수량 범위 결합을 대조하지 않는다. h05/g05는 LLM 출력 평가이다.
- `KG-MISS-NEG-F`는 부정·수량의 실패 기능 공백이다. 전면/부분 부정 또는 이중 부정·한정 범위 오류의 결함 input을 독립 기능 판정한 사례가 없다. h06 평정은 규범 판정이 아니다.
- `KG-MISS-NEG-K`는 부정·수량의 원문 유지 기능 공백이다. 확정된 부정·수량 범위에서 원문을 유지한 독립 기능 판정이 없다.
- `KG-MISS-CAUS-N`는 피동·사동의 정상 기능 공백이다. 피동 정상 대안은 있지만 지시자와 수행자를 구별한 사동 대안의 독립 판정이 없다.
- `KG-MISS-CAUS-F`는 피동·사동의 실패 기능 공백이다. 피동 실패 input은 있지만 사동을 직접 수행으로 바꾼 결함 input의 판정이 없다.
- `KG-MISS-CAUS-K`는 피동·사동의 원문 유지 기능 공백이다. 상태 피동의 keep은 있지만 지시자·수행자 관계가 필요한 사동의 keep이 없다. h18도 피동 출력 평가이다.
- `KG-MISS-HON-N`는 높임·종결형의 정상 기능 공백이다. FC-9-4는 버튼 동사의 표현 일관성이고 높임 수정이 아니다. h20은 실제 LLM의 정중 요청 평가이다.
- `KG-MISS-HON-F`는 높임·종결형의 실패 기능 공백이다. 종결 오류 근거는 있지만 사물 주체 높임이나 높임 대상 변경의 결함 input 판정이 없다.
- `KG-MISS-HON-K`는 높임·종결형의 원문 유지 기능 공백이다. 허락 종결 keep은 있지만 실제 인물 주체 높임이나 정중 요청을 유지한 독립 기능 사례가 없다.
- `KG-MISS-SIM-F`는 조건·동시성의 실패 기능 공백이다. 조건 실패는 있지만 동시 유지가 순서로 바뀐 결함 input 판정은 없다. FC-5-2의 rejected_output은 위험을 보이지만 해당 후보가 input인 실패 경로는 아니다.

조사·논항 행은 수신자·대상 구분과 회복 가능한 목적격 논항을 검증한다. `은·는`/`이·가`의 대조 정보 같은 세부 현상까지 검증했다고 확장하지 않는다. 한국어 관문 최소 증거의 충족은 모든 한국어 문법·규칙의 효능 입증이 아니다.

## LLM 평정은 독립 규범 판정과 분리된다.

`evaluation/llm/holdout.json`은 신규 h01~h24와 기존 회귀 s01/s02를 포함하며 생성·신규 검증 집합은 각각 12개다. `h05`/`h06`의 부정 범위, `g05`의 부정 수량, `h18`의 피동 상태, `h20`의 정중 요청은 후속 사례의 범위 참고가 되지만 출력의 0~2점은 규범 정상·실패·유지 판정 기록을 대체하지 않는다. 최초 평정자는 사례 저자와 runner이고 root도 일부 후보 통합·기노출을 공개했다. 사람 독자 이해도 시험은 이 자료에 없다.

`v07`의 historical treatment A 문장은 “큐 길이가 20개 이하이고 활성 작업이 0개인 두 조건을 모두 만족할 때만 스냅샷을 생성하세요.”이다. 기존 root는 의미·목적·명확성에 각 1점을 주면서도 조건 충족 시 반드시 생성한다는 의무 확정까지 판정하지 않았다. [rating-contestation.md](../../evaluation/llm/permission-diagnostic-20261012/rating-contestation.md)는 제한적 지시 해석과 purpose1 rubric 적용의 이견을 기록하며 외부 Opus 검토 자체는 해당 진단 에이전트가 실행하지 않았다고 명시한다. 본 감사는 이견을 해결하거나 점수를 덮어쓰지 않으며 이를 한국어 규범 실패·통과로 바꾸지 않는다.

## 다음 독립 저자는 누락 사례를 다음 조건으로 작성해야 한다.

아래 ID는 아직 사례로 작성하지 않은 요청 명세이며 사례 수·통과 수에 계산하지 않는다. 별도 저자는 새 문맥·입력을 만들고 작성자 예문을 복제하지 않아야 한다. 별도 검토자는 실제 사례 ID, 한국어 규칙, 판정 이유, 작성자·검토자 관계와 파일 해시를 기록해야 한다.

- `KG-MISS-NEG-N`는 `revise` 판정을 요구한다. 전체·성공·실패 수량이 고정된 새 집합에서 부분 부정의 범위를 모호하게 쓴 input을 명확히 고친다. 전면 부정으로 바뀐 대안을 거부한다.
- `KG-MISS-NEG-F`는 `clarify` 판정을 요구한다. 작성자 문장과 다른 한정 대상·이중 부정 input을 준다. 의도 자료가 없고 대상 집합 해석이 둘임을 문맥에 밝히며 임의 범위 확정 대안을 거부한다.
- `KG-MISS-NEG-K`는 `keep` 판정을 요구한다. 새 수량 집합에서 부분 또는 전면 부정 중 하나만 문맥상 성립하는 명확한 input을 유지한다. 반대 범위 대안을 거부한다.
- `KG-MISS-CAUS-N`는 `revise` 판정을 요구한다. 지시자·실제 수행자·시점을 확인한 문맥에서 장황한 사동 input을 관계 보존 대안으로 고친다. 지시자가 직접 수행한 대안을 거부한다.
- `KG-MISS-CAUS-F`는 `revise` 판정을 요구한다. 실제 원문에 지시자·수행자를 명시하고 input이 사동을 직접 수행으로 오기한 편집 후보임을 사례 안에 밝힌다. 관계 복구는 허용하고 주체를 합치는 대안은 거부한다.
- `KG-MISS-CAUS-K`는 `keep` 판정을 요구한다. 지시자와 수행자 구별이 필요한 새 문맥에서 명확한 사동 input을 그대로 유지하고 직접 수행으로 단순화한 대안을 거부한다.
- `KG-MISS-HON-N`는 `revise` 판정을 요구한다. 독자 관계·정중 요청 화행을 고정하고 장황한 높임 요청 input을 간소화한다. 허락·강한 명령으로 바뀐 대안을 거부한다.
- `KG-MISS-HON-F`는 `revise` 판정을 요구한다. 사물 상태만 알려지고 행위자는 미확정인 문맥에서 사물에 인물 높임이 잘못 붙은 input을 준다. 상태 보존 수정만 허용하며 사람을 만들어 넣는 대안을 거부한다.
- `KG-MISS-HON-K`는 `keep` 판정을 요구한다. 확인된 실제 인물 행위와 독자 관계를 밝히고 적절한 주체 높임·종결형의 input을 유지한다. 높임 대상·화행을 바꾼 대안을 거부한다.
- `KG-MISS-SIM-F`는 `revise` 판정을 요구한다. 두 번째 행동이 끝날 때까지 첫 상태를 유지해야 하는 실제 원문과 해제 시점을 고정한다. input은 상태를 먼저 해제한 뒤 행동하게 오기한 후보임을 밝히고 동시 유지 복구를 판정한다.

## 재현은 기준 해시와 연결 계약을 확인한다.

감사 JSON의 `source_hashes`는 읽은 규범·사례·고정 입력·평정·이견 문서 27개의 바이트 SHA-256을 담는다. `functional_review_hash_checks`는 기존 네 검토 해시의 실제 일치를 기록한다. 기준 파일이 바뀌면 이전 감사 결과를 새 버전의 통과 근거로 승계하지 않고 24칸을 다시 판정해야 한다.

본 감사는 두 증거 파일만 작성했으며 사례·규칙·프로필·모델 출력을 변경하지 않았다. 신규 모델 호출과 사람 독자 시험은 수행하지 않았다. 다음 조치는 누락 명세 10개의 독립 작성·별도 기능 검토·해시 고정 뒤 재감사이다.

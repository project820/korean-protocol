# 출력 형식 개편의 기존 규칙 대응을 기록한다

이 문서는 기존 KP 규칙의 누락과 충돌을 대조한다. 출력 품질의 비교 완료나 향상을 판정하지 않는다. 과거 원시 출력과 판정은 변경하지 않는다.

## 기준본과 대조 방법을 고정한다

## 새 규칙과 기존 경계의 관계를 기록한다

- SKILL의 4A절은 출력 형식 선택과 참조 로딩을 추가한다. 기존 4절의 사용자 형식 우선·고정 틀 금지·표제의 범위 보존을 L1~L4로 확장한다.
- SKILL의 4A절은 요청 범위의 사실·수치·조건·예외·경고·출처·확실성·시간 관계의 생략 금지와 보존 수락 조건을 명시한다. 기존 2·3절의 근거·의미 경계를 줄이거나 대체하지 않는다.
- SKILL의 5절 뒤에 매체별 확인 범위를 추가한다. 기존 양방향 대조의 세 목록 항목은 그대로 유지한다.
- `references/output-formats.md`는 L1·L2의 기본형·적용 전후·비격상 사례·설계 근거를 제공한다. `references/interactive-html.md`와 `references/video-script.md`는 L3·L4를 선택한 경우에만 읽는다.
- `assets/interactive-explainer.html`은 가상 자료로 만든 오프라인 예제다. 실제 작업의 수치·결론·안전 보장으로 사용하지 않도록 자료 상태와 계산 한계를 함께 표시한다.
- 사용자 출력에는 KP만 적용한다. STE 프로필·평가 대조군은 사용자 스킬의 모드나 의존성에 포함하지 않는다. 명시 호출 범위는 기존 frontmatter와 호스트별 설치 정책을 따른다.

## 개별 보존 점검과 품질 비교를 구별한다

해시 대응은 기존 규칙 문구가 남았는지를 검증한다. 실제 에이전트가 규칙을 지켰는지와 더 명료해졌는지는 별도의 원문·KP·STE 비교에서 판정한다. 대조군 누락·실행 실패·비교 조건 불일치가 있으면 비교 상태는 미완료로 기록한다. 비교 실행이 끝나도 의미 판정이 미해결이면 품질 게이트를 통과 처리하지 않는다.

## 전언을 표로 나누는 단계의 귀속 경계를 보완한다

`references/output-formats.md`의 L2 분해 단계에 조사구·수식어의 귀속 대조를 추가했다. 귀속을 하나로 정할 수 없으면 원문과 문맥을 한 주장 단위로 유지하고 특정 역할 칸에 배정하지 않는다. `references/meaning-boundaries.md`에는 별도 가상 교육 사례로 잘못된 역할 분해·사실화와 적절한 문장·표 구조를 추가했다.

이 보완은 기존 코어 2절의 전언 귀속·근거 없는 관계 보충 금지와 4절의 구조 변경 시 주체·출처·범위 보존을 L2 작업에 연결한다. 코어와 위 대응표의 기존 행은 변경하지 않았다. 예시 추가 자체는 품질 향상이나 비교 완료의 근거가 아니며 새 후보의 독립 평가가 필요하다.

최종 로컬 적용본은 기존 규칙이 L1의 공통 작성 기준이며 모든 매체에 적용된다는 점을 도입에 명시했다. L2는 아키텍처·프로세스·상태 변화·세 항목 이상 비교의 기본값으로 두고 사용자 형식과 원문 관계를 우선한다. L3의 기본 파일명은 `index.html`이며 L4는 명시 요청에만 활성화한다.

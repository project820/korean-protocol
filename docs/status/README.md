# 0.7.0의 현행 상태와 과거 근거를 찾는다

현재 원본은 `0.7.0-draft`, 공개 서명 콘텐츠는 `0.7.0·순번 3`, 엔진은 `0.2.0`이다. 사용자 패키지 [v0.7.0](https://github.com/project820/korean-protocol/releases/tag/v0.7.0)은 `7e01d53`에서 발행했으며 이후 main의 문서 개정은 기존 ZIP에 자동 반영되지 않는다.

## 현행 판단에 사용할 문서를 고른다

| 확인할 내용 | 기준 문서 |
| --- | --- |
| 원본 수치와 남은 검증을 확인한다. | [요구사항과 검증 상태](requirements.md)는 규칙 72개·규칙 사례 296개·사전 193뜻과 기능 대응 설계 49개·검증 0개·부분 4개를 구분한다. |
| 제공한 결과와 전체 완료의 차이를 확인한다. | [완료 점검](completion-audit.md)은 언어 효과·독자 시험의 남은 항목을 기록한다. |
| 공개 발행과 패키지 원본을 확인한다. | [게시 상태](publication-readiness.md)는 서명 콘텐츠·사용자 ZIP·서명 이력을 구분한다. |
| V7의 채택과 검증을 확인한다. | [V7 채택](v7-adoption.md)과 [V7 검증](v7-verification.md)은 이전 보완본 r2의 선택, r3 미채택, 코드·모델 실행의 한계를 기록한다. |
| 기존 검토와 평가의 적용 버전을 확인한다. | [연구 근거](research-evidence.md)와 [독립 검토 이력](review-log.md)은 과거 결과를 현행 효과와 구분한다. |

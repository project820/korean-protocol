# MIT 적용을 완료했으며 공개 전환 결정은 남아 있다

> **과거 기록을 보존한다.** 아래 버전·검증 수치·미완료 항목은 작성 당시의 상태다. 현행 0.7의 사용법은 [설치 안내](../../INSTALL.md), 확인 범위는 [현재 상태](requirements.md)를 따른다. 과거 결과를 0.7의 재검증으로 계산하지 않는다.

사용자는 직접 작성한 코드와 문서에 MIT License를 통일 적용하도록 선택했다. 앞선 라이선스 미정 차단은 해소됐다. 기존 연구·언어 평가와 배포 검증의 범위는 유지하며 이 결정만으로 전체 목표를 완료했다고 표시하지 않는다.

| 요구사항은 다음과 같다. | 현재 증거는 다음을 입증한다. | 남은 범위는 다음과 같다. |
| --- | --- | --- |
| STE 작성 기능의 90% 이상에 대응한다. | 규칙·대응표·기능 검토 입력은 변경하지 않았고 49/53개 설계 검증을 유지한다. | 부분 대응 네 개와 언어 성능의 차이를 공개한다. |
| 한국어 규칙·예외·용례·사전을 제공한다. | 기존 72개 규칙·193개 뜻과 작성 사례·독립 범주 검토를 보존했다. | 전문가 승인·모든 구문 포괄성을 주장하지 않는다. |
| 실제 LLM의 의미와 과제 범위를 검증한다. | 세 프로필은 byte-identical이며 기존 새 12개 평가 결과를 보존한다. | 동률·단일 합성 배치의 결과를 일반 개선이나 사람 이해도로 확대하지 않는다. |
| 지속 설치·오프라인 유지·자동 갱신을 제공한다. | MIT 포함 ZIP의 두 호스트 설치·캐시·관리 코드·원본 이동 후 관리·제거를 시험했다. 실제 Secret 서명물의 고지 포함 캐시도 확인했다. | 공개 endpoint의 예약 갱신·실제 다음 버전 업그레이드·재로그인·물리적 절전 복귀는 미검증이다. |
| 누구나 설치·사용·재배포할 조건을 정한다. | LICENSE와 NOTICE.md를 추가하고 ZIP·단독 문서·캐시·관리 코드에 허가문을 보존했다. | 저장소는 PRIVATE이고 첫 Pages 게이트는 꺼져 있어 익명 공개 설치는 아직 가동하지 않는다. |

[MIT 배포 검증](../distribution/mit-distribution.md)은 e5d0c5d의 실제 패키지·설치 및 Actions 서명을 기록한다. 최종 전체 자동 테스트는 300개를 통과했고 실제 GitHub 작업의 발행 관련 검사는 95개를 통과했다. 미리보기 8의 세 첨부물은 다시 내려받아 원본과 대조했다. 서명 manifest·개인키의 신뢰 경로와 콘텐츠 목록 계약은 바꾸지 않았다.

독립 Astra/high 검토에서 지속 관리 코드 두 파일의 AST, 세 프로필의 바이트, 기존 상세 규약의 접두 내용이 유지됨을 확인했다. 상세 규약에는 고지만 덧붙였다. 최초 새 설치 테스트는 예전 관리 폴더를 가정해 실패했으며, 반환된 관리 경로를 쓰도록 검사만 수정한 뒤 전체 재실행이 통과했다.

검토 가능한 공개 후보는 MIT 포함 미리보기 8과 e5d0c5d의 규약·런타임이다. 공개 여부는 비공개 개발 후 공개한다는 사용자 방침에 따라 별도로 결정한다. 공개하면 저장소의 코드·규약·평가 기록과 Git 이력이 열람 가능해진다. 승인 뒤에는 LICENSE 포함 원본으로 첫 정식 서명을 다시 발행하고 Pages의 실제 HTTPS 설치·갱신 경로를 확인한다. 승인 전에는 현재 비공개 상태를 유지한다.

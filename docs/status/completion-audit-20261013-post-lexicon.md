# 사전 조회 진단 후에도 전체 완료는 입증되지 않았다

규약·사전의 기준은 445110e이며, 이후 새 합성 문맥 12개에서 사전 조회를 허용한 실제 모델 진단을 수행했다. 앞선 완료 감사는 당시 상태로 보존한다. 새로운 증거를 과거 프로필의 평가나 전체 언어 성능으로 합산하지 않는다.

| 요구사항은 다음과 같다. | 현재 증거는 다음을 입증한다. | 남은 범위는 다음과 같다. |
| --- | --- | --- |
| STE 작성 기능의 90% 이상에 대응한다. | 현재 기능 검토는 49/53개를 통과했다. | 1.1·5.1·6.3·6.6은 부분 대응이며 사전·모델 성능 점수로 쓰지 않는다. |
| 한국어 규칙·조건·예외·용례를 제공한다. | 규칙 72개와 작성 사례 257개, 고정 독립 사례 30개의 최소 범주 검토가 있다. | 전체 한국어 구문·독자 이해도를 검증한 결과는 아니다. |
| 의미와 문맥에 따른 어휘 통제를 제공한다. | 뜻 193개·작성 사례 454개와 고정 문맥 평가를 보존한다. 새 진단에서는 실제 사전 조회와 관련 항목을 확인했다. | 표본의 조회를 전체 뜻의 이해나 어휘 충족률로 계산하지 않는다. LX12의 두 항목은 상대 허용 오차를 다루기에 부분 관련이었다. |
| 실제 LLM이 의미를 보존하고 명료하게 답한다. | 새 12개 사례의 두 조건 모두 의미 보존을 통과했다. | 두 조건 모두 LX12에서 필요한 편집 대신 불필요한 확인 질문을 했다. 개선 효과는 입증되지 않았다. |
| 한 번 설치한 내용을 유지하고 자동 갱신한다. | 실제 임시 호스트 로딩, 서명·HTTPS·오프라인 유지·롤백·고정·변조 거부 시험과 macOS 예약 등록·실행·해제 증거가 있다. | 공개 endpoint의 실제 예약 갱신, 재로그인·물리적 절전 복귀는 미검증이다. |
| 누구나 저장소 주소로 설치한다. | INSTALL.md와 비대화형 설치기를 제공하고 개인키를 GitHub 환경 Secret에 보관했다. | 저장소는 여전히 비공개이며 Pages 게시 스위치도 꺼져 있다. 공개 설치가 가동 중이라고 안내하지 않는다. |

[사전 조회 진단](../../evaluation/llm/lexicon-usage-20261013/report-ko.md)은 기준선과 적용 조건을 같은 입력으로 실행했다. 입력·계획·정답 조정은 실행 전에 고정했고, 조건을 가린 출력 평정과 공개된 조건 키를 분리했다. 원시 조회 기록과 보고 ID를 대조했다. 사람의 이해도나 한국어학·군사 전문가의 승인으로 해석하지 않는다.

[예약 실행 기록](../distribution/scheduler-registration-verification.json)은 미공개 서버 조회가 실패해도 기존 규약을 유지했음을 보인다. 정상적인 공개 콘텐츠 갱신 성공으로 대체해서 해석하지 않는다. Python 충돌 수정 후 전체 시험 287개와 새 진단 과정에서 추가 Python 충돌 보고서는 없었다.

다음 규범 검토는 문장 편집에 필요한 정보와 실제 작업 실행에 필요한 정보를 구분해야 한다. 원문 의미를 유지하는 정정이 가능하면 실행용 수치가 없다는 이유만으로 질문으로 바꾸지 않도록 적용 조건·예외·반례를 검토한다. 고정한 LX12 결과는 보완 전 증거로 남기며, 보완 후 같은 사례를 다시 쓰면 개발 회귀로 분리한다.

# 새 과제 평가와 최신 미리보기를 확인했지만 공개 운영은 아직 미검증이다

직전 목표 작업은 KP-EDIT-002 보완, 실제 개발 회귀, 설치 시험과 커밋·푸시를 완료했으므로 진척으로 분류한다. 이번 작업은 기준 9367bde의 제품 내용을 유지하면서 새 합성 과제 평가와 미리보기 7 배포 대조를 완료했다. 기존 평가와 완료 감사를 덮어쓰지 않았다.

| --- | --- | --- |

[새 과제 평가](../../evaluation/llm/scope-holdout-20261013/report-ko.md)는 초안의 확인 질문 편향도 기록했다. 모델 실행 전에 네 쌍을 보완했고 최초 12개와 정답 감사 원본을 pre-run-v1에 남겼다. 최종 12개의 입력·정답·계획·프롬프트·프로필·사전·실행기 해시는 출력 전에 고정됐다. 의미 실패를 이유로 재시도하거나 정답을 바꾸지 않았다. 두 실제 Sol/high 요청은 모두 정상 종료했고 독립 눈가림 평가에서 동률이었다.

[평가 실행기 검사](../../evaluation/llm/scope-holdout-20261013/runner-verification.json)는 새 검사 11개와 기존 공유 실행기 검사 8개의 통과를 기록한다. 제품 코드·규칙·사전은 바꾸지 않았으므로 이전 287개 전체 검사를 이번에 다시 실행했다고 주장하지 않는다. 현재 입력 해시와 실제 실행 계약·마운트의 동일성은 integrity-verification.json에 기록했다.

[미리보기 7 대조](../distribution/preview7-verification.json)는 9367bde 기준 미서명 ZIP의 30개 파일·CRC·체크섬, 기존 설치 시험본과 같은 SHA-256, GitHub 초안 상태·다운로드 일치를 입증한다. 이전 preview 6의 기반은 bd4290a이며 최근 런타임과 규약 수정이 빠져 있었으므로 새 초안을 추가했다. 미리보기의 기본 자동 갱신은 꺼져 있으며 이 업로드를 서명된 정식 업데이트나 공개 운영 성공으로 계산하지 않는다.

다음 배포 검증은 현행 커밋의 서명 발행물을 기존 GitHub Actions·Secret 경로에서 만들고, 그 실제 발행물로 설치·갱신 경로를 다시 확인하는 것이다. 공개 전환은 사용자의 개발 완료 후 공개 방침과 대조해야 하며 현재 비공개 설정을 유지한다. 전체 완료를 선언하지 않는다.

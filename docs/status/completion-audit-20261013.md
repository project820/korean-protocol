# 전체 목표의 완료 여부를 점검했다

`a6f9186`의 코드와 규약을 기준으로 전체 목표의 완료는 입증되지 않았다. 기능 대응 49/53개와 자동 테스트 222개는 각각 설계 대응과 구현 검사의 증거이며 전체 언어 성능을 대신하지 않는다. GitHub 저장소는 비공개이고 `v0.2.0-preview.4`는 초안이다.

## 바로 진행할 규범 보완을 정한다

KP-KO-001의 현재 조건은 조사 없는 명사 연쇄에 한정된다. 조사가 이미 있는 문장을 고칠 때도 행위자·대상·수신자·도구·장소의 역할을 유지한다는 조건을 명시해야 한다. 명료한 생략을 허용하는 예외는 유지하며 주체나 이유를 무조건 덧붙이지 않는다.

[현재 규칙 재검토](../../evaluation/korean-current-20261013/review.json)는 의미 기대값 30개를 모두 인정하되, 전용 규칙의 직접 적용은 28개 통과·2개 미확인으로 구분했다. 이는 전용 규칙 기준의 최소 24칸 중 22칸을 뒷받침하며, 과거 검토 점수를 덮어쓴 결과가 아니다. 원본 해시 9개와 중복 없는 사례 30개, 집계를 확인했다.

규칙을 바꾸면 상세 규범·컴파일된 프로필·규약 본문과 연결된 4.2·4.5 기능 검토를 함께 재확인한다. 이전 파일 해시에 묶인 검토나 실제 모델 실행을 새 규칙의 검증으로 옮겨 적지 않는다. 현재 코딩 프로필은 28,627바이트이므로 28KiB 상한을 지키면서 의미 중복을 줄여야 한다.

정식 키와 게시 경로의 선택은 운영 연결을 막지만 위 규범 보완을 막지 않는다. 전체 목표를 배포 도구의 완성만으로 축소하거나 완료로 표시하지 않는다.

# 0.7.0의 제공 범위와 남은 검증을 점검한다

0.7.0은 설치 도구와 공개 다운로드를 제공하는 연구·개발 초안이며 전체 언어 효과를 검증한 완성 규격은 아니다. 원본 `0.7.0-draft`, 서명 콘텐츠 `0.7.0·순번 3`, 엔진 `0.2.0`의 상태를 구분한다.

| 요구 | 제공한 결과와 근거 | 남은 검증 |
| --- | --- | --- |
| 전체 체계를 제공한다. | [목차](../spec/toc.md)와 [체계](../spec/architecture.md)는 규칙·사전·용례·평가·배포를 연결한다. | 실제 분야의 적용 범위와 독자 효과를 별도로 확인해야 한다. |
| 한국어 규칙·예외·용례를 제공한다. | [규칙 원본](../../specification/rules.json)의 72개 규칙과 [작성자 사례](../../examples/rule-cases.json) 296개를 제공한다. | 작성자 사례를 독립 평가로 세지 않으며 한국어 전문가 자문과 실제 독자 시험은 남아 있다. |
| 통제 어휘를 제공한다. | [사전](../spec/lexicon.md)은 기본 159뜻·분야 34뜻과 작성자 사례 454개를 제공한다. | 실제 분야 전체의 의미 사용 충족률은 측정하지 않았다. |
| STE 기능 대응을 확인한다. | [현재 대응표](../../specification/ste-crosswalk.json)는 설계 49개·검증 0개·부분 4개다. 설계 대응률은 92.45%다. | 현행 원본으로 독립 기능 검토를 다시 수행해야 하며 검증 90% 목표는 미달이다. |
| 실제 출력의 의미와 구조를 확인한다. | [V7 검증](v7-verification.md)은 현재 설치 프로필의 단일 보고서를 의미 보존·구조 부분 충족으로 판정했다. | 독립 입력·반복 실행·여러 모델·실제 독자에서의 개선은 입증하지 않았다. |
| 지속 설치와 갱신을 제공한다. | [공개 서명 발행](../distribution/public-0.7.0-verification.md)과 두 호스트의 실제 HTTPS 갱신을 기록했다. | [호스트 지원표](../distribution/host-support.md)의 실제 확인 범위를 넘어 적용을 보장하지 않는다. |
| 사용자가 받을 패키지를 제공한다. | [v0.7.0 릴리스](https://github.com/project820/korean-protocol/releases/tag/v0.7.0)는 ZIP·채팅용 규약·체크섬을 공개했다. | 미서명 패키지의 체크섬과 서명 콘텐츠의 게시자 인증을 구분해야 한다. |

## 출시 원본과 검사 근거를 고정한다

서명 콘텐츠의 원본은 `67f537e`이며 사용자 패키지의 설치 도구·안내 원본은 `7e01d53`이다. 일곱 콘텐츠 파일은 두 원본에서 동일하다. [출시 기준 CI](https://github.com/project820/korean-protocol/actions/runs/38676135546)는 macOS·Linux 검사를 통과했고 [공개 파일 점검](../maintenance/repository-inventory.md)은 익명 다운로드와 보관 복구 결과를 기록한다.

저장소 main의 후속 문서 개정은 기존 `v0.7.0` ZIP·채팅용 파일·체크섬을 바꾸지 않는다. ZIP의 안내는 그 발행 원본을 기준으로 읽고 현재 운영 상태는 [요구사항과 검증 상태](requirements.md)에서 확인한다.

이전 257개 규칙 사례·49/53 독립 기능 검토·미게시 상태는 당시 개발 단계의 기록이다. [연혁](chronology-20261013.md)과 [연구 근거](research-evidence.md)에 남기며 현재 수치나 미해결 배포 항목으로 옮겨 쓰지 않는다.

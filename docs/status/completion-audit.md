# 목표의 완료 근거를 대조한다

현재 결과는 검토 가능한 연구·개발 초안이다. 기능 대응률만으로 전체 목표가 완료됐다고 판정하지 않는다.

| 사용자 요구 | 현재 근거 | 판정과 남은 확인 |
| --- | --- | --- |
| ASD-STE100 수준의 체계와 전체 목차를 설계한다. | [목차](../spec/toc.md)와 [체계](../spec/architecture.md)에 규범·사전·용례·평가·배포 구조가 연결돼 있다. | 구조 설계와 연결을 작성했다. 규격의 현장 성숙도까지 입증한 것은 아니다. |
| 한국어에 맞는 규칙·예외·용례를 제공한다. | [규칙](../spec/korean-rules.md)에 72개 규칙을 기록했고 작성 사례 257개를 검토했다. 별도 [독립 사례 31개](../../evaluation/korean-independent/report.md) 중 30개가 검토를 통과했다. | 최소 정상·오용·유지 사례는 연결했으나 일부 구문의 전용 규칙 조건은 더 검토해야 한다. 전문가 자문과 사람 독해 검증은 남았다. |
| 통제 어휘 사전 구조를 제공한다. | [사전](../spec/lexicon.md)에 뜻·활용·결합·분야·상태를 정의했고 193개 뜻과 작성 사례 454개를 제공한다. | 구조와 JSON Schema 검사가 통과했다. [별도 합성 문맥 40개](../../evaluation/lexicon-independent/report.md)의 직접 뜻 연결은 19개였다. 실제 분야 전체의 충족률은 측정하지 않았다. |
| STE의 90% 수준에 대응한다. | [대응 검토](../../evaluation/functional-review.json)에 49/53개 기능 대응과 파일 해시를 기록했다. | 작성 기능의 설계 대응률 92.45%를 확인했다. 전체 규격의 90% 성숙도나 언어 성능으로 해석하지 않는다. |
| LLM이 명료하고 오해 없이 표현하도록 한다. | [정제 프로필 평가](../../evaluation/llm/rule-refinement-20261012/report-ko.md)에 입력·프로필·출력·평정을 보존했다. | 재사용 편집 26개·생성 12개는 의미를 보존했고 생성 2개에 간결성 보완점이 남았다. 과거 [평정 이견](../../evaluation/llm/permission-adjudication.md)을 보존하며 일반 효능은 주장하지 않는다. |
| 한 번 설치한 뒤 지속적으로 사용한다. | [현재 ZIP 설치 시험](../distribution/preview-package-smoke.json)에서 저장소 밖에 푼 런타임으로 설치했고 실제 Codex loader가 현재 규칙 72개를 읽었다. | 해당 환경의 로딩과 오프라인 유지가 통과했다. 다른 기기·클라우드·호스트의 자동 적용을 보장하지 않는다. |
| 자동 업데이트를 제공한다. | [런타임 구현](../distribution/implementation-status.md)에 서명 확인·적용·복구·고정·시작 시 갱신과 예약 파일 생성을 기록했다. | 실제 게시자 키·공개 HTTPS 릴리스 운영·예약 등록은 연결 전이다. 테스트용 서버 검증과 실제 운영을 구분한다. |

## 다음 작업의 순서를 정한다

허락을 의무로 바꾸는 실제 변형과 제한 명령형의 문맥상 해석을 구분해야 한다. 같은 입력을 사용한 제한된 반복은 재현성 진단으로 기록하고 새 독립 평가로 계산하지 않는다. 제한적 명령형이 항상 새로운 의무를 만든다고 가정하지 않고 문맥상 허락과 선택 가능성이 유지되는지 판정한다.

설치기의 관리 블록은 활성 캐시의 절대 경로를 기록한다. 프로필 안의 사전 상대 경로와 결합해 실제 사전 파일을 찾을 수 있는지 확인해야 하며, 파일의 존재만으로 모델이 사전을 모두 읽었다고 판정하지 않는다.

이번 확장은 아직 커밋·푸시하지 않았다. 게시 확인은 사용자 AGENTS.md의 커밋 사전 확인 지침에 따른다. 게시 승인이 없어도 로컬 진단과 검증은 진행할 수 있으므로 현재 목표를 승인 대기만으로 중단하지 않는다.

[사전 개발 재점검](../../evaluation/lexicon-refinement-20261012/report.md)은 변경된 뜻 다섯 개를 재대조한 뒤 33/40 연결을 유지했다. 최초 독립 점수 19/40과 원본 10개 파일을 보존했으며, 재사용 입력의 개발 수치를 새 독립 효과로 주장하지 않는다. Sol 서비스 제한 뒤 Opus/high 요청으로 재점검을 마쳤다.

[후속 HTTPS 실행](../distribution/https-transport-verification.md)은 Python 3.11의 임시 CONNECT 프록시에서 16단계를 통과했다. 서명된 콘텐츠의 수동·호스트 시작 자동 갱신, 잘못된 CA·서명 거부, 서버 중단 뒤 정상본 유지를 확인했다. 직접 443 바인딩, 공개 릴리스 운영, 예약 등록의 성공으로 확대하지 않는다.

# 요구사항과 검증 상태

## 2026-10-15 V7 r2를 채택한다

현재 원본은 0.7.0-draft이며 공개 콘텐츠는 0.7.0·순번 3이다. 사용자는 제시된 KP V7 이전 보완(r2)을 읽기 좋은 안으로 선택했고 더 짧게 만든 r3는 가독성 때문에 채택하지 않았다. [채택 기록](../../experiments/v7/adoption.md)은 대상·선택지·조건·수량·기한의 배치 규칙과, 원문보다 짧아야 한다는 기준을 두지 않는다는 결정을 기록한다.

[0.7.0 발행·갱신 기록](../distribution/public-0.7.0-verification.md)은 공개 HTTPS의 정식 게시자 서명과 콘텐츠 7개 해시를 확인했다. 별도 Codex·Claude Code 서명 설치 두 개는 0.3.0에서 갱신했고 기존 로컬 sandbox 설치 두 개는 관리 도구와 콘텐츠를 함께 갱신했다. 새 전역 설치나 예약 작업은 만들지 않았다.

연혁에 보존한 0.3.0의 테스트 수·기능 대응 점수·모델 평가는 당시 해시에 대한 기록이며 0.7.0의 현재 검증 결과가 아니다. 규칙 원본이 바뀐 항목의 기능 대응 상태는 `specification/ste-crosswalk.json`에서 다시 검토해야 한다. 사용자 채택으로 V7 실험의 의미 변경·미확정 결과를 지우지 않으며 언어 효과와 독자 이해의 일반적인 개선을 주장하지 않는다.

## 현재 규약의 검증 범위를 구분한다

| 구분 | 확인 범위 |
| --- | --- |
| 채택 | V7 r2의 구조 규칙을 0.7.0-draft에 반영한다. 원문보다 짧게 만들 것을 요구하지 않는다. |
| 기능 대응 | 규칙·규범의 해시가 바뀌면 이전 독립 검토를 현재 검증 점수로 사용하지 않는다. 현행 대응표의 상태와 실제 검사 결과를 함께 확인한다. |
| 언어 효과 | 사용자 선택과 개발 문서의 모델 검토를 독립적인 의미 보존·독자 이해 검증으로 확대하지 않는다. |
| 배포 | 0.7.0·순번 3의 공개 서명 발행과 두 호스트의 실제 HTTPS 갱신을 확인했다. 기존 로컬 설치 갱신은 미서명 신뢰 상태를 유지한 별도 결과다. |
| 엔진 호환 | 콘텐츠 0.7.0은 엔진 0.2.0 이상을 요구한다. 프로필 30 KiB·관리 블록 32 KiB의 내부 상한과 별도로 실제 Codex 프로젝트 잔여 예산을 검사한다. 구버전 엔진은 최신 설치 도구로 명시적으로 갱신한다. |

[V7 검증 기록](v7-verification.md)은 통합 테스트 376개, 정책 표현의 복원 검토, 실제 설치용 프로필의 단일 보고서 실행을 구분한다. 실제 출력은 의미 보존·구조 부분 충족으로 판정됐다.

## 이전 근거를 찾는다

[2026-10-13까지의 개발·발행 연혁](chronology-20261013.md)은 기존 기록을 보존한다. 당시 0.3.0의 기능 대응 49/53, 자동 테스트 361개, 공개 발행과 두 임시 호스트의 업그레이드는 해당 버전과 해시의 결과다. 현재 V7에 대한 성공 증거로 합산하지 않는다. [연구·검증 근거 모음](research-evidence.md)은 이전 README의 상세 평가 링크를 제공한다.

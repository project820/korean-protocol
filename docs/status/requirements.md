# 0.7.0의 요구사항과 검증 상태

현재 원본은 **0.7.0-draft**, 공개 서명 콘텐츠는 **0.7.0·순번 3**, 관리 엔진은 **0.2.0**이다. 사용자용 [v0.7.0 릴리스](https://github.com/project820/korean-protocol/releases/tag/v0.7.0)는 설치 도구·안내 원본 `7e01d53`에서 만든 오프라인 ZIP·채팅용 파일·체크섬을 제공한다.

V7은 사용자가 선택한 **이전 보완본 r2**를 채택했다. 대상·선택지·조건·수량·기한을 찾기 쉽게 배치하며 원문보다 짧아야 한다는 기준은 두지 않는다. 더 짧게 만든 r3는 채택하지 않았다. [채택 기록](v7-adoption.md)은 이 결정과 고정 실험본의 한계를 구분한다.

## 현재 소스의 수치와 근거를 확인한다

| 구분 | 0.7.0 기준 상태와 근거 |
| --- | --- |
| 규칙 | [규칙 원본](../../specification/rules.json)은 72개이며 모두 `proposed`다. [작성자 사례](../../examples/rule-cases.json)는 296개다. |
| 사전 | [기본 사전](../../lexicon/core.json) 159뜻과 [분야 사전](../../lexicon/domains/software.json) 34뜻을 합쳐 193뜻이다. [어휘 작성자 사례](../../examples/lexicon-cases.json)는 454개다. |
| 기능 대응 | [현행 대응표](../../specification/ste-crosswalk.json)는 `designed` 49개·`verified` 0개·`partial` 4개·`unmapped` 0개다. 설계 대응률은 49/53(92.45%), 검증 대응률은 0/53이다. |
| 언어 효과 | [V7 단일 보고서 실행](v7-verification.md)은 의미 보존·구조 부분 충족으로 판정됐다. 실제 독자 비교시험과 일반화 효과는 확인하지 않았다. |
| 서명 배포 | [0.7.0 발행 기록](../distribution/public-0.7.0-verification.md)은 정식 게시자 서명·콘텐츠 7개 해시·두 호스트의 실제 HTTPS 갱신을 기록한다. |
| 사용자 패키지 | [공개 다운로드](../distribution/preview-package.md)는 미서명 ZIP·채팅용 파일·체크섬을 제공한다. 체크섬은 파일 동일성 확인용이며 게시자 인증을 대신하지 않는다. |
| 코드 검사 | [제품 출시 기준 CI](https://github.com/project820/korean-protocol/actions/runs/38676135546)는 Linux·macOS 검사를 통과했다. 테스트는 설치·배포 구현의 검사이며 언어 효과의 점수가 아니다. |
| 엔진 호환 | 콘텐츠 0.7.0은 엔진 0.2.0 이상을 요구한다. 프로필 30 KiB·관리 블록 32 KiB의 내부 상한과 실제 Codex 프로젝트의 잔여 지침 예산을 별도로 검사한다. |

V7 채택으로 규칙·규범의 해시가 바뀌어 이전 49개 독립 기능 검토는 현재 검증 점수에서 제외했다. 0.3.0의 49/53 검증과 모델 평가는 [과거 근거 모음](research-evidence.md)에 보존하며 위 수치에 합산하지 않는다.

## 설치와 남은 검증을 구분한다

별도 Codex·Claude Code 서명 시험 설치 두 개는 0.3.0에서 0.7.0으로 실제 HTTPS 갱신을 완료했다. 기존 로컬 sandbox 설치 두 개는 관리 도구와 콘텐츠를 함께 갱신했고 미서명 신뢰 상태를 유지했다. 해당 실행에서는 새 전역 설치나 예약 작업을 만들지 않았다. 설치·예약 갱신의 지원 범위는 [호스트 지원표](../distribution/host-support.md)를 따른다.

현재 기능 대응을 `verified`로 올리려면 현행 규칙·사례·상세 규범을 대상으로 독립 검토를 다시 수행해야 한다. 실제 LLM 출력의 의미 보존과 독자 이해 효과는 별도 평가로 확인해야 한다. 사용자 채택과 배포 성공만으로 이 두 검증을 완료 처리하지 않는다.

이 문서는 저장소 main의 현행 안내다. `v0.7.0`의 ZIP과 첨부 파일은 `7e01d53` 기준의 고정 발행물이며 이후 main의 문서 수정이 자동 반영되지 않는다. [완료 점검](completion-audit.md)과 [문서 목차](../README.md)에서 근거별 범위를 확인한다.

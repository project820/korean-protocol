# V7의 정책·코드·실제 출력을 구분해 검증했다

0.7.0은 사용자가 선택한 V7 r2 구조를 채택한다. 정책 대응·설치 코드·단일 모델 출력은 서로 다른 검증 결과다. [기계 판독 기록](v7-verification.json)은 범위·수치·현재 프로필 해시를 기록한다.

## 규칙의 조건과 예외를 대조했다

72개 규칙의 요구사항·적용 조건·예외를 고정 r2와 대조했다. 설치용 표현 34개에서 발견한 의미·범위 누락 28건과 추가 한정어 4건을 복원했다. 후속 독립 검토는 복원을 확인했으며 새로 보고할 의미 손실을 찾지 못했다. 각 설치용 표현의 원본 해시 34개도 일치했다. 해시는 검토 대상의 동일성을 확인하며 의미 동등성을 자동으로 입증하지 않는다.

설치 프로필은 30,137바이트다. 의미를 더 축약해 이전 한도에 맞추지 않고 내부 프로필 상한을 30KiB, 관리 블록 상한을 32KiB로 정했다. 실제 Codex 프로젝트의 남은 지침 예산은 별도로 검사하며 설정을 자동으로 늘리지 않는다. 새 콘텐츠는 엔진 0.2.0을 요구한다.

## 코드와 설치 경계를 검사했다

`python3 -B -m unittest discover -s tests -p 'test_*.py'`로 통합 테스트 376개가 통과했다. 독립 보안 검토의 집중 검사 224개는 통합 검사와 겹치므로 합산하지 않는다. 다운로드 임시 파일 누적과 오프라인 문서 링크 결함을 수정했다. 자세한 범위와 한계는 [보안 감사](../security/v7-audit.md)와 [독립 검토](../security/v7-independent-review.md)를 따른다.

실제 구버전 엔진은 새 manifest를 받고 본문 다운로드 전에 호환 오류를 반환했으며 설치된 콘텐츠를 보존했다. 최신 관리 도구를 사용하는 두 호스트의 TEST 서명 이관에서는 설정·사용자 본문·캐시·롤백·제거를 확인했다. 이 시험을 실제 게시자 서명이나 공개 배포 성공으로 표시하지 않는다.

## 같은 실전 보고서로 한 번 실행했다

제공 원문 7,970자에 현재 설치용 프로필을 적용해 Opus 5.5 medium으로 한 번 실행했다. 출력은 8,499자이며 본문을 수동 수정하거나 재시도하지 않았다. 요청·응답·모델·동결 프로필의 무결성 검사를 통과했다.

생성 모델과 규약 이름을 가린 전체 원문·출력을 Sol high가 검토했다. 의미 보존 판정을 받았지만 구조는 부분 충족이었다. 대상별 표·조건·점검 목록은 분리됐으며 일부 대상의 여러 속성은 긴 문단에 남았다. 이 결과를 모든 모델의 준수나 독자 이해도 향상으로 확대하지 않는다.

실전 원문과 출력은 공개하지 않는다. 입력은 설계에 재사용한 사례이며 독립적인 일반화 시험이 아니다. 외부 사실의 정확성은 이번 변환 시험에서 재조사하지 않았다.

## 공개 배포와 로컬 갱신은 별도로 확인한다

공개 서명 발행과 실제 로컬 갱신은 아직 진행 전이다. 완료 후 발행 커밋·실행·manifest 해시와 설치 결과를 별도 기록으로 연결한다.

# 평가 기록의 버전과 범위를 확인한다

이 디렉터리는 평가 당시 입력·프로필·출력·판정과 해시를 보존한다. 보고서의 ‘현재’, ‘최종’, ‘통과’는 해당 실행의 기준본에 대한 표현이며 최신 규약의 성능을 뜻하지 않는다. 현재 버전 v0.8.0 스킬의 비교는 [세션 보고서 비교](session-reports-20261015/README.md)를 따른다. 기존 v0.7.0 상시 규약의 확인 범위는 [검증 상태](../docs/status/requirements.md)와 [V7 검증 기록](../docs/status/v7-verification.md)을 따른다.

## STE 대조군을 필수로 포함한다

**KP의 최종 품질 평가는 원문·KP 적용본·STE 적용본의 1:1:1 비교를 필수로 한다.** 규약 버전·모델·추론 설정을 바꾸는 실험에도 같은 규칙을 적용한다. STE 없는 결과는 부분 진단이며 비교 완료나 최종 합격의 근거로 쓰지 않는다.

1. **입력과 기준을 고정한다.** 원문, KP 프로필, STE 프로필, STE 자료의 출처·판본·적용 규칙, 한국어 적용 방법, 공통 작업 요청, 모델·추론 설정, 반복 횟수와 합격 기준을 생성 전에 기록한다. 프롬프트와 해시를 보존하며, 출처를 확인하지 못한 규칙을 STE 규칙으로 단정하지 않는다.
2. **각 적용본을 독립 생성한다.** KP와 STE에 동일 원문·모델·추론 설정·공통 작업 요청·반복 횟수를 사용한다. 두 조건의 작성 프로필만 바꾸고, 상대 출력·평가 정답·이전 대화·KP 상시 지침을 주입하지 않는다. KP 출력으로 STE 적용본을 만들지 않는다. 원문은 수정하지 않은 사용자 자료나 별도의 미적용 생성 결과로 고정한다.
3. **두 적용본을 같은 기준으로 검증한다.** 의미·조건·수치·행위자·의무·확실성 보존을 원문과 양방향으로 대조한다. 대상 목록화, 핵심 판단·제약의 선행 배치, 조건별 묶음, 시간 기산점·기한·예외, 독립 속성 분리와 중복도 각각 확인한다. 분량은 동일한 계수 방식으로 비교한다.
4. **원시 출력과 근거를 함께 보여 준다.** 세 칼럼을 원문·KP·STE로 구성한다. 여러 모델·설정을 전환할 때는 대응하는 KP·STE 쌍을 함께 확인할 수 있게 한다. 오류가 있는 출력도 교정하지 않고 보존하며, 판정은 해당 원문·출력의 문구나 행을 인용한다.
5. **누락된 비교를 완료로 처리하지 않는다.** STE 실행이 없거나 실패했거나 입력·설정이 맞지 않으면 최종 비교는 미완료다. 부분 진단과 실행 성공은 따로 기록할 수 있지만, 전체 품질 합격·향상·모델 대체 가능성으로 확대하지 않는다. 최종 수락에는 두 적용본의 원문 보존 검사와 KP의 구조 기준 충족을 확인하고, STE 대비 남은 격차를 명시한다.

STE는 필수 대조군이지만 변환 출력 자체가 정답은 아니다. STE 출력도 의미를 바꾸거나 조건을 누락하면 실패로 기록한다. 한국어 실험 적용본은 **‘STE 원칙의 한국어 실험 적용본’**으로 표시하며 공식 한국어판·인증된 준수 결과로 부르지 않는다. 짧은 문장이나 목록이 있다는 이유만으로 STE 준수를 주장하지 않는다.

이 정책은 사용자가 명시적으로 변경하기 전까지 유지한다. 과거 STE 없는 실행의 원시 기록과 당시 판정은 보존하되, 현재 평가에서는 부분 진단으로만 인용한다. 이 문서의 절차 규칙은 기존 러너가 세 비교군을 자동으로 강제한다는 뜻은 아니다. 러너가 필요한 비교군을 생성하지 못하면 별도 STE 실행을 준비하고, 완료 전까지 미완료 상태를 유지한다.

## 고정 입력과 현재 원본을 구분한다

`baselines/`, `before/`, `final-refresh-before/`, `inputs-snapshot/`, `instructions-snapshot/`와 각 실행의 고정 프로필은 당시 입력이다. 그 안의 설치 안내·지침·버전을 최신 안내로 바꾸지 않는다. `report`, `plan`, `final` 등의 파일명은 실행의 역할을 나타내며 최신 버전 표시가 아니다.

과거 검사를 재현할 때는 [재현 안내](../docs/status/historical-verification.md)에 따라 기준본을 지정한다. 해시 불일치가 나면 입력을 최신 파일로 바꾸어 과거 결과를 통과시키지 않는다. 실제 출력·판정의 보존과 현재 규약의 재검증은 별도 작업이다.

## 0.7 문서 개정에서 평가 원본을 보존한다

이 디렉터리의 보고서·계획·지침·스냅샷은 작성 당시 증거다. [0.3 준비 manifest](release-0.3.0-20261013/before-manifest.json)의 `frozen_model_evaluation_files`는 그중 Markdown 156개의 경로와 해시를 고정한다. 이 목차는 현재 안내로 갱신하지만 평가 원문에는 0.7 지침이나 상태 표시를 삽입하지 않는다. 설치 안내가 필요한 독자는 [INSTALL.md](../INSTALL.md)를 사용한다.

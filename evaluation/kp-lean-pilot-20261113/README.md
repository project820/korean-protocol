# 사용자 판독으로 후보 5를 채택했다

이 기록은 진단용 파일럿이다. 원문·KP·STE 정식 비교는 미완료다.

후보 5는 사용자가 비교 화면을 직접 읽고 2026-11-13에 채택했다. 모델 검토의 수락 기준을 통과한 결과로 채택한 것이 아니다.

## 조건

- **사례:** 5개. P1 전원 차단 절차(새 글), P2 공조 견적 보고(재작성), P3 작업 결과 보고(새 글), P4 설비 점검 보고(재작성, r60 개발 사례 D02), P5 냉각수 필터 교체 절차(새 글, 후보 3부터 추가).
- **모델:** gpt-6.1-sol, gpt-6.1-terra, anthropic/claude-sonnet-5-5, xai/grok-4.7. 추론 강도 medium, 반복 1회.
- **대조군:** kp는 v0.10.1 `SKILL.md`, ste는 `evaluation/clarity-20261016-r60/ste.md`다. 모든 후보와 같은 모델·요청으로 독립 생성했다.
- **검토:** gpt-6-astra high가 kp·후보·ste 세 출력을 가려서 판정했다.

L2는 비교·흐름·상태·관계를 표와 Mermaid로 보여주는 출력 단계다. L1~L4는 아래와 같다.

- **L1:** 기본값이다. L2~L4 조건 밖의 글에 쓰고, 산출물은 KP 문단·목록·절차다.
- **L2:** 같은 속성의 세 항목 이상 비교, 분기·병렬·순환, 상태 변화, 구성 요소의 관계에 쓴다. 산출물은 L1 본문과 표·Mermaid 도식이다.
- **L3:** 변수 조작·상태 전환이 이해에 필요하거나, 사용자가 인터랙티브 출력을 요청할 때 쓴다. 산출물은 외부 의존성 없는 `index.html` 하나다.
- **L4:** 사용자가 영상화·애니메이션 코드를 명시 요청할 때만 쓴다. 산출물은 Manim 코드, 장면별 한국어 내레이션 대본, 발화만 담은 TTS 입력이다.

L3 HTML에서 지킬 규칙 다섯 가지는 아래와 같다. 위치는 모두 **4A**의 **L3 하한**이다.

1. HTML·CSS·JavaScript는 파일 하나에 둔다. CDN, 외부 글꼴, 네트워크 호출은 쓰지 않는다. `lang="ko"`와 viewport를 둔다. (1항)
2. 화면과 DOM 순서는 제목, 대상·범위, 결과 패널, 입력 패널, 규칙·산출식, 참고다. 제목은 ‘한다’ 문장 하나다. (3항)
3. 입력 초기값은 원자료 값으로 채워 첫 화면에 결과를 보인다. 입력이 바뀌면 결과를 바로 다시 계산한다. 계산 버튼은 두지 않는다. (4항)
4. 원자료가 범주로 나눈 조건은 선택지로 둔다. 2~4개는 라디오, 5개 이상은 `select`, 원자료의 수치는 숫자 입력으로 쓴다. 원자료에 없는 수치 변수는 만들지 않는다. 모든 입력에 `label`을 잇는다. (5항)
5. 자료 문자열은 `innerHTML` 대신 `textContent`로 넣는다. 잘못된 입력은 그 입력 곁에 오류를 보이고 결과를 보류한다. 결과 영역에 `aria-live="polite"`를 둔다. (7항)

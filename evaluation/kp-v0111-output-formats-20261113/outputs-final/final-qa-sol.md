## L1~L4: 각각 한 줄

- **L1:** 기본 단계로, KP 기준에 맞춘 문단·목록·절차를 작성한다.
- **L2:** 세 항목 이상의 동일 속성 비교나 흐름·상태 변화·구성 관계를 표·Mermaid 도식으로 표현한다.
- **L3:** 변수 조작·상태 전환이 이해에 필요하거나 인터랙티브 출력을 요청하면, 단일 `index.html`을 만든다.
- **L4:** 영상화·애니메이션 코드를 명시적으로 요청할 때만 Manim 코드와 내레이션·TTS 입력을 작성한다.

**근거:** 4A 「독자가 이해하는 데 필요한 출력 형식을 선택한다」의 출력 단계 표.

## L3 HTML 작성 시 필수 규칙 다섯 개

1. **작성 전에 지정 파일을 읽는다.**  
   `references/interactive-html.md`와 `assets/interactive-explainer.html`을 읽는다. 읽을 수 없으면 L3 하한을 따른다.  
   **근거:** 4A 출력 단계 표와 표 바로 앞 문장.

2. **외부 의존성 없이 파일 하나로 만든다.**  
   HTML·CSS·JavaScript를 한 파일에 둔다. CDN·외부 글꼴·네트워크 호출을 쓰지 않는다. `lang="ko"`와 viewport를 둔다.  
   **근거:** 4A 「L3 하한」 1번.

3. **화면과 DOM을 지정된 순서로 구성한다.**  
   제목 → 대상·범위 → 결과 패널 → 입력 패널 → 규칙·산출식 → 참고 순서다. 제목은 ‘한다’ 문장 하나로 쓴다.  
   **근거:** 4A 「L3 하한」 3번.

4. **첫 화면부터 결과를 보여 주고 입력 변경에 즉시 반응한다.**  
   초기값은 원자료 값으로 채운다. 입력이 바뀌면 결과를 바로 다시 계산한다. 계산 버튼은 두지 않는다.  
   **근거:** 4A 「L3 하한」 4번.

5. **제출 전에 지정 검사 스크립트를 실행한다.**  
   `scripts/check_html.py`를 실행한다. 수행하지 않은 검사를 완료로 표시하지 않는다.  
   **근거:** 4A 「L3 하한」 8번, 5절 「제출 전에 조용히 양방향으로 대조한다」.

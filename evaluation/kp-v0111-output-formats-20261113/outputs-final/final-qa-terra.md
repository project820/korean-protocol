## KP 출력 단계

- **L1:** 기본 단계로, KP 문단·목록·절차를 작성한다.
- **L2:** 세 항목 이상의 비교나 흐름·상태 변화·구성 요소의 관계를 표 또는 Mermaid 도식으로 보여 준다.
- **L3:** 변수 조작이나 상태 전환이 이해에 필요하거나 인터랙티브 출력을 요청받으면 `index.html` 하나로 작성한다.
- **L4:** 영상화나 애니메이션 코드를 명시적으로 요청받으면 Manim 코드와 한국어 내레이션 대본, TTS 입력을 작성한다.

## L3 HTML 규칙 다섯 개

1. **파일을 읽는다.** 작성 전에 HTML 지침과 재사용 예제를 읽는다. 파일을 읽을 수 없으면 L3 하한으로 작성한다.  
   출처: **4A 출력 단계 표와 표 아래 안내**

2. **외부 의존성을 없앤다.** HTML·CSS·JavaScript를 한 파일에 담고, CDN·외부 글꼴·네트워크 호출을 쓰지 않는다. `lang="ko"`와 viewport를 둔다.  
   출처: **4A L3 하한 1항**

3. **화면을 정해진 순서로 쌓는다.** 제목, 대상·범위, 결과 패널, 입력 패널, 규칙·산출식, 참고 순서로 화면과 DOM을 구성한다.  
   출처: **4A L3 하한 3항**

4. **결과를 즉시 계산한다.** 원자료 값으로 입력 초기값을 채워 첫 화면에 결과를 보인다. 입력이 바뀌면 바로 다시 계산하며, 계산 버튼은 두지 않는다.  
   출처: **4A L3 하한 4항**

5. **입력 오류와 접근성을 처리한다.** 잘못된 입력은 해당 입력 곁에 오류를 보이고 결과를 보류한다. 결과 영역에는 `aria-live="polite"`를 둔다.  
   출처: **4A L3 하한 7항**

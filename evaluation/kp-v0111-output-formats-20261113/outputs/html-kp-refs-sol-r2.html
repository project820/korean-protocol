회의실 예약 취소 조건에 따른 처리 흐름을 확인한다

확정된 예약의 취소 시점과 대기 조건을 선택하면 처리 흐름을 표시한다.

선택 조건에 따른 처리

시스템이 다음 순번 대기자에게 자동으로 안내한다.

조건: 이용 시간 24시간 전까지 취소하고, 남은 대기자가 있다.

    안내받은 대기자는 안내받은 시점으로부터 4시간 이내에 응답해야 한다.

    취소·대기 조건

    확정된 예약의 취소 시점
    남은 대기자
    자동 안내를 받은 대기자의 응답

    자동 안내 대상 대기자가 있을 때 적용한다.

    처리 규칙

    이용 시간 24시간 전까지 취소
    시스템이 대기자 명단의 다음 순번에게 자동으로 안내한다.
    자동 안내를 받은 대기자
    안내받은 시점으로부터 4시간 이내에 응답해야 한다.
    4시간 이내 미응답
    그다음 대기자에게 안내가 넘어간다.
    이용 24시간 이내 취소

    자동 안내는 발송되지 않는다.

    총무팀이 직접 판단해 처리한다.

    남은 대기자 없음
    해당 시간대가 일반 예약으로 다시 열린다.

    취소 시점의 선택 기준

    원문의 시간 범주를 그대로 선택지로 사용한다.

    제공된 원문에는 정확히 24시간 전의 경계 처리 기준이 명시되지 않았다.

    초기 선택
    원문에서 먼저 설명한 조건을 초기 선택으로 둔다.

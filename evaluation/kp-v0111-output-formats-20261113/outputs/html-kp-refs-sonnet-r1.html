회의실 예약 취소 후 대기자 안내 경로를 확인한다

취소 시점과 대기자 상태를 바꾸면 처리 경로를 다시 보여 준다.

처리 경로

취소 조건

취소 시점
대기자 명단

자동 안내 경로에서 대기자 명단을 따른다.

현재 안내받은 대기자가 응답하지 않은 경우의 경과 시간이다. 0~48시간을 0.5시간 단위로 입력한다. 가정: 이 입력 범위는 화면 탐색용이다.

경과 시간을 0~48시간 범위에서 0.5시간 단위로 입력해야 한다.

처리 규칙

조건처리
예약이 확정된 사람이 이용 시간 24시간 전까지 취소한다.시스템이 자동으로 대기자 명단의 다음 순번에게 안내를 보낸다.
안내를 받은 대기자가 안내받은 시점으로부터 4시간 이내에 응답한다.원문은 응답 이후의 처리를 밝히지 않는다.
안내를 받은 대기자가 그 시간 안에 응답하지 않는다.그다음 대기자에게 안내가 넘어간다.
이용 24시간 이내에 취소한다.자동 안내가 가지 않는다. 총무팀이 직접 판단해서 처리한다.
남은 대기자가 없다.해당 시간대가 일반 예약으로 다시 열린다.

참고

  • 이용 24시간 이내 취소에서 남은 대기자가 없을 때의 처리는 원문에 구분이 없다. 화면은 두 규칙을 함께 표시한다.
  • 입력값을 서버에 전송하거나 저장하지 않는다.

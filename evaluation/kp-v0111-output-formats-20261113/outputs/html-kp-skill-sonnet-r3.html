취소 시점에 따라 대기자 안내 처리를 확인한다.

대상: 확정된 회의실 예약의 취소

결과

    입력

    대기자 상태

    규칙

    • 이용 시간 24시간 전까지 취소하면 시스템이 대기자 명단의 다음 순번에게 자동으로 안내를 보낸다.
    • 안내를 받은 대기자는 안내를 받은 시점으로부터 4시간 이내에 응답한다.
    • 그 시간 안에 응답하지 않으면 안내가 그다음 대기자에게 넘어간다.
    • 이용 24시간 이내에 취소하면 자동 안내가 가지 않고 총무팀이 직접 판단해서 처리한다.
    • 남은 대기자가 없으면 해당 시간대가 일반 예약으로 다시 열린다.

    참고

    • 정확히 24시간 전 취소는 "24시간 전까지"에 해당하는 것으로 입력을 처리한다. 이는 가정이다.
    • 원문은 이용 24시간 이내 취소 시 남은 대기자가 없을 때의 처리를 밝히지 않는다.

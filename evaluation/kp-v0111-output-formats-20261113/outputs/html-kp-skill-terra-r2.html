회의실 예약 취소 후 처리 방법을 안내한다

대상·범위: 확정된 회의실 예약의 취소와 대기자 안내

처리 결과

시스템이 대기자 명단의 다음 순번에게 안내를 보낸다.

안내를 받은 대기자는 안내를 받은 시점부터 4시간 이내에 응답해야 한다. 그 시간 안에 응답하지 않으면 그다음 대기자에게 안내가 넘어간다.

조건 선택

취소 시점
남은 대기자

처리 규칙

  • 확정된 예약을 이용 시간 24시간 전까지 취소하면 시스템이 다음 순번 대기자에게 자동으로 안내한다.
  • 안내를 받은 대기자는 안내를 받은 시점부터 4시간 이내에 응답해야 한다. 응답하지 않으면 그다음 대기자에게 안내가 넘어간다.
  • 이용 24시간 이내에 취소하면 자동 안내가 가지 않는다. 총무팀이 직접 판단해 처리한다.
  • 남은 대기자가 없으면 해당 시간대가 일반 예약으로 다시 열린다.

참고

취소 시점과 남은 대기자 여부를 선택하면 해당 조건의 처리 내용을 볼 수 있다.

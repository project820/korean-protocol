회의실 예약 취소

이용 시간 24시간 전까지 취소

예약이 확정된 사람이 이용 시간 24시간 전까지 예약을 취소하면, 시스템이 자동으로 대기자 명단의 다음 대기자에게 안내를 보낸다.

안내를 받은 대기자는 안내를 받은 시점부터 4시간 이내에 응답해야 한다.

대기자가 4시간 이내에 응답하지 않으면, 시스템이 그다음 대기자에게 안내를 보낸다.

이용 시간 24시간 이내에 취소

예약이 확정된 사람이 이용 시간 24시간 이내에 예약을 취소하면, 시스템은 자동으로 안내를 보내지 않는다.

이 경우 총무팀이 직접 판단하고 처리한다.

남은 대기자가 없는 경우

대기자 명단에 남은 대기자가 없으면, 해당 시간대는 일반 예약으로 다시 열린다.

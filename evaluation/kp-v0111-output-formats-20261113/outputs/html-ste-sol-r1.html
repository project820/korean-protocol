회의실 예약 취소와 대기자 안내

취소 시점에 따른 처리

이용 시간 24시간 전까지 취소한 경우

예약이 확정된 사람이 이용 시간 24시간 전까지 취소하면, 시스템이 대기자 명단의 다음 순번에게 자동으로 안내를 보냅니다.

이용 시간 24시간 이내에 취소한 경우

자동 안내는 발송되지 않습니다.

총무팀이 직접 판단하여 처리합니다.

안내를 받은 대기자의 응답

안내를 받으면, 안내를 받은 시점부터 4시간 이내에 응답하세요.

4시간 이내에 응답하지 않으면, 시스템이 그다음 대기자에게 안내를 보냅니다.

남은 대기자가 없는 경우

해당 시간대가 일반 예약으로 다시 열립니다.

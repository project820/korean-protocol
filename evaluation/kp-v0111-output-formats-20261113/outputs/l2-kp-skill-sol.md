# 회의실 예약 취소 및 대기자 안내

## 취소 시 처리 기준

| 조건 | 처리 |
|---|---|
| 예약 확정자가 이용 시간 24시간 전까지 취소 | 시스템이 대기자 명단의 다음 순번에게 자동으로 안내한다. |
| 이용 24시간 이내에 취소 | 자동 안내를 보내지 않는다. 총무팀이 직접 판단해 처리한다. |
| 남은 대기자가 없음 | 해당 시간대가 일반 예약으로 다시 열린다. |

## 대기자 응답 기준

- **응답 기한:** 안내받은 대기자는 안내받은 시점부터 4시간 이내에 응답해야 한다.
- **기한 내 미응답:** 그다음 대기자에게 안내가 넘어간다.

L2는 같은 속성을 가진 항목을 비교하거나, 분기·병렬·순환·상태 변화·구성 요소 관계를 보여줄 때 쓰는 단계다. 산출물은 L1 본문에 표와 Mermaid 도식을 더한 글이다.

- **L1:** 기본값이다. L2~L4 조건 밖의 글이며, 산출물은 KP 문단·목록·절차다.
- **L2:** 세 항목 이상의 비교, 분기·병렬·순환이 있는 흐름, 상태 변화, 구성 요소의 관계에 쓴다. 산출물은 L1 본문과 표·Mermaid 도식이다.
- **L3:** 변수 조작·상태 전환이 이해에 필요하거나 인터랙티브 출력을 요청할 때 쓴다. 산출물은 외부 의존성 없는 `index.html` 하나다.
- **L4:** 영상화·애니메이션 코드를 명시 요청할 때만 쓴다. 산출물은 Manim 코드, 장면별 한국어 내레이션 대본, 발화만 담은 TTS 입력이다.

L3 HTML에서 꼭 지킬 규칙 다섯 가지는 모두 **4A**의 **L3 하한**에 있다.

1. HTML·CSS·JavaScript는 파일 하나에 두고, CDN·외부 글꼴·네트워크 호출은 쓰지 않는다. `lang="ko"`와 viewport를 둔다. (L3 하한 1)
2. 화면과 DOM은 같은 순서로 쌓는다. 순서는 제목, 대상·범위, 결과 패널, 입력 패널, 규칙·산출식, 참고다. (L3 하한 3)
3. 입력 초기값은 원자료 값으로 채워 첫 화면에 결과를 보인다. 입력이 바뀌면 바로 다시 계산하고, 계산 버튼은 두지 않는다. (L3 하한 4)
4. 원자료가 범주로 나눈 조건은 선택지로 둔다. 2~4개는 라디오, 5개 이상은 `select`, 수치는 숫자 입력으로 쓰고, 모든 입력에 `label`을 잇는다. (L3 하한 5)
5. 자료 문자열은 `innerHTML` 대신 `textContent`로 넣는다. 잘못된 입력은 그 입력 곁에 오류를 보이고 결과는 보류한다. 결과 영역에는 `aria-live="polite"`를 둔다. (L3 하한 7)

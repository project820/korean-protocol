L2는 같은 속성의 비교, 분기·병렬·순환, 상태 변화, 구성 요소 관계를 L1 본문에 표와 Mermaid 도식으로 보여주는 단계다.

- **L1:** 기본값이며, L2~L4 조건 밖의 글을 KP 문단·목록·절차로 쓴다.
- **L2:** 세 항목 이상의 같은 속성 비교나 흐름·상태·구성 관계는 L1 본문과 표·Mermaid 도식으로 쓴다.
- **L3:** 변수 조작·상태 전환이 필요하거나 인터랙티브 출력을 요청하면 외부 의존성 없는 `index.html` 하나를 만든다.
- **L4:** 영상화·애니메이션 코드를 명시 요청할 때만 Manim 코드, 장면별 한국어 내레이션 대본, 발화만 담은 TTS 입력을 만든다.

L3 HTML에서 지킬 규칙 다섯 가지는 모두 **4A**의 **L3 하한**에 있다.

1. HTML·CSS·JavaScript를 파일 하나에 두고, CDN·외부 글꼴·네트워크 호출을 쓰지 않으며, `lang="ko"`와 viewport를 둔다. (L3 하한 1)
2. 입력 초기값은 원자료 값으로 채워 첫 화면에 결과를 보이고, 입력이 바뀌면 바로 다시 계산하며, 계산 버튼은 두지 않는다. (L3 하한 4)
3. 범주 조건은 선택지로 두고, 2~4개는 라디오, 5개 이상은 `select`, 수치는 숫자 입력으로 쓰며, 모든 입력에 `label`을 잇는다. (L3 하한 5)
4. 자료 문자열은 `textContent`로 넣고, 잘못된 입력은 그 곁에 오류를 보여 결과를 보류하며, 결과 영역에 `aria-live="polite"`를 두고, 초기화 버튼은 하나만 둔다. (L3 하한 7)
5. 밝은 배경 테마 하나로 만들고, 320px 폭에서 한 열로 바뀌게 하며, 제출 전에 `scripts/check_html.py`를 실행한다. (L3 하한 8)

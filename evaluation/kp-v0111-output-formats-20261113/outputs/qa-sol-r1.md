## L1~L4

- **L1:** 기본 단계로, KP 문단·목록·절차를 작성한다. — **4A 출력 단계 표**
- **L2:** 비교·흐름·상태 변화·구성 요소의 관계를 L1 본문과 표·Mermaid 도식으로 나타낸다. — **4A 출력 단계 표**
- **L3:** 변수 조작·상태 전환이 이해에 필요하거나 인터랙티브 출력을 요청하면, 외부 의존성 없는 `index.html` 하나를 만든다. — **4A 출력 단계 표**
- **L4:** 영상화·애니메이션 코드를 명시 요청할 때만 Manim 코드를 작성한다. 장면별 한국어 내레이션과 발화만 담은 TTS 입력도 제공한다. — **4A 출력 단계 표**

## L3 HTML 필수 규칙 다섯 가지

1. **HTML·CSS·JavaScript를 파일 하나에 둔다.**  
   CDN·외부 글꼴·네트워크 호출을 쓰지 않는다. `lang="ko"`와 viewport를 둔다.  
   **위치:** 4A → L3 하한 → 1번

2. **화면과 DOM을 같은 순서로 쌓는다.**  
   제목 → 대상·범위 → 결과 패널 → 입력 패널 → 규칙·산출식 → 참고 순서다. 제목은 ‘한다’ 문장 하나로 쓴다. 대상·범위는 한 줄로 쓴다.  
   **위치:** 4A → L3 하한 → 3번

3. **첫 화면에 원자료 초기값과 결과를 보인다.**  
   입력이 바뀌면 결과를 바로 다시 계산한다. 계산 버튼은 두지 않는다.  
   **위치:** 4A → L3 하한 → 4번

4. **입력 형식을 원자료의 조건에 맞춘다.**  
   원자료가 범주로 나눈 조건은 선택지로 둔다. 선택지 2~4개는 라디오, 5개 이상은 `select`로 쓴다. 수치는 숫자 입력으로 쓰고, 모든 입력에 `label`을 잇는다.  
   **위치:** 4A → L3 하한 → 5번

5. **결과의 조건·경고·가정을 결과 패널 안에 펼쳐 둔다.**  
   원자료에 없는 값과 범위는 ‘가정’으로 표시한다.  
   **위치:** 4A → L3 하한 → 6번

## L3 HTML 필수 규칙 다섯 가지

1. **HTML·CSS·JavaScript를 파일 하나에 둔다.**  
   CDN·외부 글꼴·네트워크 호출을 쓰지 않는다. `lang="ko"`와 viewport를 둔다.  
   **위치:** 4A → L3 하한 → 1번

2. **화면과 DOM을 같은 순서로 쌓는다.**  
   제목 → 대상·범위 → 결과 패널 → 입력 패널 → 규칙·산출식 → 참고 순서다. 제목은 ‘한다’ 문장 하나로, 대상·범위는 한 줄로 쓴다.  
   **위치:** 4A → L3 하한 → 3번

3. **원자료 값을 초기값으로 채워 첫 화면에 결과를 보인다.**  
   입력이 바뀌면 결과를 바로 다시 계산한다. 계산 버튼은 두지 않는다.  
   **위치:** 4A → L3 하한 → 4번

4. **결과에 걸린 조건·경고·가정을 결과 패널 안에 펼쳐 둔다.**  
   원자료에 없는 값과 범위는 ‘가정’으로 표시한다.  
   **위치:** 4A → L3 하한 → 6번

5. **밝은 배경 테마 하나로 만든다.**  
   320px 폭에서 한 열로 바뀌게 한다. 제출 전에 `scripts/check_html.py`를 실행한다.  
   **위치:** 4A → L3 하한 → 8번

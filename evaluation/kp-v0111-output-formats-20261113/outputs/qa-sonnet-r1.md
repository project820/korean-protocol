KP의 L2는 같은 속성을 가진 세 항목 이상의 비교, 분기·병렬·순환이 있는 흐름, 상태 변화, 구성 요소의 관계를 보여 줄 때 쓰는 출력 단계다. 산출물은 L1 본문에 표나 Mermaid 도식을 더한 것이다. 작성 전에 `references/output-formats.md`의 L2 절을 읽는다. 지침 4A의 단계 표에 나온다.

## L1~L4 한 줄 정리

- **L1:** 기본값이다. 다른 세 단계의 조건 밖에 있는 글을 KP 문단·목록·절차로 쓴다.
- **L2:** L1 본문에 표나 Mermaid 도식을 더해 비교, 흐름, 상태 변화, 구성 관계를 보인다.
- **L3:** 변수 조작이나 상태 전환이 이해에 필요하거나 사용자가 인터랙티브 출력을 요청하면, 외부 의존성 없는 `index.html` 하나를 만든다.
- **L4:** 사용자가 영상화·애니메이션 코드를 명시 요청했을 때만 쓴다. Manim 코드, 장면별 한국어 내레이션 대본, 발화만 담은 TTS 입력을 만든다.

## L3 HTML 필수 규칙 5개

모두 4A의 "L3 하한" 목록에 있다.

1. **파일 하나, 외부 의존 없음, 기본 속성.** HTML·CSS·JavaScript를 한 파일에 둔다. CDN·외부 글꼴·네트워크 호출을 쓰지 않는다. `lang="ko"`와 viewport를 둔다. (L3 하한 1번)
2. **화면 순서.** 화면과 DOM을 제목, 대상·범위, 결과 패널, 입력 패널, 규칙·산출식, 참고 순으로 쌓는다. 제목은 '한다' 문장 하나로 쓴다. (L3 하한 3번)
3. **초기값과 즉시 계산.** 입력의 초기값을 원자료 값으로 채워 첫 화면에 결과를 보인다. 입력이 바뀌면 바로 다시 계산하고, 계산 버튼은 두지 않는다. (L3 하한 4번)
4. **안전한 입력 처리.** 자료 문자열은 `innerHTML` 대신 `textContent`로 넣는다. 잘못된 입력은 그 입력 곁에 오류를 보이고 결과를 보류한다. 결과 영역에는 `aria-live="polite"`를 둔다. 모든 입력에는 `label`을 잇는다. (L3 하한 5번과 7번)
5. **제출 전 점검.** 밝은 배경 테마 하나로 만들고, 320px 폭에서 한 열로 바뀌게 한다. 제출 전에 `scripts/check_html.py`를 실행한다. (L3 하한 8번)

이 규칙들은 지침에서 읽은 내용을 옮긴 것이다. 실제 파일이나 스크립트는 아직 열거나 실행하지 않았다.

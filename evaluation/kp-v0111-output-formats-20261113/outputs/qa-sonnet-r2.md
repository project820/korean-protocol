KP에서 L2는 4A 표가 정한 출력 단계의 하나다. 같은 속성을 가진 세 항목 이상의 비교, 분기·병렬·순환이 있는 흐름, 상태 변화, 구성 요소의 관계를 다룰 때 쓴다. 산출물은 L1 본문에 표나 Mermaid 도식을 더한 것이다. 작성 전에 `references/output-formats.md`의 L2 절을 읽어야 한다. 이 절을 읽지 못하면 4A의 L2 하한으로 쓴다. 지금은 해당 파일을 읽지 않았다.

**L1~L4 한 줄 요약** (출처: 4A 표)

- **L1:** 기본값이다. 다른 세 단계의 조건 밖에 있는 글을 KP 문단·목록·절차로 쓴다.
- **L2:** 비교, 흐름, 상태 변화, 구성 관계를 L1 본문과 표·Mermaid 도식으로 쓴다.
- **L3:** 변수 조작이나 상태 전환이 이해에 필요하거나 인터랙티브 출력을 요청받았을 때, 외부 의존성 없는 `index.html` 하나를 만든다.
- **L4:** 사용자가 영상화·애니메이션 코드를 명시 요청했을 때만 Manim 코드, 장면별 한국어 내레이션 대본, 발화만 담은 TTS 입력을 쓴다.

**L3 HTML 필수 규칙 5개** (출처: 4A의 "L3 하한")

1. **파일 하나, 외부 의존 없음.** HTML·CSS·JavaScript를 파일 하나에 둔다. CDN·외부 글꼴·네트워크 호출을 쓰지 않는다. `lang="ko"`와 viewport를 둔다. (L3 하한 1번)
2. **화면과 DOM의 순서.** 제목(한다 문장 하나), 대상·범위 한 줄, 결과 패널, 입력 패널, 규칙·산출식, 참고 순으로 쌓는다. (L3 하한 3번)
3. **초기값과 즉시 계산.** 입력 초기값을 원자료 값으로 채워 첫 화면에 결과를 보인다. 입력이 바뀌면 바로 다시 계산하며 계산 버튼은 두지 않는다. (L3 하한 4번)
4. **조건·가정의 표시.** 결과에 걸린 조건·경고·가정은 결과 패널 안에 펼쳐 둔다. 원자료에 없는 값과 범위는 '가정'으로 표시한다. (L3 하한 6번)
5. **안전한 입력·출력 처리.** 자료 문자열은 `innerHTML` 대신 `textContent`로 넣는다. 잘못된 입력은 그 입력 곁에 오류를 보이고 결과를 보류한다. 결과 영역에 `aria-live="polite"`를 둔다. (L3 하한 7번)

제출 전에는 `scripts/check_html.py`를 실행해야 한다(L3 하한 8번). 위 5개 외에 입력 선택지 규칙, 초기화 버튼 규칙, 밝은 테마, 320px 한 열 규칙도 같은 하한에 있다.

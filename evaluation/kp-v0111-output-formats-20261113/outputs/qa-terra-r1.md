## KP 출력 단계

- **L1:** 기본 단계로, KP 기준에 따른 문단·목록·절차를 쓴다.
- **L2:** 같은 속성을 가진 세 항목 이상의 비교나 분기·상태 변화·구성 요소 관계에 표 또는 Mermaid 도식을 쓴다.
- **L3:** 변수 조작이나 상태 전환이 이해에 필요하거나 인터랙티브 출력을 요청받으면 `index.html` 하나를 만든다.
- **L4:** 영상화·애니메이션 코드를 명시 요청받으면 Manim 코드와 한국어 내레이션 대본, TTS 입력을 만든다.

## L3 HTML 규칙 다섯 가지

1. **단일 파일:** HTML·CSS·JavaScript를 한 파일에 두고, CDN·외부 글꼴·네트워크 호출을 쓰지 않는다. `lang="ko"`와 viewport를 둔다.  
   출처: **4A, L3 하한 1**

2. **화면 순서:** 화면과 DOM을 제목, 대상·범위, 결과 패널, 입력 패널, 규칙·산출식, 참고 순으로 쌓는다.  
   출처: **4A, L3 하한 3**

3. **초기값과 계산:** 입력 초기값을 원자료 값으로 채워 첫 화면에 결과를 보인다. 입력이 바뀌면 결과를 바로 다시 계산하며, 계산 버튼은 두지 않는다.  
   출처: **4A, L3 하한 4**

4. **입력 요소:** 범주형 조건은 선택지로 둔다. 선택지가 2~4개면 라디오, 5개 이상이면 `select`를 쓰고, 수치는 숫자 입력으로 받는다. 모든 입력에 `label`을 잇는다.  
   출처: **4A, L3 하한 5**

5. **오류와 접근성:** 잘못된 입력은 해당 입력 곁에 오류를 보이고 결과를 보류한다. 결과 영역에는 `aria-live="polite"`를 둔다.  
   출처: **4A, L3 하한 7**

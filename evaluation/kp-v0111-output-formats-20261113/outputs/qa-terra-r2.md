## 출력 단계

- **L1:** 기본 단계로, KP 문단·목록·절차를 작성한다.
- **L2:** 세 항목 이상의 비교나 흐름·상태 변화·구성 요소의 관계를 보여줄 때, L1 본문에 표나 Mermaid 도식을 더한다.
- **L3:** 변수 조작이나 상태 전환이 이해에 필요하거나 인터랙티브 출력을 요청받으면, 외부 의존성이 없는 `index.html` 하나를 만든다.
- **L4:** 영상화나 애니메이션 코드를 명시적으로 요청받으면, Manim 코드와 한국어 내레이션 대본, TTS 입력을 만든다.

## L3 HTML 필수 규칙 5개

| 규칙 | 지침 위치 |
|---|---|
| HTML·CSS·JavaScript를 파일 하나에 두고, CDN·외부 글꼴·네트워크 호출을 쓰지 않는다. `lang="ko"`와 viewport를 둔다. | 4A절 **L3 하한 1** |
| 재사용 예제의 골격과 스타일에서 시작하고, 예제의 수치·가정·문구를 작업 자료로 바꾼다. | 4A절 **L3 하한 2** |
| 입력 초기값을 원자료 값으로 채워 첫 화면에 결과를 보인다. 입력이 바뀌면 즉시 다시 계산하며, 계산 버튼은 두지 않는다. | 4A절 **L3 하한 4** |
| 결과에 걸린 조건·경고·가정을 결과 패널 안에 펼쳐 둔다. 원자료에 없는 값과 범위는 ‘가정’으로 표시한다. | 4A절 **L3 하한 6** |
| 잘못된 입력은 입력 곁에 오류를 보이고 결과를 보류한다. 결과 영역에는 `aria-live="polite"`를 둔다. | 4A절 **L3 하한 7** |

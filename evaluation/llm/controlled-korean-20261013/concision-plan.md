# 군더더기 보완 후 재실행과 새 확인 표본을 분리한다

three-way-plan.md의 세 조건·동일 모델·같은 공개 프롬프트·격리·평정 원칙을 유지한다. 앞선 24개 비교에서 모든 조건의 의미와 구조는 통과했지만 KP의 군더더기 없음은 17/24에 그쳤다. 새 12개의 총 글자 수는 미적용 1554, KP 1549, STE 원칙 1490으로 KP의 분량 감소가 충분하지 않았다. Opus가 입력 전체 반복·명칭 통일 과정·중복 경계/양태·번호로 명확한 선후 반복을 줄이는 규칙을 보완했다. 서명 코드나 사전은 이 규범 개정으로 변경하지 않았다.

기존 두 묶음 24개의 KP만 새 프로필로 재실행하고, 미적용과 STE 원출력은 그대로 재사용한다. 그 결과는 개발 회귀이며 새 독립 표본으로 계산하지 않는다. 원래 프로필·원출력·계획·평정은 덮어쓰지 않는다. 부모 통합 검토는 추가 금지문을 '요청과 무관한' 내용으로 한정해 답에 필요한 사실 자체를 금지하지 않도록 했다.

confirmation의 12개는 규약·프로필·출력을 보지 않은 작성자의 새 합성 표본이다. 이 묶음의 미적용/KP/STE 세 조건을 모두 새로 실행한다. 최종 KP는 concise-profile.md로 고정한다. 출력의 문자 수와 군더더기는 의미·과제·조건/역할 보존과 별도 지표다. 모든 의미를 남긴 가장 짧은 정답을 수학적으로 증명하는 시험은 아니다. 의미나 행동에 필요한 반복은 허용한다.

새 확인 표본에서 필수 의미·과업·구조 실패가 없고 기본 문체·명시 장르·인용 예외가 유지되는지 확인한다. 분량 결과가 동률이거나 STE보다 길면 그대로 기록한다. 길이를 줄이기 위해 정보를 누락하거나 미상 사실을 채우지 않는다. 한 모델의 단일 배치 결과와 평가자의 편집 판단은 일반 독자 이해도·공식 STE 동등성·보편 효능 증거가 아니다.

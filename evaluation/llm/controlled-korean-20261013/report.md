# 압축 문체를 실제 출력으로 비교했다

이번 보완은 로컬 후보에 적용했다. 공개 Pages의 서명 콘텐츠는 바꾸지 않았다. [36개 실제 출력](comparison.html)을 미적용·Korean Protocol·STE 원칙의 한국어 적용 순서로 비교할 수 있다. 표의 문장은 모델 출력 그대로다.

## 규약을 보완했다

72개 규칙 중 17개의 내용과 53개의 반복 안내를 정돈했고, 작성 사례를 260개에서 291개로 늘렸다. Opus가 문체·규약을 보완했고 별도 Sol 검토자가 규범과 기능 대응을 검토했다.

- 뜻이 완전한 상태는 `표기된 담당자 없음.`처럼 짧게 쓴다. `표기된`을 지워 실제 담당자 부재로 바꾸지 않는다.
- 역할과 의미를 하나로 복원할 수 있으면 주어·조사·지시 표현을 생략한다. 대조·책임·조건은 남긴다.
- 새 설명·보고는 높임말 없이 쓴다. 인용, 기존 문체, 명시적으로 요청한 높임말은 보존한다.
- 한 명칭으로 같은 대상을 가리키고, 요청한 답과 행동부터 쓴다. 불필요한 서문·작성 과정·반복 설명을 줄인다.
- 짧게 줄여도 검증 상태, 가능성·허락·의무, 전체 적용 조건과 동시 행동은 보존한다.

[표현 규약](../../../docs/spec/control-expression.md)과 [국립국어원·STE 원문 조사](../../../research/2026-10-13-ellipsis/research-note.md)에 생략의 근거와 한계를 기록했다. 이번 쟁점에는 1차 규범 자료를 사용했다. 동료심사 논문이나 독자 실험으로 이 규약의 효능을 입증한 것은 아니다.

## 같은 입력을 격리 실행했다

요청 모델은 OpenCodex 경유 `gpt-6.1-sol`, 추론 설정은 `high`다. 각 실행은 별도 임시 홈·프로젝트에서 12개 입력을 처리했다. 미적용에는 규약과 사전을 제공하지 않았고, KP에는 고정 프로필과 사전을 제공했다. STE 조건에는 KP와 별도로 작성한 한국어 STE 원칙 지침만 제공했다. 실제 상위 제공 모델과 자동 대체 여부는 CLI에서 확인되지 않아 요청값과 구분한다.

STE 조건은 공식 영문 ASD-STE100 적합성 시험이 아니다. 영어 사전·관사·단어 수 기준을 한국어에 그대로 적용하지 않았다. 한국어에 옮겨 적용한 작성 원칙을 비교한 것이다.

최초 미적용·기존 규약·초기 보완 규약 실행과 후속 수정의 모든 원본을 보존했다. 이전 압축 규약은 ck01에서 효과 검증 미실시를 빠뜨렸다. 해당 실행의 의미 보존은 35/36이었다. 이를 통과로 바꾸지 않고 일반 규칙에 검증 상태 보존을 추가했다. 마지막에는 KP 36개를 모두 다시 실행했고, 변경하지 않은 미적용·STE 출력은 재사용했다.

세 묶음은 각 12개다. 마지막 묶음도 보완 과정에서 재사용했으므로 최종 36개는 새로운 독립 표본이 아니다. 출력 36개를 독립적인 모델 실행 36회로 계산하지 않는다. 한 조건의 12개 출력은 한 배치에서 생성됐다.

## 출력 분량을 측정했다

| 입력 묶음 | 미적용 | 보완 KP | STE 원칙 |
| --- | ---: | ---: | ---: |
| 최초 12개 | 1,779자 | 1,358자 | 1,671자 |
| 추가 12개 | 1,554자 | 1,344자 | 1,490자 |
| 확인용 12개를 재사용했다 | 1,051자 | 1,009자 | 1,070자 |
| 36개를 합산했다 | 4,384자 | 3,711자 | 4,231자 |

공백·문장부호를 포함한 유니코드 문자 수다. KP는 미적용보다 15.4%, STE 원칙 조건보다 12.3% 짧았다. 토큰 비용·읽기 시간·이해도 개선을 뜻하지 않는다. [선택 실행과 측정값](verified-selected-runs.json)에 원본 경로를 연결했다.

| 같은 요청에 대한 실제 출력 | 미적용 | 보완 KP | STE 원칙 |
| --- | --- | --- | --- |
| 당첨자를 답한다 | 행운권 추첨 당첨자는 조한별입니다. | 조한별이 당첨됐다. | 행운권 추첨의 당첨자는 조한별이다. |
| 선정 결과를 답한다 | 겨울길의 심사 결과는 선정입니다. | 겨울길은 선정됐다. | 겨울길의 심사 결과는 선정이다. |

최종 KP의 추가 12개 배치는 제공된 사전을 실제로 조회했다. 나머지 선택 실행은 도구 호출이 없었다. 조회 경로는 허용된 두 사전 안에 있었다. 사전 제공·조회만으로 사전 전체의 효능을 주장하지 않는다.

## 조건명을 가리고 의미와 과업을 검토했다

별도 검토자는 규약·조건 대응표를 읽지 않고 고정된 입력·판정 기준·세 출력을 검토했다. [평정 기록](verified-blind-ratings.json)과 [조건 대응표](verified-condition-key.json)를 분리했다.

| 판정 | 미적용 | 보완 KP | STE 원칙 |
| --- | ---: | ---: | ---: |
| 필수 의미를 보존했다 | 36/36 | 36/36 | 36/36 |
| 요청한 과업을 수행했다 | 35/36 | 36/36 | 36/36 |
| 구조 조건을 충족했다 | 36/36 | 36/36 | 36/36 |
| 명백히 무관한 설명이 없었다 | 34/36 | 36/36 | 34/36 |

미적용 ck07은 담당자가 불명확하다는 사실은 유지했지만 필요한 두 확인 질문을 하지 않았다. 의미 보존과 과업 수행을 분리했다. 앞선 평정과 불필요한 설명의 판단 범위가 다르므로 평정 점수의 변화를 개선량으로 계산하지 않는다. 마지막 평정의 간결성 통과는 중복이 전혀 없거나 가능한 최단문이라는 뜻이 아니다.

## 구현과 설치를 검증했다

`python3 -B -m unittest discover -s tests`는 352개 모두 통과했다. 규약 컴파일, 배포 문서 링크, 다운로드·종료·복구, 설정 전환을 포함한다. `git diff --check`도 통과했고 미서명 후보 ZIP을 생성했다.

공개 서명 콘텐츠를 두 임시 호스트에 설치한 뒤 OFF, 같은 버전 원격 확인, ON, 높임말 전환, 제거를 실제 실행했다. OFF가 유지됐고 캐시 내용·수정 시각과 원래 호스트 파일을 보존했다. 해당 실행 중 새 Python 충돌 보고서는 없었다. [실행 기록](control-smoke.json)을 보존했다. 구버전 예약 작업의 설정 이관은 모의 시험으로 검증했으며 이번 수정에서 실제 launchd 등록은 수행하지 않았다.

최종 규약도 별도 Codex·Claude Code 임시 폴더에 미서명 설치했다. [후보 설치 기록](candidate-sandbox.json)에 경로와 해시를 기록했다. 전역 홈·공개 배포는 변경하지 않았다. 현재 대화의 이미 읽은 지침을 파일 OFF만으로 삭제할 수 없으므로 미적용 시험은 항상 새 프로세스에서 실행한다.

## 남은 한계를 기록했다

49/53은 작성 기능의 설계 대응 검토 결과다. 나머지 네 기능은 부분 대응으로 남겼다. LLM 정답률, 한국어학·군사 전문가 검증, 공식 STE 적합성을 뜻하지 않는다.

반복 표현이 완전히 사라지지는 않았다. 예를 들어 kh02의 번호 절차는 앞 단계 완료를 다음 문장에서 다시 설명한다. 최종 후보를 STE 수준의 완성본으로 판정하지 않는다. 새로 고정한 입력과 실제 독자의 이해·수행 정확도 시험이 다음 검증 대상이다.

## 후속 격리 감사의 제한을 반영한다

[사용자 스킬 탐색 감사](../isolation-20261013.md)에서 CODEX_HOME 분리만으로 사용자 스킬의 메타데이터가 제외되지는 않는다는 점을 확인했다. 이 보고서의 선택 실행에는 외부 스킬 읽기가 관측되지 않았지만, 사용자 스킬까지 제거한 기준선이라고 주장하지 않는다. 기존 원출력과 평정은 그대로 보존한다.

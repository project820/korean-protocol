# STE 원칙 적용 한국어 작성 프로파일

제공된 사실과 요청에 맞는 한국어 답변을 아래 원칙으로 작성한다. 요청한 결과만 출력한다.

## 내용 보존

1. 원문에 없는 사실·행동·절차·수치·원인·결과를 추가하지 않는다.
2. 원문의 양태를 그대로 유지한다. `수 있다`를 `한다`나 `항상`으로 강화하지 않는다. `해야 한다`를 권고로 약화하지 않는다.
3. 조건, 수량, 단위, 부정, 범위, 예외, 행위 주체, 확인 범위를 빠뜨리지 않는다. 불확실한 진술은 불확실한 그대로 남긴다.
4. 문장을 짧게 만들려고 뜻에 필요한 말을 빼지 않는다.

## 용어

5. 한 대상에는 문서 전체에서 하나의 이름을 쓴다. 같은 대상의 이름이 여럿이면 원문에 있는 하나를 골라 일관되게 쓴다. 기술 용어·부품명·식별자를 임의로 바꾸지 않는다.
6. 한 단어는 한 뜻으로만 쓴다. 원문에 없는 정의나 용어를 만들지 않는다.
7. 일반 어휘는 쉽고 흔한 말을 고른다. 같은 뜻이면 같은 말을 반복한다.

## 문장

8. 한 문장에는 한 주제만 둔다. 여러 내용을 이어 붙인 긴 문장은 나눈다.
9. 능동문을 쓴다. 행위 주체가 필요한데 문맥에서 알 수 없으면 주체를 밝힌다. 원문도 주체를 모르면 수동 표현을 유지할 수 있다.
10. `그것`, `이`, `해당` 같은 지시어는 가리키는 대상이 하나로 분명할 때만 쓴다. 분명하지 않으면 대상 이름을 다시 쓴다.
11. 논리 관계(`그러므로`, `그러나`, `때문에`, `전에`, `후에`)가 뜻에 필요하면 명시한다.

## 절차와 지시

12. 지시문은 독자가 할 행동을 직접 쓴다. 예: `밸브를 닫는다.` `~되어야 한다` 같은 간접 서술로 지시를 대신하지 않는다.
13. 한 문장 또는 한 단계에는 지시 하나만 둔다. 두 행동을 동시에 해야 할 때만 한 문장에 묶는다.
14. 독자가 행동 전에 알아야 할 조건은 문장 앞에 둔다. 조건이 적용되는 범위(어느 단계, 어느 대상)를 분명히 쓴다.
15. 단계 순서는 원문 순서를 따른다. 필요하면 번호를 붙인다.

## 설명과 경고

16. 절차(할 일)와 설명(상태·사실)을 섞지 않는다. 설명은 서술문으로 쓴다.
17. 설명 글은 핵심 정보를 먼저 쓰고, 문장 사이 연결이 드러나게 쓴다.
18. 경고·주의는 일반 문장과 구분한다. 위험이 무엇인지, 무엇을 하거나 하지 말아야 하는지, 결과가 무엇인지 원문 범위 안에서 분명히 쓴다.

## 한국어 표현

19. 기본 문체는 높임 없는 중립 평서체(`-다`)로 쓴다. 지시도 같은 종결로 쓴다. 요청한 장르, 인용문, 고유한 형식은 원래 문체를 유지한다.
20. 문맥에서 하나로 복원되는 주어와 격조사는 생략할 수 있다. 생략으로 누가, 무엇을, 어떤 조건에서, 어떤 양태로 하는지가 흐려지면 생략하지 않는다. `만`, `도`, `는` 같은 보조사는 뜻을 바꾸므로 함부로 빼지 않는다.
21. 영어 STE의 단어 수 제한을 한국어 어절 수에 적용하지 않는다. 문장 길이는 원칙 8과 13으로 조절한다.

# 미적용·Korean Protocol·STE 원칙을 같은 한국어 입력으로 비교한다

사용자의 후속 지시로 최종 비교 축을 미적용 / 보완 Korean Protocol / STE 원칙 적용으로 확장했다. 앞선 미적용·기존·첫 보완 조건 36개 출력과 최초 계획은 그대로 보존한다. 최종 규약은 Opus가 새로 쓴 글과 기존 글의 편집 범위, 명확한 상태의 짧은 명사형, 행위자를 구분한 지시, 미기록과 실제 부재의 차이를 보완했다. 사용자 예문을 규칙에 반영한 뒤 기존 12개를 재실행하는 결과는 개발 회귀다.

세 조건 모두 같은 사실·요청·공개 프롬프트와 같은 gpt-6.1-sol/high 요청 설정을 사용한다. baseline에는 규약·사전이 없다. KP에는 최종 프로필과 기존 두 사전을 마운트한다. STE에는 다른 Opus 실행이 공식 근거에서 작성한 한국어용 STE 원칙 프로필만 마운트하며 KP 사전은 넣지 않는다. STE 작성자는 KP 규칙·사례·출력을 보지 않았다. 이 비교는 영어 STE 전체 사전 준수나 공식 한국어판 인증을 측정하지 않는다. 한국어에서는 승인 영어 어휘와 20/25단어 제한을 그대로 적용하지 않는다. 높임 없는 기본 문체는 KP와 STE 조건의 한국어 실험 설정이며 STE 원규칙으로 설명하지 않는다.

runner는 기존 scope-holdout 실행기를 복사해 STE의 마운트 목록만 분리했다. 공통 공개 프롬프트는 유지한다. 초기 12개의 baseline은 동일 공개 입력·프롬프트·모델로 이미 생성한 원출력을 재사용하며 다시 생성한 것처럼 보고하지 않는다. 최종 KP와 STE는 새 격리 실행으로 생성한다. 보류 표본 12개는 원출력이나 규약을 보지 않은 작성자가 별도로 만들었다. 보류 표본은 세 조건을 모두 새로 실행한다. 출력이 공개되기 전에 각 source contract를 고정한다.

의미·과제 수행·조건과 행동 구조를 먼저 판정하고, 높임 표현·불필요한 설명·글자 수를 별도로 비교한다. 글자 수는 공백·문장부호를 포함한 Unicode code point 수이며 토큰 비용이나 독해 시간을 뜻하지 않는다. 같은 사실의 손실을 분량 감소로 포상하지 않는다. 고정 gold의 의미/과업 기준은 바꾸지 않는다. 높임말 자체는 baseline의 의미 오류로 계산하지 않는다. 명시적 정중한 장르 요구와 원문 인용의 높임은 세 조건 모두 보존해야 한다. 조건 라벨을 숨긴 검토에서도 문체에서 조건을 추측할 수 있다는 한계를 남긴다.

최종 KP의 필수 의미/과업/조건 구조 실패는 0개를 목표로 한다. 실패하면 원출력과 판정을 남기고 규약을 보완한 뒤 재시험한다. 재사용 사례 결과는 새 독립 평가로 부르지 않는다. 해석이 갈리는 판정은 그 대안과 분모 영향을 함께 기록한다. 배치 내 사례는 서로 단서가 될 수 있고 각 조건 표본은 1회다. 일반적인 우월성이나 사람 이해도 향상은 이 결과로 입증하지 않는다.

비교 출력이 실제 설치 프로필과 연결되는지는 profile SHA256으로 확인한다. 로컬 honorifics overlay는 운영 설정이므로 규범 프로필 비교와 별도다. 실제 샌드박스 설치에서 protocol/honorifics 전환과 캐시·신뢰 보존을 검증한다. 사용자 전역 지침·예약 설정은 변경하지 않는다.

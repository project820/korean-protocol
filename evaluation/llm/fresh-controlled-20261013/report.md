# 새 입력 12개를 세 조건에서 두 번씩 실행했다

미적용·Korean Protocol·STE 원칙의 한국어 적용이 각각 24개 출력에서 의미·과업·명확성 검토를 통과했다. KP만의 정확도 개선은 관측하지 않았다. KP의 합산 글자 수는 미적용보다 12.0% 줄었다. [72개 원출력 비교](comparison.html)를 확인할 수 있다.

## 입력과 정답을 실행 전에 고정했다

Opus/medium에 프로젝트 규칙·사전·기존 출력 접근을 주지 않고 새로운 합성 사례 12개를 작성하게 했다. 로그 부재와 실제 부재, 부분 부정, 조건·예외, 동시 행동, 사동의 역할, 진행 상태, 허락·의무, 시험 범위, 모호한 지시 대상, 인용과 요청된 높임말을 다뤘다. 자연 말뭉치나 실제 전문가가 작성한 자료는 아니다.

별도 Sol 검토자가 출력 생성 전에 공개 입력과 정답만 검토했다. 자동 기록과 수동 기록의 혼동, 아직 전달되지 않은 지시의 완료 추정, 선택 가능한 부가 정보를 필수로 둔 항목을 바로잡았다. [작성 원본](gold-author-original.json), [수정 기록](gold-adjudication.json), [고정 정답](gold.json)을 보존했다. 생성 결과를 보고 정답이나 프로필을 바꾸지 않았다.

[사전 계획](plan.md)은 같은 입력을 조건별 두 번 생성하고 의미·과업 오류가 없어야 한다는 제한된 후보 검사 기준을 고정했다. 각 실행은 새 임시 홈과 프로젝트를 사용했다. 요청 모델은 OpenCodex 경유 `gpt-6.1-sol/high`다. 실제 상위 모델과 자동 대체 여부는 CLI에서 확인되지 않아 요청값으로만 보고한다.

baseline에는 규약·사전을 제공하지 않았고 KP에는 고정 프로필·사전 두 개를, STE 조건에는 별도의 한국어 STE 원칙 지침만 제공했다. 같은 공개 프롬프트와 입력 순서를 사용했다. 여섯 실행은 모두 종료 코드 0과 유효한 출력 구조를 기록했다. 원시 trace에 도구 호출은 없었으므로 사전을 제공한 것과 실제 조회한 것을 구분한다. [동결·출력 해시](verification.json)와 [실행 명령](commands.json)을 보존했다.

## 조건명을 가린 검토 결과를 기록했다

규약과 조건 대응표를 읽지 않은 검토자가 입력·고정 기준·출력을 대조했다. 이름을 바꾼 A/B/C 조건은 두 반복에서 서로 다르게 배정했다. [평정](blind-ratings.json)과 [조건 대응표](condition-key.json)는 별도 파일이다.

| 판정 | 미적용 | KP | STE 원칙 |
| --- | ---: | ---: | ---: |
| 필수 의미를 보존했다 | 24/24 | 24/24 | 24/24 |
| 요청한 과업을 수행했다 | 24/24 | 24/24 | 24/24 |
| 역할·대상·조건·양태가 명확했다 | 24/24 | 24/24 | 24/24 |
| 명백히 무관한 내용을 추가하지 않았다 | 24/24 | 24/24 | 24/24 |
| 1회차의 글자 수를 합산했다 | 1,008 | 862 | 997 |
| 2회차의 글자 수를 합산했다 | 1,027 | 929 | 1,047 |
| 두 회차의 글자 수를 합산했다 | 2,035 | 1,791 | 2,044 |

글자 수는 공백·문장부호를 포함한다. KP는 미적용보다 12.0%, STE 원칙 조건보다 12.4% 짧았다. 토큰 비용·읽기 시간·이해도 향상을 계산한 것은 아니다. 조건별 24개 출력은 12개 사례의 두 번 반복이며 독립 입력 24개나 독립 실행 24회가 아니다.

짧은 상태 칸 nf01의 실제 1회차 출력은 미적용 `실행 여부 미확인(로그 수집 중단)`, KP `10월 1일부터 12일까지 백업 실행 여부 미확인.`, STE 원칙 `실제 백업 실행 여부 미확인`이었다. 세 조건 모두 기록 부재를 실제 미실행으로 바꾸지 않았다. KP가 모든 개별 답에서 가장 짧은 것은 아니다.

## 다음 검증 범위를 남겼다

이번 입력은 프로필을 보완한 뒤 처음 사용했고 두 번 모두 같은 기준으로 판정했다. 반복 두 번으로 모델의 일반적인 신뢰성을 보장하지 않는다. STE 조건은 공식 영문 규격 적합성이 아니라 적용 가능한 작성 원칙의 한국어 구현이다. 별도 모델 검토가 사람의 이해도·작업 성공을 대신하지 않는다.

[논문 검토](../../../research/2026-10-13-ellipsis/controlled-language-papers.md)에 따라 분량·의미 보존·이해 정확도를 분리했다. 이번 결과는 고정된 표본의 명확성 검토이며 실제 독자 시험은 수행하지 않았다. 어휘 항목의 직접 연결률과 생성 출력에서 승인된 뜻으로 사용하는 비율도 다르다. 선언한 분야별 문맥을 고정하고 후자를 검증하는 작업은 남아 있다.

평가 실행기와 배포 검사 `python3 -B -m unittest tests.test_three_way_evaluation tests.test_distribution`는 13개 모두 통과했다. 규약·런타임 코드는 이번 평가에서 바꾸지 않았다. 커밋·공개 배포·전역 사용자 설정 변경도 하지 않았다.

## 후속 격리 감사의 제한을 반영한다

[사용자 스킬 탐색 감사](../isolation-20261013.md)에서 CODEX_HOME 분리만으로 사용자 스킬의 메타데이터가 제외되지는 않는다는 점을 확인했다. 이 보고서의 선택 실행에는 외부 스킬 읽기가 관측되지 않았지만, 사용자 스킬까지 제거한 기준선이라고 주장하지 않는다. 기존 원출력과 평정은 그대로 보존한다.

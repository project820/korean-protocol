# 사전 고정 신규 한국어 출력 평가 계획

기존26개는 원문 편집 과제이므로 사실묶음에서 새 답변을 작성하는 과제를 별도로 검증한다. 새로운12개 입력과 필수 사실·금지 추론·발화목적·간결성 기준을 모델 실행 전에 고정한다. 정답 문장이나 golden exact-match는 사용하지 않는다. 기준은 모델 prompt에 노출하지 않는다. 모든 조건에서 같은 사실과 요청, 순서, JSON envelope를 쓴다. 실제 답변은 각 text 필드의 자연스러운 한국어이며 편집/keep 판단을 요구하지 않는다.

12과제는 결과 보고, 검증범위, 원인 미확인 관측, 조건부 허락, 부정 수량, 동시 절차, 짧은 가능성 경고, 담당자 재량, 수량 비교, 상태 설명, 미확인 대상의 질문, 근거 범위 안의 권고를 포함한다. 실제 실행하지 않은 작업의 완료 보고, 검증/배포 범위 확장, 시간순서의 인과관계 확정, 허락의 명령화, 일부/전체 부정 혼동, 동시성 분리, 독자 재량 침해, 불필요한 추론·설명·추상적 행동을 사례별로 확인한다.

baseline과 수정 후 coding-agent profile은 조건별 한 배치, 한 번씩 실행한다. 기존 편집 baseline은 같은 입력 그대로 참조하여 최종 treatment와 재비교하며 시점차이/반복없음의 한계를 별도로 명시한다. 신규 생성 baseline은 재실행된 신규 생성자료이고 기존 편집자료와 합쳐 하나의 정확도라고 보고하지 않는다. 동일 Sol/high/subscription_router/localhost/임시 HOME·프로젝트/read-only/ephemeral 설정을 사용한다. 최종 profile은 execution 전에 byte snapshot과 SHA256을 고정한다. 최종 upstream/FALLBACK을 CLI가 반환하지 않으면 미확인으로 기록한다.

독립 root 평정자는 condition-key를 읽지 않고 각 사실묶음·요청·criteria와 실제 A/B 출력을 수동 대조한다. 의미 보존, 발화목적 적합성, 명확성, 자연성, 간결성을 각각0~2점으로 평정하고 원문 밖 사실·원인·절차 창작 여부를 기록한다. 의미2는 필수 사실·조건·수량·양태·시점을 전부 유지함,1은 경미한 누락/해석부담,0은 중요한 사실변형/창작이다. 목적2는 보고/지시/허락/경고/설명/권고/질문의 요청 기능을 지킴,1은 불필요한 편집/확인,0은 화행을 바꾸거나 정보 없이 실행을 확정함이다. 명확성2는 대상/관계/다음판단이 식별됨,1은 개선여지가 있음,0은 필요한 대상/관계가 흐려짐이다. 자연성2는 통상적인 업무 한국어,1은 어색하지만 해석가능,0은 부자연스러움이 이해를 막음이다. 간결성2는 필요한 뜻을 남기고 반복/불필요한 설명이 없음,1은 중복/과설명이 있음,0은 핵심을 묻거나 불필요한 설명 때문에 판단이 방해됨이다. 출력 누락/실행 실패는 unscored로 남기고0점과 구별한다.

prompt, CLI JSONL/stderr/final response, 실행 exit·시각·모델요청설정·프로필/입력 digest, JSON 구조 검사, 평정 원자료를 보존한다. 구조검사를 내용점수로 바꾸지 않는다. 표본12·고정순서·단일batch·모델1종·반복1이며 후속 규칙수정 후 같은 유형을 재평가한다는 선택조건을 명시한다. 모델/독자 일반효능, 통계유의성, 현장성능, 비용을 주장하지 않는다. 별도 hostloader 모델probe는 root의 취소 지시로 실행하지 않으며 실제 debug prompt-input 자료와 생성평가를 구분한다.

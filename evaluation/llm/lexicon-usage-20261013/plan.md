# 사전 조회를 허용한 실제 모델 진단을 고정한다

현재 규칙·프로필·사전은 변경하지 않는다. 기존 평가가 사전 파일 읽기를 금지한 공백을 다루며, 두 사전의 모든 뜻을 모델이 이해했다거나 규약의 일반 효능을 입증했다고 표시하지 않는다.

## 입력과 판정 기준을 실행 전에 고정한다

독립 작성 에이전트가 프로젝트의 사전·프로필·이전 사례를 읽지 않고 새 합성 문맥 12개를 작성했다. 네 분야에 세 개씩 배정했으며 자연 말뭉치나 한국어학 전문가 연구가 아니다. 원본 cases.json을 보존한다. 별도 에이전트가 원본 사례만 읽고 정답 기준을 검토했다. gold-adjudication.json은 LX01·03·09·12의 허용 판정을 조정한다. LX09는 최근의 시간 지시가 가능하여 행동 구분력이 낮다는 한계를 그대로 공개한다.

모델에는 id·explicit_context·source·candidate·target_concept만 제공한다. expected_action·required_meaning·forbidden_inferences·acceptable_answer·reason과 후속 정답 조정은 모델 입력과 작업 폴더에 넣지 않는다. 프롬프트·사례·계획·평정 기준·실행기·프로필·사전의 해시는 실제 호출 전에 고정한다. 실행 후 정답을 결과에 맞춰 바꾸지 않는다.

## 두 조건을 같은 모델과 입력으로 실행한다

미적용 조건의 임시 프로젝트에는 프로필과 사전이 없다. 적용 조건에는 현재 coding-agent 프로필을 AGENTS.md로 두고 core.json과 domains/software.json을 원본 그대로 제공한다. 두 조건의 공개 프롬프트와 입력 순서는 같다. 조건당 한 배치를 실행하며 순서는 미적용 다음 적용이다. 임시 CODEX_HOME은 기존 인증 파일만 참조하고 사용자 설정·전역 지침을 불러오지 않는다.

작업 폴더의 파일 조회를 허용한다. 사전이 있으면 관련 뜻과 조건을 확인하도록 요청한다. 인터넷·다른 모델·작업 폴더 밖의 자료는 요청하지 않는다. CLI의 read-only sandbox는 파일 쓰기를 제한하지만 읽기 범위를 작업 폴더로 강제하는 보안 경계는 아니다. 원시 trace를 검토하여 외부 자료 조회가 있으면 해당 실행을 유효 비교로 사용하지 않는다.

결과는 id·action·text·reason·used_entry_ids를 담는다. 사전 ID의 자기 보고만으로 조회를 입증하지 않는다. trace의 실제 파일 조회 명령·반환 내용과 대조한다. 전체 파일을 제공했다는 사실, 파일을 도구로 읽었다는 사실, 관련 뜻을 출력에 적용했다는 판정을 서로 구분한다. 미등록 개념은 임의의 항목에 연결하지 않는다.

첫 요청 모델은 OpenCodex 경로의 gpt-6.1-sol/high다. capacity 오류가 발생하면 실패를 보존하고 두 조건을 모두 anthropic/claude-opus-5-5/high로 다시 실행한다. CLI 호출은 최대 네 번이며 환경·입력 오류나 의미 실패를 이유로 재시도하지 않는다. FALLBACK 표시가 있는 Opus 실행은 비교에서 제외한다. 실제 상위 공급자가 관측되지 않으면 요청 모델과 관측 한계를 기록한다.

## 의미·행동·사전 적용을 분리해 평가한다

별도 검토자에게 공개 문맥·후보·실행 전 고정한 의미 기준과 A/B의 action·text만 제공한다. 모델명·조건 키·reason·used_entry_ids·trace는 숨긴다. 검토자는 의미 보존, 행동의 적절성, 불필요한 재작성 여부를 판정한다. 표현 차이가 있다는 사실만으로 의미 오류나 개선으로 세지 않는다.

핵심 의미 성공은 각 사례의 필수 의미를 보존하고 금지한 사실 추가·누락·양태 변화가 없는 것이다. 불필요한 확인 질문이나 재작성은 의미 손상과 별도로 보고한다. 두 조건이 모두 성공하면 개선 효과를 주장하지 않는다. 단일 배치와 작은 합성 표본의 결과를 사람의 이해도·전체 어휘 충족률·전체 193개 뜻의 성능으로 확대하지 않는다.

파일 조회와 표본의 어휘 뜻 적용은 별도 기록으로 남긴다. 실행 추적에서 조회한 항목과 반환한 ID·의미의 일치 여부를 확인하되, 어휘의 승인 상태는 이 프로젝트의 자체 편집 상태이며 외부 전문가의 승인으로 해석하지 않는다.

# 정제 프로필의 실제 모델 검토 결과

편집26개와 생성12개는 의미를 보존했고, 보완6개는 기준 조건과 프로필 조건 모두 판단·의미 기준을 충족했다. 생성 v09와 v10에는 간결성 보완점이 남았다.

| 검토 묶음 | 검토 결과 | 해석 범위 |

| 편집26개 | 26개 모두 허용 판단을 선택하고 원문·문맥의 사실과 범위를 보존했다. | 기존 입력을 재사용한 개발 회귀 점검이다. |
| 생성12개 | 12개 모두 의미·발화 목적·명확성·자연스러움에서 각각2점을 받았고 사실 창작이 없었다. | 기존 입력을 재사용한 개발 회귀 점검이다. |

v09는 같은 단계에서 Alt 키를 누른 상태를 반복하지만 이동 중 키 유지와 타일을 놓은 뒤 해제라는 조건을 보존했다. v10은12개 이미지의 시험 범위를 반복하고 후속 속도 측정 권고를 길게 썼다. v10의 권고는 타당하며 측정을 이미 완료했다고 창작한 내용은 없다.

보완 ASP02의 기준 조건은 “지호는 지금 안경을 쓴 상태다.”라고 썼고 프로필 조건은 “지호는 지금 안경을 쓰고 있다.”라고 썼다. 두 표현은 명시된 문맥에서 착용 결과 상태를 보존하므로 동등한 답으로 인정했다. PAS01은 두 조건 모두 “지후가 예나에게 밀렸다.”라는 피동문으로 예나와 지후의 역할을 보존했다. 검토는 정답 예문의 문자열 일치를 요구하지 않았다.

처음 고정한 계획·입력·프롬프트·프로필의 해시는 평정 기록 저장 시에도 일치했다. 프로필은28,627바이트이며 SHA256은 282cbdcea153cf6eec5361eda2431c7d2ee2c66d04e71c3fca19639a875c46ee이다. 실제 Sol/high 첫 요청은 2026-10-12T14:13:21.799939+00:00에 시작해 용량 부족 오류로 종료했고 의미 출력이 없었다. 다음 Opus 요청 전에 저장한 용량 대응 변경 기록은 2026-10-12T14:15:44.264448+00:00에 전체 예산을5회, 즉 실패한 Sol1회와 원래 네 조건을 대체하는 Opus4회로 변경했다.

네 대체 요청은 모두 anthropic/claude-opus-5-5와 high를 지정하고 OpenCodex의 localhost10100 subscription_router를 사용했다. 네 요청은 종료 코드0을 반환했고26·12·6·6개 응답의 JSON 구조가 유효했다. CLI 기록에는 FALLBACK 표기가 없지만 실제 상위 제공자는 관측되지 않았다. 보완6개의 두 조건은 같은 프롬프트를 사용했고 추가 모델 반복은 없었다.

상위 에이전트는 조건 이름을 알고 모든 출력과 사례 기준을 직접 읽어 평정했다. 따라서 이 평정은 눈가림 검토가 아니며 통합 작업에서 완전히 독립한 검토도 아니다. 조건당 한 배치만 실행했고 입력은 재사용했으므로 일반 효능, 새 독립 표본의 성능, 과거 Sol 대비 인과적 개선이나 통합 정확도를 주장하지 않는다. 특히 보완6개는 프로필 정제 전에 관측된 사례이므로 재사용 사례에 대한 진단으로만 해석한다.

프로필은 사전 파일을 참조하지만 이번 모델 입력은 도구와 파일 읽기를 금지했다. 따라서 이번 실행은193개 사전 용어 전체의 실제 적용을 평가하지 않았다. 원문 출력·명령·환경 설정·오류·해시는 각 실행 폴더에 보존했고, 사례별 원평정은 root-ratings.json, 구조·해시 근거는 structural-evidence.json, 검토 원자료는 review-packet.md에 저장했다.

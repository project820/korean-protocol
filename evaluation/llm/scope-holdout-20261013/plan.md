# 새 문맥에서 과제에 필요한 정보를 구분하는지 검증한다

기준은 9367bde이며 규칙·프로필·사전은 이번 평가 중 수정하지 않는다. 직전 변경은 기존 사례의 편집 행동 오류를 해소했지만 같은 사례를 재사용했으므로 새 문맥의 효과는 입증하지 못했다. 이번에는 규칙·사전·기존 평가를 읽지 않은 별도 작성자가 만든 합성 문맥 12개를 실행 전에 고정한다. 자연 말뭉치·전문가 자문·사람 독해 시험으로 표시하지 않는다.

## 과제와 정답을 실행 전에 검토한다

소프트웨어·업무 조정·데이터 문맥에서 편집이나 보고와 실제 실행·판정 요청을 구분한다. 정보가 없다는 사실만으로 질문이 정답이 되지 않으며, 요청 수행에 그 정보가 필요한지가 판정 기준이다. 편집 자체에 미상 주체가 필요한 경우와 실제 판정에 필요한 정보가 충분한 경우를 통제 사례로 포함한다. 같은 주제의 두 요청을 한 배치에 포함하므로 서로의 표현이 단서가 될 수 있다는 한계를 남긴다.

작성자는 공개 facts·request와 비공개 의미 기준·허용 행동·예시·금지 추론을 작성한다. 별도 검토자는 사례만 읽고 문맥의 자족성, 정답 충돌, 과도한 확인 요구, 허용 답안의 폭을 검토한다. 사례 원본은 보존하고 조정은 gold-adjudication.json에 분리한다. 모델에는 id·facts·request만 제공하며 정답·예시·범주·쌍 연결은 주지 않는다. 실제 출력에 맞춰 정답을 변경하지 않는다. 사용자가 선택을 맡긴 과제는 임의의 사실을 단정하는 경우와 구별하며, 선택 근거를 정직하게 밝힌 위임 수행을 일괄 오류로 판정하지 않는다. 확인이 필요하다는 판정은 물음표 유무가 아니라 필요한 정보와 판단 한계를 정확히 전달했는지로 평가한다. 실행 전 정답 검토에서 구분력이 약하거나 복수 행동이 가능한 사례를 발견하면 이를 명시한다. 최초 검토의 12개와 판정은 pre-run-v1에 보존한다. 네 주제의 선택 요청이 재량 위임을 허용한 설계 문제는 실제 출력이 없는 상태에서 작성자에게 되돌려, 기존 기준에 실제 관측값을 적용하는 판정으로 보완한다. 보완 후에도 최종 표본은 12개이며 별도 검토를 거쳐 고정한다. 고정과 실행 뒤에는 약한 사례를 삭제하거나 바꾸지 않는다.

## 두 조건의 입력과 실행을 고정한다

baseline은 프로필·사전이 없는 임시 프로젝트다. treatment는 현재 coding-agent 프로필을 AGENTS.md로 두고 두 사전 원본을 제공한다. 공개 입력·순서·프롬프트는 같다. 두 조건 모두 자연스러운 한국어 답변을 작성하며 action 라벨을 강제하지 않는다. 로컬 사전이 있으면 관련 항목만 읽을 수 있지만 외부 과제 자료·인터넷·다른 모델·에이전트는 요청하지 않는다. 로컬 파일 도구 사용을 허용하므로 read-only sandbox를 cwd 읽기 격리 보장으로 해석하지 않는다.

현재 실행기·공유 실행기·사례·조정 정답·계획·프롬프트·프로필·사전 해시를 실제 실행 전에 고정한다. 모델 작업 폴더에는 공개 입력과 제공 파일만 있고 정답·계획·동결 기록은 밖에 둔다. 임시 CODEX_HOME과 기존 인증 참조를 사용하며 사용자 전역 설정은 바꾸지 않는다. 원시 trace와 마운트 해시를 보존하고 명시적 외부 자료 조회가 있으면 유효 비교에서 제외한다. 경로를 알 수 없는 CLI 경고와 내부 관측 한계도 공개한다.

순서는 baseline 다음 treatment이며 요청 모델은 gpt-6.1-sol/high다. 실제 CLI 호출은 조건당 한 번이다. capacity 오류가 발생할 때만 실패 기록을 보존하고 두 조건 모두 OpenCodex의 anthropic/claude-opus-5-5/high로 전환한다. 총 호출은 최대 네 번이다. 의미 실패·형식 오류·환경 오류에 대한 재시도는 하지 않는다. FALLBACK 표시가 있는 실행은 유효 비교에서 제외한다. 실제 상위 공급자가 관측되지 않으면 요청 모델과 관측 한계를 구분한다.

## 의미·과제 수행·질문 필요성을 따로 판정한다

출력을 받은 뒤 별도 검토자에게 조건 이름·모델명·프로필·reason·trace를 숨긴 A/B text와 공개 문맥·고정 정답만 제공한다. 의미 보존은 사실 추가·누락, 조건·주체·수량·확실성·시점의 변경이 없는지로 판정한다. 과제 수행은 요청된 편집·판정·보고 또는 필수 정보 확인을 수행했는지로 판정한다. 불필요한 확인과 근거 없는 답변 확정을 따로 집계한다. 같은 뜻의 표현 차이나 정답 예시와 어휘가 다르다는 이유만으로 실패로 판정하지 않는다.

이 표본의 통과 기준은 필수 의미 실패 0개, 과제 수행 실패 0개, 불필요한 확인 0개, 근거 없는 확정 0개다. 미적용 조건과 적용 조건을 모두 같은 기준으로 공개한다. 어느 조건이든 실패하면 해당 문맥·출력·고정 기준을 그대로 보고하며 입력 삭제나 분모 조정으로 통과시키지 않는다. 미확정 평정은 성공으로 계산하지 않는다. 동률이면 개선 효과를 주장하지 않는다. 단일 작은 합성 표본의 통과는 일반 한국어의 안정성·전체 어휘 성능·사람 이해도 개선을 입증하지 않는다.

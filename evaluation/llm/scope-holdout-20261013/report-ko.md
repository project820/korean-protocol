# 새 합성 문맥 12개에서 두 조건 모두 과제 범위를 지켰다

미적용·적용 조건은 의미 보존과 과제 수행 각각 12/12를 통과했고 불필요한 확인과 근거 없는 확정은 없었다. 결과가 같으므로 규약의 개선 효과를 주장하지 않는다. 이 결과는 한 번의 작은 합성 평가이며 전체 한국어 구문이나 사람의 이해도를 입증하지 않는다.

## 실행 전에 사례와 기준을 고정했다

규칙·사전·기존 사례와 출력을 읽지 않은 별도 에이전트가 6개 주제의 요청 쌍 12개를 작성했다. 다른 에이전트의 정답 검토에서 첫 초안의 실제 선택 요청 네 개가 사용자 재량 위임을 허용한다는 문제가 확인됐다. 작성자는 실제 모델 실행 전에 네 쌍을 보완했다. 이미 정해진 규칙에 아직 모르는 관측값을 적용하는 판정으로 바꿨고, 첫 사례·검토 원본은 pre-run-v1에 보존했다. 결과를 보고 실패 사례를 제외하거나 정답을 바꾸지 않았다.

최종 사례는 배포 점검 완료 시각, 완료율 분모, 원문 언어에 따른 담당자, 로그 경과 일수, 장애 접수 수에 따른 우선순위, 지시 대상과 충분한 배포 규칙을 다룬다. 다섯 편집 요청은 미상 상태를 유지해 답할 수 있고 다섯 판정 요청은 관측값이 부족하다. 추가 통제 사례는 편집 대상이 미상인 요청과 이미 충분한 규칙을 가진 실제 판정이다. 따라서 직접 답변 6개와 기능적 확인 6개로 구성된다.

정답의 clarify는 질문 형식이 아니라 필요한 정보의 부재를 정확히 전달하는 기능이다. 예를 들어 완료 48건과 목표 80%에 대해 전체 대상이 60건 이하일 때만 달성한다는 조건부 답변은 허용한다. 실제 분모가 60건이라고 만들면 실패다. 편집에는 초안 밖 모든 배경 사실의 반복을 요구하지 않는다.

별도 작성자와 검토자는 모델 에이전트이며 실제 한국어학·군사 전문가의 자문이 아니다. 사례는 자연 업무 자료에서 추출한 말뭉치가 아니고, 짝지은 주제를 한 배치에서 읽으므로 상대 요청이 단서가 될 수 있다. 이 경계 평가를 자유 재량 선택 전반의 성능으로 확대하지 않는다.

## 두 조건을 같은 설정으로 실행했다

기준 커밋은 9367bde이며 규칙·프로필·사전은 그 커밋과 같다. 미적용 조건은 빈 임시 작업 폴더이고 적용 조건은 현재 coding-agent 프로필과 두 사전 원본을 제공했다. 모델에는 id·facts·request만 제공했으며 정답·예시·평가 범주·계획은 주지 않았다. 자연 답변 text만 요구하고 action 라벨을 강제하지 않았다.

실행 전 freeze-manifest.json에 사례·정답·계획·실행기·공유 실행기·정확한 프롬프트·프로필·두 사전의 해시를 고정했다. 실행기 새 검사 11개와 공유 실행기 검사 8개가 통과했다. 두 실제 호출의 계약과 마운트 파일 집합·바이트가 동결 해시와 일치한다. 기존 평가·제품 코드는 바꾸지 않았다.

OpenCodex subscription_router 경로에 gpt-6.1-sol/high를 요청했고 미적용 다음 적용 순서로 한 번씩 실행했다. 두 호출은 종료 코드 0과 출력 구조 검사를 통과했다. capacity 오류·FALLBACK 표시는 없었으며 Opus 호출이나 의미 실패 재시도는 없었다. 실제 상위 공급자와 자동 fallback 여부는 CLI가 반환하지 않아 직접 관측하지 못했다.

미적용 실행은 도구를 호출하지 않았다. 적용 실행은 사전 상대 경로를 대상으로 rg와 Python 명령을 한 번씩 실행했으며, 반환된 KPL-0087과 KPL-SW-0021의 전체 항목이 동결 사전과 같았다. 조회 사실은 해당 어휘가 판단을 개선했다는 증거가 아니다. 적용 실행에는 알 수 없는 경로의 sandbox 경고와 Xcode 캐시 생성 거부 경고가 남았으나 명령 종료 코드는 0이었다. trace-audit.json은 명시적인 외부 과제 자료·네트워크·다른 에이전트 호출을 관측하지 않았다는 범위만 기록한다. CLI 내부의 전체 파일 접근이나 cwd 읽기 격리를 증명하지 않는다.

## 조건을 가린 판정을 집계했다

별도 평가자에게 사실·요청·고정 정답과 A/B 답변만 제공했다. 조건 키·모델명·프로필·trace는 제공하지 않았다. 원본 출력 24개와 평정 패킷 text가 정확히 같은지 확인했으며, 평가 후 키를 연결했다. A는 적용이고 B는 미적용이다.

| 판정 항목은 다음과 같다. | 미적용 결과는 다음과 같다. | 적용 결과는 다음과 같다. |
| --- | --- | --- |
| 의미를 보존했다. | 12/12개가 통과했다. | 12/12개가 통과했다. |
| 요청한 과제를 수행했다. | 12/12개가 통과했다. | 12/12개가 통과했다. |
| 불필요한 확인을 했다. | 0개였다. | 0개였다. |
| 근거 없는 내용을 확정했다. | 0개였다. | 0개였다. |

두 조건은 실제 관측값이 없는 판정에서 부족한 정보와 정확한 조건부 결과를 설명했다. 적용 조건은 다섯 판정에 직접 질문도 붙였지만, 필요한 정보를 묻는 것이므로 이를 불필요한 질문으로 세지 않았다. 충분한 배포 규칙이 있는 통제 사례에서는 A를 선택했고, 편집 대상을 특정할 수 없는 사례에서만 편집 전에 확인했다.

summary.json의 sample_gate_passed는 이 고정 표본의 사전 기준을 충족했다는 뜻이다. 전체 완료나 일반화 성공을 뜻하지 않는다. 평가자는 한 명이며 복수 평정자 일치도와 실제 독자의 이해도·재독 시간은 측정하지 않았다. 이번에는 새로운 규범 실패가 발견되지 않았으므로 규칙을 추가로 고치거나 같은 표본을 재실행하지 않는다.

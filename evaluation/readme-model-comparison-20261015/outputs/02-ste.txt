# 교육 신청 방식

교육 신청 방식은 포털 신청과 부서 취합 두 가지입니다.

## 포털 신청

- **대상 과정:** 참석자가 20명 이상인 정기 과정
- **신청자:** 참석자 본인
- **방법:** 포털에서 직접 신청합니다.
- **마감:** 마감일 18:00

## 부서 취합

- **대상 과정:** 소규모 실습 과정 또는 외부 강사 과정
- **신청자:** 부서 담당자
- **방법:** 참석자 명단을 취합하여 제출합니다.
- **기한:** 과정 시작 5영업일 전까지

## 법정 의무교육 대상자 확인

법정 의무교육 대상자의 누락 여부는 자동으로 확인됩니다. 이 확인은 신청 방식과 관계없이 적용됩니다.

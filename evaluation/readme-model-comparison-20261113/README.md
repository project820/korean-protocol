# README 예문 6개를 v0.11.0과 STE로 비교했다

**Opus 5.5·medium에서 출력 12건을 생성했다. 의미 검토는 12건 모두 보존이다.** 출력은 고치거나 다시 생성하지 않았다.

이 비교는 짧은 예문 6개의 예시다. v0.11.0의 원문·KP·STE 정식 비교는 **미완료**다.

[README의 세 열 비교로 돌아간다.](../../README.md#문장과-구조를-함께-다듬는다)

## 실행 조건

| 항목 | 조건 |
| --- | --- |
| **원문** | [v0.7.0 비교](../readme-model-comparison-20261015/README.md)와 같은 6개 문장이다. [cases.json](cases.json)을 그대로 복사했다. |
| **모델** | 두 조건 모두 `anthropic/claude-opus-5-5`를 요청했다. 응답 메타데이터도 같은 모델을 반환했다. |
| **추론** | 두 조건 모두 `medium`이다. 온도와 시드는 지정하지 않았다. |
| **KP 입력** | 태그 `v0.11.0`(커밋 `7810679`)의 `skills/korean-protocol/SKILL.md` 전체다. 참조 문서는 넣지 않았다. |
| **STE 입력** | [한국어 적용 지침](ste-profile.md)이다. v0.11.0 파일럿과 같은 지침이며 [ASD-STE100 공식 FAQ](https://asd-ste100.org/STE_faq.html)의 공개 원칙을 요약했다. |
| **횟수** | 원문마다 조건별 1회, 모두 12회다. 재시도·선별·사후 교정은 없다. |
| **격리** | 호출마다 지침 하나와 원문 하나만 넣었다. 대화 기록·AGENTS·도구·설명용 답안은 넣지 않았다. |
| **실행일** | 2026-11-13. 호출별 시각은 [records](records)에 있다. |

두 조건의 공통 요청은 다음 문장이다.

> 다음 원문을 제공한 작성 지침에 따라 한국어로 정리해줘. 사실·조건·수치·기한·행위 주체·의무·자동 처리·확실성은 유지해줘. 정리한 본문만 출력하고 설명이나 자기 평가는 덧붙이지 마.

**범위:** 이 비교는 지침을 본문으로 넣은 변환 실험이다. 설치·호출 동작은 시험 범위 밖이다. STE 열은 영어 규격의 공개 원칙을 한국어에 적용한 실험이며 공식 한국어판이나 준수 결과로 쓰지 않는다.

## 의미 검토

원문의 뜻이 출력에 남았는지와 출력에 새 뜻이 생겼는지를 양방향으로 확인했다.

- **독립 검토:** GPT-6.1 Sol·high가 조건명을 A/B로 가린 [비교 자료](blind-packet.json)를 판정했다. 12건 모두 보존이다.
- **가림 한계:** 검토자는 파일을 읽을 수 있었고 같은 폴더에 [대응표](blind-key.json)가 있었다. 접근 격리는 하지 않았다.
- **주 검토:** 생성 모델과 같은 Opus 5.5가 독립 판정 전에 12건을 대조했다. 판정은 같았다. 생성 모델과 같아서 독립 검토로 세지 않는다.

| 원문 | KP v0.11.0 | STE | 확인한 의미와 조건 |
| --- | --- | --- | --- |
| 1. 반납 대상 | 보존 | 보존 | 대상 3개, 총무팀 접수, 7월 5일 18:00 마감 |
| 2. 교육 신청 | 보존 | 보존 | 두 방식, 20명 이상 정기 과정, 마감일 18:00, 부서 담당자 명단 제출, 시작 5영업일 전, 방식과 무관한 자동 확인 |
| 3. 취소와 대기 | 보존 | 보존 | 이용 24시간 전 취소, 자동 안내, 수신 후 4시간 응답 의무, 미응답 시 다음 대기자 |
| 4. 수신 확인 기한 | 보존 | 보존 | 목록 확인 뒤 4시간, 근무시간 밖 제출 건의 다음 영업일 12:00, 기본 기한을 대신하는 관계 |
| 5. 실행과 의미 오류 | 보존 | 보존 | 12건 실행 성공과 2건 누락의 구분, 보완 의무, 재검토 전 배포 금지 |
| 6. 표기와 지정 여부 | 보존 | 보존 | 자료의 표기 없음과 지정 여부 미확인의 구분 |

사례별 판정 이유는 [review.json](review.json)에 있다.

## 구조 차이

- **1·4·6번:** KP는 굵은 라벨 목록으로 대상·기한·상태를 앞에 두었다.
- **2번:** KP는 방식마다 소제목을 두고 대상·신청·마감을 나눴다. STE는 표로 나눴다.
- **3번:** KP는 조건 부분을 굵게 표시했다. STE는 조건 문장 세 개로 썼다.
- **5번:** 두 출력 모두 실행 성공을 먼저 썼다. 의미 오류를 첫머리로 옮기지 않았다.
- **길이:** KP 790자, STE 776자다.

**의미 보존 판정은 구조 규칙 충족과 별개다.** 반복 실행, 다른 모델, 긴 문서, 사람의 읽기 시간은 시험하지 않았다.

- **원본 스트림:** 요청·응답 원본은 실행한 로컬 환경에 보관한다. 저장소에는 해시만 올렸다.

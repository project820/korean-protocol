# STE 원칙을 한국어에 적용하는 실험 지침

ASD-STE100 공식 FAQ에서 확인한 작성 원칙을 아래처럼 한국어에 적용한다. 영어 규격 전체나 승인 영어 사전을 한국어 규격으로 대체한 것이 아니다.

1. 문장을 짧게 쓴다. 한 문장에는 한 주제를 둔다.
2. 쉽고 익숙한 말을 쓰고, 같은 대상과 동작에는 같은 용어를 쓴다. 한 단어를 서로 다른 뜻으로 혼용하지 않는다. 정확한 전문명과 식별자는 유지한다.
3. 능동문을 쓴다. 설명문에서 행위자가 알려져 있지 않으면 피동 표현을 허용한다. 행위자를 새로 만들지 않는다.
4. 독자가 수행할 절차는 직접적인 행동 지시로 쓴다. 상태 설명과 자동 처리 결과를 독자의 행동 지시로 바꾸지 않는다.
5. 독자가 행동 전에 알아야 할 조건은 그 행동 앞에 둔다. 조건과 그 조건에 해당하는 결과의 관계를 분명히 한다.
6. 절차는 실행 순서에 맞춰 쓴다. 한 단계에서 독자가 할 행동을 명확히 구별한다.
7. 독자의 필요에 맞춰 정보를 논리적으로 구성한다. 제목, 목록, 번호, 표는 필요하면 사용하며 특정 형식을 강제하거나 금지하지 않는다.
8. 원문의 의미를 바꾸지 않는다. 사실, 주체, 조건, 예외, 수량, 기한, 의무, 가능성, 부정, 미확인 상태를 유지한다.

한국어 적용 범위: 영어 승인 어휘·품사·문법·단어 수 제한을 한국어에 기계적으로 대입하지 않는다. 높임말이나 명사형을 일괄 강제하지 않는다. 형식이나 문장 길이 때문에 뜻에 필요한 말을 삭제하지 않는다.

근거: https://asd-ste100.org/STE_faq.html (2026-10-15 확인). 위 문장은 실험을 위한 자체 요약이며 규격 원문을 전재한 것이 아니다. 원칙 4·6·7의 한국어 실행 단위와 형식 선택은 해당 원칙을 적용하기 위한 실험 설계다.

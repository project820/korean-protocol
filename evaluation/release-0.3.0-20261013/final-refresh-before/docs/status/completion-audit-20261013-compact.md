# 압축 문체 후보의 완료 여부를 점검했다

전체 목표는 아직 완료로 판정하지 않는다. 기능 대응 49/53과 출력 표본의 통과를 전체 규격의 90% 성능으로 바꾸어 해석하지 않는다. 이전 목표 턴은 규약·설치 제어와 실제 출력 증거를 추가했으므로 진행으로 분류한다. 이번 턴도 새 사례의 반복 실행·독립 평정·논문 근거·요구사항 정정을 추가했다.

## 현행 출처를 확인했다

통합 작업트리는 `codex/editing-information`이며 기준 커밋은 `2067f541d2cc97d94f4a8625de2015d2330aeb1b`다. 기존 미커밋 변경을 보존했다. 현행 규칙·사례·규범의 기능 검토 해시와 [후보 검토](../../evaluation/controlled-language-20261013/review.json)를 확인했다. 생성 프로필 해시는 [새 평가 동결 기록](../../evaluation/llm/fresh-controlled-20261013/verification.json)과 같다.

`gh repo view project820/korean-protocol --json visibility,defaultBranchRef,url`은 공개 저장소와 main을 반환했다. 공개 HTTPS manifest는 버전 0.2.0·순번 1이며 coding-agent 해시는 `786cddbe11388e15c0776204c76fa2fd1ff2f32885447a1343a048477c10025b`다. 로컬 후보의 해시 `53ebc2f02ddcffce961cae668c5a71851e46fa0d9fe09b9b67169b8cdaebae60`와 다르다. 이번 조회는 공개 상태 확인이며 새 버전 게시나 서명 재검증으로 계산하지 않는다.

## 각 요구사항의 증거를 분리했다

| 요구사항 | 현재 판정과 근거 |
| --- | --- |
| 전체 목차·규칙·예외·용례를 제공한다 | 구조와 작성물은 있다. 규칙 72개·작성 사례 291개를 기록하고 규범·JSON·생성물을 대조했다. |
| STE 작성 기능의 90% 이상에 대응한다 | 독립 기능 설계 검토는 49/53이며 네 부분 대응을 공개한다. 이 범위의 관문은 충족한다. |
| 한국어 고유 기능을 통제한다 | 독립 한국어 사례와 조사·논항 검토, 화행·생략·높임의 최신 변경 검토를 보존했다. 전문가·전체 한국어 구문 검증으로 확대하지 않는다. |
| 통제 어휘 사전을 제공한다 | 193개 뜻과 454개 작성 사례, 활용·결합·확장·충돌 정책을 갖췄다. 기존 연결률은 사용 성능이 아니며 분야별 실제 출력의 승인 의미 사용 비율은 아직 별도 검증이 필요하다. |
| LLM 출력의 의미와 명확성을 검증한다 | [새 합성 입력 12개×두 반복](../../evaluation/llm/fresh-controlled-20261013/report.md)에서 세 조건 모두 통과했다. 의미 손실 없는 표본은 확인했지만 일반적 정확도 우위·사람 이해도 향상은 확인하지 않았다. |
| 한 번 설치하고 갱신 없이 사용한다 | 공개본 설치·오프라인 유지와 후보의 두 임시 호스트 설치를 확인했다. 이미 읽은 대화 문맥의 삭제와 파일 OFF를 구분한다. |
| 자동 갱신·실패 복구를 제공한다 | 공개본 서명·예약 실행과 시험용 다음 버전 전환, 후보 OFF 유지·이관 복구 증거가 있다. 실제 공개 다음 버전 업그레이드·재로그인·절전 복귀는 남아 있다. |
| 연구 근거를 추적한다 | [논문 네 편](../../research/2026-10-13-ellipsis/controlled-language-papers.md)의 과제·측정·확인 범위를 기록했다. 같은 실험을 재설명한 논문을 독립 재현으로 중복 계산하지 않았다. |

## 다음 작업을 구체화했다

분야별 승인 의미 사용 평가는 출력 생성 전에 표본과 뜻 연결을 고정해야 한다. 소프트웨어 실행·업무 조정·데이터 작업·사양 문서에서 같은 표면형의 다른 뜻, 허용 활용, 논항, 미등록 고유명·식별자 예외를 포함한다. 사전 직접 연결·규약상 허용 예외·미확정·실제 오용을 구분하고 분모에서 실패나 미확정을 빼지 않는다. 출력 뒤에 적합한 어휘만 골라 분모를 만들지 않는다.

후보를 공개하려면 커밋 승인과 새 버전의 서명·게시 절차가 필요하다. 현재 로컬 후보를 기존 0.2.0 서명물에 덮어쓰지 않는다. 연구·평가·로컬 수정을 계속할 수 있으므로 목표를 blocked나 complete로 변경하지 않는다.

## 후속 어휘 사용 검증을 반영한다

[분야별 허용 뜻 사용 평가](../../evaluation/llm/lexical-meaning-use-20261013/report.md)는 고정한 24개 문맥에서 KP의 허용 뜻 16/16·예외 4/4·미확정 처리 4/4를 확인했다. 독립 지표 검토자는 원출력·동결 해시·집계·판정 이견을 재확인하고 기존 규범·시험과 합쳐 선언한 제한적 어휘 관문의 근거가 충분하다고 판정했다. 전체 사전이나 자연 말뭉치의 90%를 검증한 것으로 표시하지 않는다.

최초 어휘 비교에서 사용자 스킬 파일의 외부 읽기를 발견해 모든 조건을 다시 실행했다. 새 실행기는 관측한 스킬 57개를 프로세스별로 비활성화하며 실제 inventory와 모델 지침 로드를 확인했다. 이전 비교의 사용자 스킬 메타데이터 노출 가능성도 별도로 기록했다. 새 원출력의 도구 접근은 제공된 어휘집 범위 안에 있었다.

전체 자동 테스트는 355개가 통과했다. 기능 대응·한국어 최소 사례·제한된 실제 출력·어휘 관문의 근거는 갖췄지만, 보완 후보는 아직 공개본과 다르다. 다음 작업은 후속 버전의 배포물을 준비하고, 공개 발행 후 기존 설치의 실제 업그레이드를 검증하는 것이다. 기존 0.2.0의 지속 설치 성공을 새 후보의 공개 배포 성공으로 대신하지 않는다.

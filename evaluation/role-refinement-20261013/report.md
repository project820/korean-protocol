# 조사·논항 적용 조건을 보완했다

KP-KO-001은 조사가 이미 있는 문장을 편집할 때도 행위자·대상·수신자·도구·장소의 대응을 보존하도록 보완했다. 명사 연쇄를 풀 때의 기존 기능과 회복 가능한 조사 생략 예외는 유지했다. 규칙의 요구·조건 외에 나머지 71개 규칙과 고정 사례는 바꾸지 않았다.

[보완 전 감사](../korean-current-20261013/review.json)는 두 사례의 전용 규칙 매핑을 미확인으로 남겼다. [보완 후 독립 검토](korean-review-after.json)는 고정 사례 30개 모두에서 의미 기대값과 전용 규칙 매핑을 인정했다. 이는 여덟 범주의 최소 24칸을 충족한 규범 검토이며 한국어 전체의 완전성이나 실제 독자 효과를 뜻하지 않는다. KI-NEG-03 제외와 과거 증거는 보존했다.

[기능 대응 검토](../functional-review.json)는 영향을 받는 4.2·4.5의 선정 규칙 여섯 개, 작성 사례 21개와 독립 기능 사례 네 개를 다시 대조했다. 다른 51개 판정은 관련 원본이 불변임을 확인한 뒤 승계했다. 보완 전 기능 검토는 [별도 원본](functional-review-before.json)에 보존했다. 49/53개 통과와 네 부분 대응은 그대로이며 새 독립 사례를 추가한 결과가 아니다.

컴파일된 코딩 프로필은 28,652바이트로 28KiB 상한보다 20바이트 작다. 규칙·상세 문서·프로필은 25바이트씩 늘었고 원본 지침을 잘라내지 않았다. 검사·발행 테스트 56개와 기능 대응 무결성 검사가 통과했다.

[실제 모델 진단](../llm/role-refinement-20261013/report-ko.md)은 같은 세 사례의 미적용·적용을 Sol/high로 각각 한 번 실행했다. 조건을 가린 별도 검토에서 여섯 출력 모두 의미 보존·적절한 행동을 충족했고 불필요한 재작성은 없었다. 두 조건이 모두 통과했으므로 개선 효과를 주장하지 않는다.

[새 패키지 시험](package-smoke.json)은 수정된 프로필을 담은 ZIP의 체크섬과 두 호스트 설치, 복제본 이동 후 상태 확인·제거를 확인했다. 정식 발행키·운영 서버·예약 등록은 연결하지 않았다.

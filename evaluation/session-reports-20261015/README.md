# Codex 세션 보고서로 KP와 STE를 비교했다

**KP v0.8.0을 채택했다.** 실제 Codex 세션 보고서 30개로 원문·KP·STE 1:1:1 비교를 했다. 블라인드 검토에서 KP가 STE보다 재독 부담이 적었다. 미공개 시험 세트 6개에서 STE는 모든 원문에서 최하위였다.

## 남은 한계

- 구조 기준 8개를 모두 통과한 출력은 소수다. 미공개 시험 세트에서 v0.8.0은 6개 중 1개, STE는 0개를 통과했다.
- 가장 많이 남은 결함은 **대상 목록화(G3)**다. v0.8.0은 미공개 시험 세트 6개 중 5개에서 실패했다.
- KP 출력은 원문보다 길다. 원문 대비 글자 수는 +9.8%~+17.6%다.
- 생성 모델은 Opus 5.5 `medium` 요청 하나, 표본은 조건별 1회다. 다른 모델과 반복 변동은 검증하지 않았다.
- 검토는 모델 검토자(gpt-6.1-sol high)의 문서 판정이다. 사람의 읽기 시간은 측정하지 않았다.

## 규약 변경

r10의 반복 결함을 고쳤다.

| r10 결함 | r11·v0.8.0 규칙 |
| --- | --- |
| 미완료·미검증 상태가 있는데 부분 성공으로 시작했다. | 분석·검토·답변·조사 보고에도 첫 문장에 핵심 판단을 쓴다. 사용을 제한하는 상태는 첫 문장에 결과와 함께 쓴다. |
| 검증 범위·견적 범위·선행 조건이 상세 뒤나 추신에 남았다. | 의존 한계를 추출해 첫 판단 바로 다음에 한계마다 한 행으로 둔다. |
| 독립 주장 둘을 한 문장에 이었다. | 한 문장에 주장 하나. 조건-결과, 원인-결과 한 쌍만 허용한다. |
| 표의 한 행을 제목과 여러 `이름: 값` 행으로 풀었다. | 원문 비교 표는 표로 유지한다. 설명 문장에 ‘목적:’ 같은 이름표를 새로 붙이지 않는다. |
| 원문이 구분하지 않은 열에 값을 복제했다. | 원문에 없는 열·행을 만들지 않는다. |
| 시간 값 둘을 한 행에 묶었다. | 행동을 좌우하는 시간 값은 값마다 한 행에 둔다. |

r11은 새 오류 두 종류와 반복 문제를 만들었다. v0.8.0에서 고쳤다.

- 권고·의무를 ‘미확인’ 상태로 바꿨다. → 원문이 상태로 진술한 한계만 옮긴다.
- 목록을 나누며 일부 항목의 수식어를 모든 항목에 붙였다. → 수식 범위를 확인하고, 확정할 수 없으면 원문 구절을 유지한다.
- 첫 문장의 제한을 제약 블록에 반복했다. → 반복하지 않는다.

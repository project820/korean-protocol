# 고정 실험과 현재 규약을 구분한다

[V7 실험 기록](v7/README.md)은 r1·r2·r3의 고정 프로필, 결합 순서와 의미 보존·구조 판정을 보존한다. 사용자는 r2의 가독성을 선택했으며 r3는 채택하지 않았다. [채택 기록](v7/adoption.md)은 이 결정과 남은 실패를 함께 설명한다.

실험 프로필은 설치용 생성물과 바이트가 다르다. 현재 설치에는 [INSTALL.md](../INSTALL.md)를 사용하며 실험 파일을 전역 지침으로 직접 설치하지 않는다. 현행 원본과 실제 배포 프로필의 관계는 [통합 기록](../docs/status/v7-adoption.md)을 따른다.

# V7 r2의 구조 규칙을 채택한다

2026-10-15 사용자는 제시된 **KP V7 이전 보완(r2)**을 읽기 좋은 안으로 선택했다. 더 짧게 만든 r3는 가독성 때문에 채택하지 않았다. 현재 원본 버전은 `0.7.0-draft`이며 콘텐츠 발행 버전은 `0.7.0`으로 정한다.

## 채택 범위를 정한다

대상 목록을 앞에 배치하고, 선택지별 속성과 조건별 결과를 나눈다. 수량의 기준과 기한을 관련 행동에 연결해 표시한다. 공통 규칙의 범위와 시간의 기산 사건을 유지한다. 필요한 구분이 늘어나더라도 원문보다 짧게 만들 것을 요구하지 않는다. 이미 짧고 찾기 쉬운 문장은 불필요하게 여러 제목으로 나누지 않는다.

채택 기준은 사용자가 제시된 출력에서 선택한 가독성이다. r3의 압축 보완을 기본 규칙으로 합치거나 길이 감소를 합격 조건으로 삼지 않는다. 실제 배포 프로필은 현재 규칙 원본에서 생성하며, [고정 r2 프로필](profile-v7-r2.md)의 바이트를 덮어쓰지 않는다.

## 의미 보존의 한계를 남긴다

[실험 기록](README.md)의 r2 모델 검토 집계는 32개 출력 중 의미 보존 23개·변경 6개·미확정 3개다. 사용자 선택으로 이 실패를 통과로 바꾸지 않는다. 한 개발 문서의 r2와 r3 비교도 독립 평가나 독자 시험으로 세지 않는다.

사용자의 채택은 모든 문서의 의미 보존·일반적인 모델 성능·독자 이해 효과를 입증하지 않는다. 사실·행위자·대상·조건·예외·수량·부정·시점·확실성·출처를 원문과 대조하는 기준은 계속 적용한다. 새로운 문서의 의미 보존 평가와 실제 독자 시험은 별도 검증으로 남는다.

## 발행과 설치 결과를 구분한다

콘텐츠 0.7.0은 엔진 0.2.0 이상을 요구한다. 내부 프로필 상한은 30 KiB, 관리 블록 상한은 32 KiB이며 기존 Codex 프로젝트 잔여 예산 검사는 유지한다. 구버전 엔진은 새 콘텐츠를 거부하고 기존 설치본을 유지하므로 [최신 설치 도구](../../INSTALL.md#기존-설치의-관리-도구를-먼저-갱신한다)를 명시적으로 실행해야 한다. 콘텐츠 자동 갱신은 관리 코드를 교체하지 않는다.

콘텐츠 0.7.0의 공개 서명 발행·익명 다운로드·실제 설치 갱신은 검증 대기 중이다. 현재 공개 주소의 버전은 실제 `release.json`과 서명·콘텐츠 해시 확인 결과로 보고한다. 기존 [0.3.0 공개 검증](../../docs/distribution/public-0.3.0-verification.md)은 이번 발행의 증거로 재사용하지 않는다.

설치 파일 갱신은 이미 시작한 대화의 지침을 지우지 않는다. 호스트의 새 세션 로딩과 모델 출력의 규칙 준수도 구분한다. 발행·설치 검증을 마친 뒤 실제 버전·순번·검증 기록을 이 절에 연결한다.

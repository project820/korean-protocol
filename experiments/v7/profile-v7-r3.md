# V7 압축 후보: 정보는 보존하고 반복을 없앤다

이 규칙은 의미·조건 보존을 전제로 문서의 중복을 제거한다. 원문보다 짧게 쓰되 고유한 사실을 삭제해서 줄이지 않는다. 의미 보존은 형식·분량보다 우선한다. 배치·목록·표제·문체 선택이 앞의 기존 규칙과 충돌하면 아래 규칙을 따른다. 이 변환의 높임말 옵션은 끄기다. 작성 과정·자체 판정·규칙 설명은 출력하지 않는다.

## C1. 첫 블록에서 대상과 판단을 함께 찾게 한다

조사·비교 문서는 핵심 대상에 판단과 필요한 조건을 붙여 바로 제시한다. 긴 선정 배경이나 '다음 조건을 검토했다'라는 예고로 시작하지 않는다. 처리·반납·제출 안내는 대상 목록을 먼저 둔다. 원문의 진행 상태·실패·출처도 빠뜨리지 않고 관련 블록에 남긴다. 한 결론을 도입·요약·마무리에서 다시 설명하지 않는다.

## C2. 같은 사실은 한곳에서 완전하게 쓴다

표·분석·권고·체크리스트를 원문 순서대로 각각 다시 만들지 않는다. 같은 대상의 반복된 정보를 한 기록으로 통합한다. 주체·행동·대상·조건·시점·수량·확실성·출처가 같은 명제만 중복으로 본다. 표현이 비슷해도 대상·조건·한정이 다르면 별개 정보다. 상충하는 서술은 임의로 하나를 고르지 않는다.

같은 사실이 짧은 표와 긴 본문에 중복되면 한쪽에만 완전하게 남긴다. 긴 본문에만 있는 조건·수치·근거·예외를 그 기록에 합친다. 목록으로 바꾼 내용을 바로 앞뒤 문장에서 다시 풀지 않는다. 제목·라벨이 이미 밝힌 대상을 항목마다 반복하지 않는다. 필요한 짧은 색인이나 비교 판단은 허용하되 사양·근거 전체를 되풀이하지 않는다.

## C3. 반복된 내용을 읽지 않고도 대상을 비교하게 한다

대상마다 식별 가능한 제목을 두고 판단·적용 조건·수치·예외를 해당 대상에 모은다. 각 항목은 하나의 판단이나 속성을 담당한다. 다른 대상의 정보가 한 항목에 섞이면 나눈다. 짧은 값에는 '항목: 값'을 쓴다. '가격은 다음과 같다', '이 모델은 다음 기능을 제공한다'처럼 목록과 역할이 같은 도입문을 없앤다. 독립 정보마다 제목을 추가하지 않는다. 같은 구분을 제목과 라벨 양쪽에 반복하지 않는다.

## C4. 공통 규칙과 개별 조건을 구분한다

원문에서 실제로 공통인 요구·검증 사항은 별도 공통 블록에 한 번만 둔다. 일부 대상에만 적용되는 옵션·허용·예외를 공통 사실로 만들지 않는다. '필수 선정 조건'을 '모든 후보가 충족한 사실'로 바꾸지 않는다. 마지막 대상의 제목 아래에 공통 규칙을 붙이지 않는다. 조건 아래 행동을 나눌 때 그 조건에 걸리는 행동만 묶는다. 공통 조건의 범위를 벗어나는 규칙은 동급 제목 등으로 분리한다.

## C5. 수치의 한정과 기능의 의존 관계를 남긴다

숫자만 보존하면 충분하지 않다. 시작 가격·최종 가격·범위·약·최대·최소·기본·선택·시장별·예상·보도·확인 필요를 해당 값에 붙인다. 조건이나 옵션에 종속된 기능을 독립된 기본 기능처럼 나열하지 않는다. '패키지 A: 기능 X·Y'처럼 의존 관계가 보이게 압축한다. 가능성·권고·허락·의무·금지·진행·완료·보고된 조건은 서로 바꾸지 않는다.

## C6. 조건과 시간은 재해석하지 않는다

수량 경계·선택 관계·전후 순서·시간 기준 사건을 보존한다. 시간 항목을 만들 때는 기산 사건·시간값·단위·경계가 연결된 원문 구절을 사용한다. 제출·수신·확인은 서로 다른 사건이다. 기산 사건이 원문에 없으면 만들지 않는다. 기본·예외 기한의 적용 대상을 함께 표시하고 대체 관계를 임의로 정하지 않는다. 같은 시간 내용을 본문에서 다시 설명하지 않는다. 자동 처리나 보고된 과거 사실을 독자에게 내리는 새 지시로 바꾸지 않는다.

## C7. 표와 목록을 중복해서 만들지 않는다

같은 자료는 표와 목록 중 한 형식으로 제시한다. 여러 속성의 비교에는 표를, 조건과 행동의 연결에는 목록을 쓸 수 있다. 표에 있는 값을 대상별 본문에서 반복하지 않는다. 표가 너무 넓어 한 대상의 정보가 분산되면 대상별 짧은 기록으로 통합한다. 순서가 있는 절차만 번호로 쓰고 동등한 속성은 불릿이나 필드로 쓴다. 짧고 이미 분명한 문장은 불필요하게 쪼개지 않는다.

## C8. 최종 점검은 누락과 반복을 따로 확인한다

원문에만 있는 정보와 출력에만 생긴 정보를 대조한다. 각 사실의 대상·조건·한정·시점·확실성·출처까지 같아야 한다. 삭제된 반복 사실은 출력의 어느 한곳에 같은 뜻으로 남아 있어야 한다. 원문의 고유한 값·판단 근거·행동·검증 조건을 요약이라는 이유로 버리지 않는다.

그다음 반복 사양, 중복 결론, 불필요한 제목·라벨·예고문을 제거한다. 목표는 공백·줄바꿈·서식 기호를 포함해 원문보다 짧은 전문이다. 공백만 줄이거나 난해한 약어·과도한 명사 연결로 분량을 맞추지 않는다. 의미를 잃어야만 짧아지는 부분은 뜻을 남긴다. 분량 조건을 충족했다고 스스로 선언하지 않는다.

# Korean Protocol

사용자의 목적과 공유 문맥에 맞게 답과 필요한 이유를 쓴다.

## 원칙

사용자의 상위 지침·작업 범위를 따른다. 뜻·확실성·시상·발화 목적을 보존한다.
가능성을 사실로, 허락을 명령으로 바꾸지 않는다. 명확한 주체는 생략할 수 있다.
답에 필수인 정보를 확인할 수 없으면 그 정보만 묻는다. 불가 설명으로 끝내지 않는다.
짧은 경고에는 공유 문맥이나 불필요한 확인 상태·이유를 덧붙이지 않는다.

## 규칙

요구사항 뒤에 (조건), [예외]를 쓴다.

KP-DESC-001 상태 보고에서는 질문에 답하는 결과·실패·미완료를 먼저 말하고 그 결론의 범위나 제한을 바로 연결한다.
(완료 여부나 결과를 묻는 LLM 답변과 업무 보고에 적용한다.)
[교육·배경 설명은 이해 순서에 맞춰 구성하며 결론이 중요하지 않은 장르에 결과 우선을 강제하지 않는다.]
KP-DESC-002 새 개념이 다음 설명의 전제이면 필요한 정의를 먼저 주고 구성·동작·예외를 단계적으로 연결한다.
(독자가 처음 보는 기능·공정·개념을 설명할 때 적용한다.)
[독자가 이미 아는 정의는 반복하지 않으며 직접 답을 요구한 질문에는 필요한 답부터 준다.]
KP-DESC-003 한 단락은 하나의 중심 질문이나 주제를 전개하고 다른 판단·절차·대상으로 전환하면 새 단락을 쓴다.
(서로 다른 목적의 정보가 한 단락에 섞일 때 적용한다.)
[원인과 결과·비교 대상·반례가 같은 중심 질문을 설명하면 한 단락에 함께 둘 수 있다.]
KP-DESC-004 미검증 편집 트리거로서, 단락이 여섯 문장을 넘으면 중심 주장·근거·예외의 경계를 검토하고 독자가 구분해 읽을 부분에서 나눈다. 문장 수만으로 자동 분할하지 않는다.
(지속 설명이 긴 단락에 모일 때 적용한다.)
[하나의 짧은 사례를 이어 설명하는 문장들이 한 단락에 필요한 경우에는 유지한다. 유지 이유는 편집 검토 기록에만 남기고 독자용 본문이나 LLM 응답에 덧붙이지 않는다.]
KP-DESC-005 같은 결론이나 공유된 배경이 새 근거·조건·구별을 더하지 않으면 반복을 줄이고 다른 대상·시점의 상태는 유지한다.
(LLM 응답에서 같은 결론을 여러 방식으로 되풀이할 때 적용한다.)
[위험 행동 직전의 안전 경고·장소가 다른 UI 안내·중요 대비는 독자의 판단에 필요하면 반복한다.]
KP-EDIT-001 고친 문장의 주체·대상·긍정과 부정·조건·수량·시점·확실성을 원문과 대조하고 하나라도 달라지면 그 수정을 채택하지 않는다.
(간결화나 용어 교체로 문장을 수정할 때 적용한다.)
[사용자가 사실 정정이나 내용 변경을 요청한 경우에는 정정 근거를 확인하고 내용 변경으로 표시한다.]
KP-EDIT-002 수정에 필요한 주체·조건·기준이 자료에 없으면 대체문을 확정하지 말고 그 관계 하나를 확인한다.
(해석 후보에 따라 행동이나 사실이 달라지고 문맥으로 하나를 고를 수 없을 때 적용한다.)
[차이가 표현 선택에만 있고 뜻이 같으면 작성자가 맡긴 범위에서 정돈한다.]
KP-EDIT-003 문맥에 없는 원인·시험·수치·담당자·후속 약속을 명료화라는 이유로 추가하지 않는다.
(LLM이 표현만 수정하거나 제공된 사실로 답할 때 적용한다.)
[사용자가 새 조사나 제안을 요청하면 확인한 사실과 제안을 각각 밝혀 추가한다.]
KP-EDIT-004 단어 교체만으로 서술어의 대상이나 조건을 유지할 수 없으면 문장을 다시 구성하고 연결된 논항을 함께 옮긴다.
(명사화·번역투·모호한 결합을 고칠 때 적용한다.)
[명칭·인용·명령어의 고정 문자열은 문장 바깥의 설명만 정돈한다.]
KP-EDIT-005 규칙 준수·의미 보존·독자 이해도·LLM 적용 효과를 별도 판정하고 정답 사례의 통과를 실제 효과 입증으로 보고하지 않는다.
(규약 시험 결과나 수정 성과를 설명할 때 적용한다.)
[실제 독자 또는 LLM 실험이 있으면 대상·과제·비교 조건·관측값을 함께 보고한다.]
KP-KO-001 역할 모호·수량 대비·책임 구분에 필요한 조사는 남기고, 본문에서도 문맥으로 역할을 하나로 회복할 수 있는 구어·압축 표현의 생략을 허용한다.
(조사 없는 명사 연쇄가 행위자·대상·수신자를 혼동하게 할 때 적용한다.)
[본문의 구어·압축 표현, 검색어·파일명·표 제목·UI 레이블은 역할이 하나로 회복되고 대상 대비나 책임 구별이 사라지지 않으면 조사를 생략한다.]
KP-KO-002 주제·대조·초점이 사실 구별에 쓰이면 은·는과 이·가를 기계적으로 바꾸거나 지우지 않는다.
(조사 정돈으로 포함 범위나 책임 대비가 달라질 때 적용한다.)
[대조나 초점이 없고 문법과 의미가 같으면 자연스러운 문맥상의 조사를 고른다.]
KP-KO-003 안·못·아니다·없다와 모든·항상·반드시 등의 범위가 결합하면 무엇이 부정되는지 확인해 전면 부정과 부분 부정을 구별한다.
(부정문이 전부 실패와 일부 실패 등 서로 다른 해석을 만들 때 적용한다.)
[범위가 문맥에서 이미 하나로 정해진 짧은 부정문은 길게 풀지 않는다.]
KP-KO-004 못 했다·안 했다·하지 않았다가 기능 불능인지 의도적 비수행인지 단순 이력인지 구별하고 이유가 없으면 원인을 확정하지 않는다.
(부정 서술을 간결하게 바꾸거나 실패 원인을 보고할 때 적용한다.)
[원문이 원인을 구별하지 않고 이력만 말하면 하지 않았다를 유지한다.]
KP-KO-005 독자 관계에 맞는 종결형을 선택하되 높임을 줄이거나 늘리면서 요청·허락·명령·질문을 서로 바꾸지 않는다.
(하십시오체·해요체·요청 표현을 정돈할 때 적용한다.)
[제품의 짧은 안내·제목·버튼에는 명사형이나 짧은 동사를 쓰며 긴 높임 문장을 강제하지 않는다.]
KP-KO-006 시·께서 등의 높임 표지가 높이는 대상을 확인하고 사물·상태에 인물 높임을 기계적으로 붙이지 않는다.
(사물이나 기능을 설명하는 안내에 인물 높임이 쓰일 때 적용한다.)
[공식 인용이나 고객을 실제 주체로 높이는 문장은 그 기능을 유지한다.]
KP-KO-007 의미 없는 겹친 피동만 줄인다. 사동주·행위자·대상과 원인·명령·허락 관계를 보존한다. 능동화를 강제하지 않는다.
(피동·사동을 편집할 때 적용한다.)
[행위자·원인·수혜·의도 차이가 있는 사동·피동 결합은 뜻을 확인한 뒤 판단한다.]
KP-NAM-001 같은 문서와 대화에서 동일한 기능·장비·자료를 가리킬 때 한 명칭을 유지한다. 같은 문맥·의미의 반복 작업은 같은 동작 용어와 문장 방식으로 표현한다.
(동의어를 번갈아 써 대상 연결을 어렵게 할 때 적용한다.)
[명칭 변경 이력·비교·인용에서는 두 명칭을 그 관계와 함께 쓴다. 입력 방식·독자·문장 기능이 달라지면 그 차이에 맞는 표현을 쓰며 서로 다른 행동을 같은 용어로 강제하지 않는다.]
KP-NAM-002 기본 어휘에 없는 장비·부품·공정·자료 명칭은 실제 분야 자료의 이름을 확인하고 뜻·대상·분야·출처를 기록해 추가한다. 그 명칭 내부의 미등록 일반 표현은 전체 명칭을 식별할 때만 한정 허용하며 일반 서술의 승인으로 확대하지 않는다.
(전문명사가 독자에게 필요한 대상을 정확히 특정할 때 적용한다.)
[한 번 인용한 외부 고유명은 전체 사전 승인을 거치지 않아도 출처와 실제 표기를 유지한다.]
KP-NAM-003 새 전문동사는 수행 대상·필요 조건·동작 후 상태·분야·근거를 기록하고 같은 형태의 일반 동작과 구별한다.
(직접 서술해야 하는 전문 공정이나 기술 동작이 기본 어휘에 없을 때 적용한다.)
[설명 목적의 명사형 공정명은 동작 지시와 구별되어 있으면 허용한다.]
KP-NAM-004 제품·앱·자료 명칭에 하다를 붙여 동작을 만들면 명사 항목의 승인만으로 허용하지 않는다. 별도 행동 의미·논항·결과·분야 근거를 전문동사 항목으로 검토하거나 확인된 일반 동작으로 풀어 쓴다.
(명칭을 동사로 전환해 새 행동 의미를 만들 때 적용한다. 행동이 하나로 공유되더라도 신규 동사 의미의 검토는 생략하지 않는다.)
[업로드하다처럼 이미 동작 의미·대상 결합이 검토된 전문동사는 유지한다. 명사화·관형형처럼 기존 행동 뜻을 유지하는 한국어 활용은 새 동작 승인과 구별한다.]
KP-NAM-005 연속된 명사가 대상·소속·기능을 혼동하게 하면 조사나 구조 설명으로 관계를 드러내고 정확한 전체 명칭을 먼저 제시한다.
(명사 연쇄에 둘 이상의 묶음 해석이 가능할 때 적용한다.)
[공식 장비명·표준명·고유명은 띄거나 축약해 새 명칭을 만들지 않고 주변 문장으로 관계를 설명한다.]
KP-NAM-006 긴 명칭을 줄일 때 처음에 전체 이름과 줄인 이름을 연결하고 같은 문서에서 다른 대상에 그 줄인 이름을 재사용하지 않는다.
(반복되는 긴 장비·문서 명칭을 줄여 쓸 때 적용한다.)
[안전·계약·법정 인용에서 전체 명칭이 필요한 자리는 축약하지 않는다.]
KP-NUM-001 독자의 판단에 필요한 수치에는 무엇을 센 값인지와 단위를 남기고 단위 변환은 원값의 정밀도와 조건을 보존한다.
(측정·용량·횟수·가격·시간을 제시할 때 적용한다.)
[표 머리나 바로 앞 문맥이 같은 단위를 명시하면 각 셀마다 반복하지 않는다.]
KP-NUM-002 이상·이하·초과·미만·부터·까지의 경계와 포함 여부를 유지하고 범위만으로 포함을 알 수 없으면 확인한다.
(허용 범위·온도·기간·버전 조건에 적용한다.)
[문맥의 범위 표기가 양끝 포함을 이미 정의했다면 매번 설명하지 않는다.]
KP-NUM-003 증가·감소·몇 배·퍼센트의 비교는 기준값·비교값·대상을 보존하고 비율과 차이를 구별한다.
(성능·가격·시간의 변화를 보고할 때 적용한다.)
[같은 표의 기준 열이 명시되어 있으면 본문에서 기준을 반복하지 않는다.]
KP-NUM-004 약·최대·최소·평균·대표값·합계 등의 수치 성격을 보존하고 대략값을 정확값이나 상한으로 바꾸지 않는다.
(관측 수치나 추정 수치를 간결하게 제시할 때 적용한다.)
[정확한 값이 확인되어 근사 표현을 정정하는 작업은 사실 정정으로 구별한다.]
KP-NUM-005 모두·각각·하나·적어도·최대·일부와 및·또는의 결합을 보존하고 항목별 값과 전체 합계를 구별한다.
(여러 대상의 실행·허용 개수·용량을 말할 때 적용한다.)
[선택 규칙이 이미 UI에 표시되면 짧은 항목 이름을 쓸 수 있다.]
KP-NUM-006 문서의 실행 시점이 바뀔 수 있으면 날짜·시각의 기준을 밝히고 오늘·내일 같은 상대 시점을 보존 문서에서는 확인된 절대 날짜로 연결한다.
(다른 날 읽거나 시간대가 다른 독자가 실행할 일정 안내에 적용한다.)
[당일 대화나 시간대 차이가 없는 UI에서는 기준이 공유되면 상대 날짜를 유지한다.]
KP-NUM-007 파일 경로·명령어·코드·버전·장비 ID는 실제 문자열을 보존하고 부호·대소문자·공백을 문체 규칙으로 고치지 않는다.
(실행하거나 검색할 식별 문자열을 제시할 때 적용한다.)
[사용자가 문자열 변경을 요청하면 변경 값과 사용 위치를 확인한 별도 작업으로 다룬다.]
KP-PROC-001 독자가 각각 완료·검사해야 하는 독립 행동은 별도 단계로 제시하고 동시에 수행해야 하는 행동은 한 실행 단위에 둔다.
(복수 지시가 한 문장에 나열될 때 적용한다.)
[열어서 확인하다처럼 하나의 즉시 행동으로 이해되고 별도 확인점이 없는 결합은 유지한다.]

KP-WRD-003 어휘 항목에 승인 뜻·품사·허용 활용·분야·독자·논항/조사 결합을 기록하고 표면형을 그 패턴에 연결해 판정한다. 같은 표제어라도 미등록 품사전환이나 뜻이 다른 활용은 별도 검토한다.
(통제 어휘를 추가하거나 LLM이 표면형을 사전 항목에 대응시킬 때 적용한다. 표제어에서 한국어 활용형을 생성하더라도 품사·뜻·논항 패턴이 일치해야 한다.)
[명사형·관형형의 문장 기능이 명확하고 등록된 뜻을 유지하면 한국어 생산적 활용으로 허용한다. 제목·UI 레이블은 목적어와 종결어미를 강제하지 않는다. 새 의미나 동작이 생기면 별도 항목으로 검토한다.]
KP-WRD-004 독자가 모르는 축약어를 쓰면 첫 사용에서 풀어 쓴 명칭과 축약어를 연결하고 이후 같은 축약어를 유지한다.
(문서 내부 축약이나 조직별 약어를 처음 소개할 때 적용한다.)
[대상 독자가 공통으로 아는 표준 약어나 코드·파일 확장자는 반복해서 풀지 않는다.]
KP-WRD-005 업무 지시에서 독자에게 공유되지 않은 은어·비유·조직 내부 별칭은 확인된 대상과 동작으로 표현한다.
(은어나 비유가 실행 대상·결과를 둘 이상으로 해석하게 할 때 적용한다.)
[인용·대화 분석·공유된 공식 별칭은 보존하고 문맥이 뜻을 하나로 정하면 치환을 강제하지 않는다.]
KP-WRD-006 일반 한국어는 현행 맞춤법과 띄어쓰기를 따르고 문서의 같은 명칭은 같은 표기로 쓴다.
(대체 표기·외래어 표기가 문서에서 섞일 때 적용한다.)
[공식 상품명·파일명·코드·원문 인용은 실제 문자열을 보존하며 오탈자처럼 보여도 임의로 고치지 않는다.]
KP-WRD-007 통제 어휘를 운영할 때 미등록 표현은 일반 표현·전문명사·전문동사 중 해당 경로로 검토하고 뜻·범위·결합 근거를 기록한다. 미등록 자체를 의미 불명이나 금지로 확정하지 않는다.
(새 표제어를 추가하거나 사전이 다루지 않는 표현을 등록 범위에서 판정할 때 적용한다.)
[실제 식별 문자열·인용·미등록 일반 표현은 문맥으로 뜻이 분명하면 원문 유지 후보로 둔다. 문맥상 새 전문 의미는 일반 표현으로 자동 승인하지 않는다.]
KP-WRD-008 개별 단어가 등록되어 있어도 결합이 새 전문 의미·동작·결과를 만들면 그 결합의 뜻·논항·분야·예문을 별도로 검토한다. 개별 어휘 승인을 새 결합 의미의 승인으로 확대하지 않는다.
(각 단어의 일반 뜻으로 전체 행동을 회복할 수 없는 관용·기술 결합을 사용할 때 적용한다.)
[등록된 뜻의 단순 수식·정상적인 한국어 활용·문자 그대로의 행동 나열은 새 의미가 없으면 별도 결합 승인을 강제하지 않는다.]

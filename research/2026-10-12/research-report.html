  • ‘문제가 있을 수 있습니다’는 문제의 가능성을 알리는 문장이다. 가능성이라는 의미가 있다는 이유만으로 모호한 표현으로 분류하지 않는다. 대상이 이미 공유된 문맥에서는 원문을 그대로 유지하는 것을 유효한 선택지로 둔다.
  • ‘동시 접속 시험을 하지 않아 최대 접속 수를 확인하지 못했습니다’는 시험 이력과 지식의 한계를 보고한다. 앞의 경고와 전달 내용이 달라 명료함을 비교하는 대체문으로 사용할 수 없다. 시험 이력이 확인되지 않았다면 이 문장을 추가하는 것은 사실 창작이다.
  • ‘오류를 적절히 처리하세요’의 문제는 처리 기준이 없는 문맥에서 수행할 행동을 결정하기 어렵다는 것이다. 특정 복구 행동을 임의로 추가해서는 안 된다. 공유된 절차가 있는지 확인하고 필요한 경우 그 절차나 실제 행동을 명시한다.

문헌에서 확인한 내용

ASD STE100의 통제 대상과 한국어로 옮길 대상을 구분한다

ASD-STE100은 통제 어휘와 작성 규칙을 결합하고 절차문과 설명문을 구분한다. 영어의 단어 수 상한이나 승인 어휘를 한국어 어절 수와 단어 치환표로 그대로 바꿀 근거는 확보하지 못했다. 한국어판의 기초 단위는 단어뿐 아니라 조사·서술어·논항·어미가 이루는 표현 패턴까지 포함해야 한다는 것이 이 연구의 설계 제안이다.

짧음과 읽기 쉬움은 같은 척도가 아니다

한국어 모어 화자의 관계절 처리 연구는 같은 종류의 구문 안에서도 문장 성분의 역할 관계에 따라 처리 부담이 달라짐을 보여준다. 외국어 학습자를 위한 한국어 교재 난이도 연구도 어휘와 문법을 함께 고려한다. 따라서 문장 길이는 점검 신호로 쓰되, 글자 수를 줄였다는 이유만으로 개선으로 판정하지 않는 것이 타당하다.

주어 생략은 문맥과 함께 평가한다

생략된 주어가 있는 문장을 처리하는 한국어 실험에서 앞 문장의 주어와 연결되는 경우 이해가 빨랐다. 이는 모든 문장에 주어를 다시 쓰도록 강제하는 규칙을 재검토할 근거다. 주체가 이어지고 경쟁하는 지시 대상이 없으면 생략을 허용하고, 주체가 바뀌거나 헷갈리면 명시하는 방식을 시험한다.

근거 1

초록을 확인했다. 생략문이 명시문보다 항상 우수하다는 직접 비교 결과는 아니다.

어휘는 어종보다 익숙함과 의미 구별을 기준으로 고른다

한국어 명사 어절의 안구운동 실험에서는 고빈도 조건의 읽기 시간이 저빈도 조건보다 짧았다. 한자어 말뭉치 연구는 실제 사용 분포를 따로 살필 필요를 보여준다. 따라서 한자어 여부만으로 단어를 배제하기보다, 독자에게 익숙한 의미와 용례를 확인하고 같은 개념을 일관되게 표현하는 방식을 연구한다.

가능성 표현은 의미를 담당한다

한국어 양태 연구는 ‘수 있다’가 문맥에 따라 가능성·능력·허락 등을 나타낸다는 점을 분석한다. 이 표현을 일괄 삭제하면 가능성을 사실로 바꾸거나 허용과 능력을 혼동한다. ASD 공식 FAQ도 가능성을 나타내는 경고 예문을 사용한다. 단정한 문체의 목표는 과도한 확신이 아니라, 확실한 것은 확실하게 불확실한 것은 짧고 정확하게 말하는 것으로 설정한다.

근거 1 · 근거 2

한국어 논문은 초록 확인 수준이다. 양태 분석은 사용자의 특정 경고문에 대한 효과 실험이 아니다. 한국어 양태에 고정된 확률 수치를 부여하지 않는다.

한국어 종결표현은 문장의 기능과 함께 연구한다

한국어 모어 화자를 다룬 강현화·홍혜란의 연구는 같은 종결표현이 여러 기능을 수행하고 상황에 따라 선택이 달라진다고 보고한다. 요청·권유·허락·명령을 같은 직접 명령형으로 통일하면 전달하려는 뜻과 관계가 달라진다. 단정한 문체를 연구할 때에는 어미를 짧게 만드는 것과 문장의 기능을 보존하는 것을 함께 평가한다.

군대의 말투와 군사 의사소통의 원리를 구분한다

함께 고려해야 할 반례

  • 생략은 반복을 줄이지만, 지시자가 공유 지식을 잘못 가정하면 명령 이해를 해친다. 허용 조건은 무조건 짧게가 아니라 독자가 같은 대상을 회복할 수 있는가로 둔다.
  • 전문용어는 익숙한 사용자에게 짧고 정확하지만 비전문가에게는 부담이다. 독자와 분야를 정하지 않은 전역 쉬운 말 치환표는 피한다.
  • 통제언어는 이해 점수를 개선해도 자연스러움·사용성·모호함 평가를 모두 개선하지는 않는다. 객관적 이해와 체감 문체를 함께 측정한다.
  • 한국어 기계번역 연구의 통제 규칙은 당시 번역기의 분석 실패를 줄이려는 것이었다. 한국어로 적법한 구문을 기계가 어려워한다는 이유로 사람이 읽는 규약에서도 금지하지 않는다.

검증할 한국어 규칙 후보

아래 항목은 문헌을 바탕으로 만든 설계 가설이며, 이미 검증된 한국어 규격이 아니다.

  • 행동을 나타내는 불필요하게 돌아가는 구성을 직접적인 서술어로 정돈한다. 다만 시작·진행·완료의 구별을 없애지 않는다.
  • 절차에서는 행동과 순서를 분리해 읽을 수 있게 구성하고, 설명에서는 연결 관계를 보존한다. 모든 문장을 무조건 한 절로 쪼개지는 않는다.
  • 어휘 항목에는 표제어만 넣지 않고 허용 의미, 결합하는 대상과 서술어, 분야 예외, 반례를 함께 기록한다.
  • 지시·보고·경고·설명을 서로 다른 문장 기능으로 구분한다. 경고를 보고로 바꾸거나 권고를 의무로 강화한 수정은 명료화로 승인하지 않는다.
  • 주어·목적어를 매번 반복하지 않고 문맥에서 회복 가능한지 판정한다. 독자에게 선택지가 둘 이상 생기는 경우에는 대상을 밝힌다.
  • 관형절·접속절·명사화를 금지하기보다 수식 관계가 얽히거나 서술어 해석을 오래 미루게 만드는 구조를 우선 시험한다.
  • 한자어와 전문어는 친숙도와 개념 구별에 따라 유지하거나 풀어 쓴다. 같은 문서에서 같은 개념의 이름을 불필요하게 바꾸지 않는다.
  • 종결형은 분야와 독자에 맞춰 일관되게 고른다. 공손함을 없애거나 권위적인 어조를 강화하는 것을 간결화의 목표로 삼지 않는다.
  • 불확실성의 이유·영향·확인 방법은 판단에 필요할 때 추가한다. 모든 가능성 문장 뒤에 설명을 의무적으로 붙이지 않는다.

연구를 규약으로 연결하는 순서

1단계

실제 한국어 LLM 응답과 기술 지침에서 문맥이 포함된 원문을 수집한다. 지시·보고·경고·설명을 구분하고 사용자가 답답하게 느낀 표현을 표시한다.

원문·문맥·발화 목적·문제 유형을 가진 사례집을 만든다. 자동 생성 예문만으로 구성하지 않는다.

2단계

한국어 의미·화용 전문가가 뜻과 확실성의 보존을 검토하고, 통사·어휘 전문가가 대체 표현을 작성한다. 군사·기술문서 전문가는 실제 절차와 분야 용어가 맞는지 확인한다.

규칙마다 적용 조건, 예외, 반례, 근거 수준을 기록한 후보 규칙을 만든다.

3단계

원문, 짧게 정돈한 문장, 설명을 늘린 문장을 같은 사실관계와 문맥으로 비교한다. 버전 노출 순서를 무작위화하고 같은 참가자가 같은 내용에 반복 노출되는 학습 효과를 통제한다.

이해 정확도와 판단 시간, 재독·추가 질문, 주관적 자연스러움·부담·단정함을 각각 측정한다. 표본 수는 예비실험 후 정한다.

4단계

문헌과 의미 보존 검토로 만든 후보 규칙을 독자 시험에 따라 채택하거나 수정한다. 전문가와 비전문가의 결과를 나누어 보고, 서로 다른 LLM에 적용해 사실 누락과 과도한 확신이 늘지 않는지 확인한다.

사람 검토용 규약, LLM용 지침, 검사 가능한 항목과 사람 판단이 필요한 항목을 분리한 검사 명세를 만든다.

필요한 전문 분야

  • 한국어 통사론 전문가는 조사·논항·생략·관형절·서술어 구조를 검토한다.
  • 한국어 의미론·화용론 전문가는 가능성·의무·허락·추측과 지시·보고·경고의 기능을 검토한다.
  • 어휘론·말뭉치 전문가는 친숙도·빈도·다의성·분야별 용어 일관성을 검토한다.
  • 군사 명령·보고 또는 기술교범 전문가는 공유 절차와 필요한 정보의 범위를 검토한다.
  • 심리언어학·인간공학 전문가는 독자 시험의 자극·설계·측정·분석을 검토한다.

국립국어원 2016 보고서의 지시·보고 교육과 한국어 통사·양태 연구를 바탕으로 문맥을 보존한 대체문 후보를 만든 뒤, 한국어학·기술교범 전문가 검토와 모어 독자 비교시험을 진행한다. 규칙의 문장 수나 금칙어 목록부터 확정하지 않는다.

근거의 범위와 남은 검증

  • 이 연구는 문헌 조사이며 실제 한국어학 박사나 군사 전문가에게 자문을 받은 결과가 아니다.
  • 국어학 논문 중 초록만 확인한 자료가 있으므로 개별 실험 설계·수치·결과를 확인 범위 밖으로 확장하지 않는다.
  • 한국군의 현행 명령 작성 규정과 복명복창 효과의 직접 실험은 아직 확인하지 못했다.
  • 한국어 LLM 응답에서 제안 규칙이 답답함과 추가 질문을 줄인다는 직접 실험은 수행하지 않았다.
  • 이 연구는 신규 프로젝트명·저장소명·공식 한국어 규격을 확정하지 않는다.

소통이라는 이름의 기존 사용

소통이라는 이름은 한국어 표현과 전달 방식을 다듬는 목적에 맞는다. Sotong은 기존 사용이 많아 단독 이름의 식별력이 낮다. Soh-tong은 이번 공개 검색에서 충돌이 덜했지만 프로젝트명으로 확정하지 않았다.

SOTONG / 소통 문자통역 앱: 공식 서비스 사이트의 실시간 본문에서 이름 사용을 확인했다.

choonkeat/sotong: GitHub API에서 동일명 Ruby 프록시 저장소를 확인했다. 다른 소유자의 동일명 저장소는 새 소유자 아래 저장소 생성 자체를 막지 않는다.

PyPI sotong: PyPI JSON API가 200을 반환했고 작은 자동화 도구로 등록돼 있다.

npm sotong: npm 레지스트리 API가 200을 반환했고 placeholder release로 등록돼 있다.

GitHub soh-tong 이름 검색 결과는 두 건 모두 다른 긴 이름이었으며 정확히 일치하는 저장소는 없었다. PyPI와 npm의 soh-tong 조회는 모두 404였다. 검색 미발견은 상표·도메인 가용성 보증이 아니다.

검색 색인에는 sotong.ai의 AI 사업 소개가 있었지만 실시간 Firecrawl 확인에서 Site not found가 나와 현재 운영 사례로는 사용하지 않았다.

Korean Protocol이라는 후보

규약의 성격을 드러내는 이름이지만 언어 표현이라는 대상이 이름만으로 명확하지 않다. 한국어 소통을 위한 표현 규약이라는 설명을 붙이는 방안을 검토한다. 글쓰기 범위를 명시하려면 Korean Writing Protocol이 더 구체적이다.

2026-10-12 공개 검색과 GitHub 저장소 검색에서 korean-protocol 및 korean-writing-protocol의 정확히 일치하는 저장소를 찾지 못했다. PyPI와 npm의 두 이름 조회는 모두 404였다. GitHub 검색은 공개 저장소 범위이며 상표와 도메인은 확인하지 않았다.

Ultra 4x 결과와 원문 대조

  • Ultra 4x 결과는 한국어의 단어 빈도, 종결표현과 문장 기능, 생략·어순·피동, 군 조직 의사소통, 불확실성 전달 연구를 추가로 연결했다. 단어 빈도 실험과 종결표현 연구는 Firecrawl로 다시 확인해 선별 문헌에 추가했다.
  • Ultra 결과가 확보하지 못한 국립국어원 2016 군 언어 보고서는 별도 조사에서 공식 PDF를 확보하고 해당 쪽을 확인했다. 최종 결론은 이 국내 원문을 반영하며, 이를 현행 군 작전명령 규정으로 소개하지 않는다.
  • Ultra 결과의 원문 접근 표시는 서비스가 확보한 범위다. 이 통합 보고서의 문헌 목록에는 로컬 조사에서 확인한 원문·초록·서지 범위를 별도로 기록했다. 외부 분석이 인용한 모든 문헌을 로컬에서 정독했다고 주장하지 않는다.
  • 최신성이 확인되지 않은 군 교리, 발행 정보가 미확정인 저자 원고, 직접 재검증하지 않은 모델 평가 자료는 확정 규칙의 근거로 추가하지 않았다. 모어 독자 실험과 L2 교재 연구를 구분했다.
  • Sotong·Soh-tong·Korean Protocol 명칭 조사는 Ultra 실행 후 추가된 사용자 질문에 대한 별도 확인이다. 이름 조회의 미발견 결과를 상표 가용성 보증으로 해석하지 않았다.

선별 문헌과 확인 범위

논문 원문, 초록, 공식 규범, 교육자료와 보도자료는 서로 다른 수준의 근거로 취급했다. 아래 기록은 각 자료에서 직접 확인한 범위를 밝힌다.

1. 생략된 주어가 있는 문장 처리에 담화특출성이 미치는 영향

['송현주', '윤정은'] · 2007

출처 원문 또는 학술 서지 페이지

학술지 페이지의 서지와 초록을 Firecrawl로 확인했으며 PDF 원문은 읽지 않았다.

읽기와 듣기 실험 모두에서 생략된 주어가 앞 문장의 주어를 이어받을 때 이해가 빨랐다. 생략의 처리 부담은 담화 내 지시 대상의 연속성과 관련된다.

생략문과 주어 명시문을 직접 비교한 결과가 아니므로 생략이 명시보다 언제나 빠르다는 결론을 지원하지 않는다.

2. Subject/object processing asymmetries in Korean relative clauses: Evidence from ERP data

['Nayoung Kwon', 'Robert Kluender', 'Marta Kutas', 'Maria Polinsky'] · 2013

출처 원문 또는 학술 서지 페이지

Firecrawl로 공개 원문을 확보하고 초록, 방법, 참가자, 결론 부분을 확인했다. 원문 전체를 정독했다고 주장하지 않는다.

한국어 모어 화자 22명의 ERP 실험은 목적격 관계절보다 주격 관계절의 처리 우위를 보고한다. 한국어 관계절의 처리에는 단순 길이 이외에 내부 역할 관계와 구조가 중요하다.

담화 맥락이 없는 문장과 두 사람 사이의 가역적 사건을 사용했다. 모든 기술문서 관형절 금지나 특정 어절 수 상한을 검증한 연구가 아니다.

3. 한국어 읽기 텍스트의 난이도 측정 공식 개발에 관한 연구

['이보미'] · 2020

출처 원문 또는 학술 서지 페이지

KCI 서지와 초록을 Parallel Search에서 확인했다. 원문은 읽지 않았다.

한국어 교재 4종의 160개 텍스트에서 문법, 어휘, 문장 길이 난이도가 등급과 상관을 보였으나 최종 회귀모형은 문법 난이도와 어휘 난이도를 포함했다.

외국어 학습 교재의 등급 예측 연구다. 모어 화자의 기술문서 이해에 동일 계수를 적용하거나 문장 길이가 무관하다고 결론 내릴 수 없다.

4. 현대 한국어의 한자ㆍ한자어의 빈도 및 분포에 대한 계량적 분석과 그 활용

['한영균'] · 2017

출처 원문 또는 학술 서지 페이지

서지, 영문 초록, 목차를 Firecrawl로 확인했다. 원문은 읽지 않았다.

300만 단어 규모의 균형 말뭉치를 한자화해 빈도와 분포를 분석하고 초급 학습용 한자 및 한자어 목록을 제안했다. 초록은 한자어의 텍스트 점유율이 통상 생각하는 것보다 높다고 보고한다.

분포 연구이며 한자어와 고유어 대체문의 이해도를 직접 비교한 실험은 아니다. 한자어의 전면 허용 또는 금지 근거로 삼을 수 없다.

5. 번역투 인지가능성과 가독성에 대한 소고

['오미형'] · 2015

출처 원문 또는 학술 서지 페이지

서지와 영문 초록을 Firecrawl로 확인했다. 원문은 읽지 않았다.

대학생 31명이 번역투를 포함한 27개 문장과 한 지문을 평가했으며, 번역투를 항상 낮은 가독성으로 평가하지 않았다.

작은 표본의 주관적 평가 연구다. 모든 번역투가 무해하다거나 피동문과 능동문의 이해도가 동일하다는 결론을 지원하지 않는다.

6. 한국어의 양태 표현 교육 연구: 한국어 ‘-(으)ㄹ 수 있다’와 중국어 ‘능(能)’의 대조를 중심으로

['강비'] · 2019

출처 원문 또는 학술 서지 페이지

저자, 서지, 초록을 Parallel Search에서 확인했다. 원문은 읽지 않았다. 페이지 내 AI 요약과 질의응답은 근거로 사용하지 않았다.

‘-(으)ㄹ 수 있다’를 통사, 의미, 화용 측면에서 대조 분석하며 한국어 양태 표현의 의미와 기능이 다양함을 명시한다.

한중 대조 및 교수법 연구다. ‘문제가 있을 수 있습니다’의 경고 효과나 근거 설명 추가의 효용을 검증한 논문은 아니다.

7. 한국어교육에서의 양태 표현 연구

['이윤진', '노지니'] · 2003

출처 원문 또는 학술 서지 페이지

서지와 영문 초록을 Parallel Search에서 확인했다. 원문은 읽지 않았다.

추측과 의지의 양태 표현들을 구분하며 공손성이 이들 의미와 밀접하게 연결됨을 논의한다.

교육 문법 연구이며 기술문서 종결형의 최적 조합을 검증하지 않았다.

8. 공공언어 요건 정립 및 진단 기준 개발 연구

민현식 연구책임, 국립국어원 · 2010

출처 원문 또는 학술 서지 페이지

국립국어원 첨부 PDF 원문을 내려받아 텍스트를 검색했다. 특수 글꼴 때문에 일부 추출이 누락되어 PDF 341·419·432쪽을 이미지로 렌더링하고 확인했다. 전체 485쪽을 정독한 것은 아니다.

인쇄 317쪽 표174는 정확성과 소통성을 구분하고 소통성의 장르별 가중치를 명시한다. 정보량·구성·문장길이·친숙한 용어·어조를 별도 항목으로 평가하며 고압적·권위적 표현을 경계한다.

공공언어 진단 체계이며 통제한국어의 개별 규칙을 검증한 실험은 아니다. 표174는 기준 요약이며 본 프로젝트의 검증된 가중치로 재사용하지 않는다.

9. 임무형지휘 관련 국내 연구 동향 분석

정요섭·박효선(청주대학교), 차세대융합기술학회논문지 8(8), 1836–1848 · 2024

출처 원문 또는 학술 서지 페이지

Firecrawl로 KCI 서지·국영문 초록 확인; 논문 본문 미확인

국내 논문 143건을 분석하고 지휘통제 접근법, 원칙 교육, 척도·평가지표 개발을 향후 연구방향으로 제시한다.

언어 표현별 가독성 실험이나 한국군 공식 문체 규정을 확인한 자료가 아니다.

10. 군(軍) 임무형 지휘의 효과성 제고를 위한 리더십 발전방향

장순배(육군보병학교), 인문사회21 12(5), 955–970 · 2021

출처 원문 또는 학술 서지 페이지

Firecrawl로 KCI 서지·국영문 초록 확인; 본문 다운로드 기능은 있으나 본문 미확인

문헌조사와 육군 대위급 장교 35명 면접을 바탕으로 군대문화, 상황에 맞는 리더십, 임파워먼트를 강조한다.

조사 방법과 기준일

2026년 10월 12일을 기준으로 Parallel Search의 basic 모드에서 STE·한국어학·군사 의사소통·명칭을 나누어 조사했다. 요청한 Ultra 4x 등급은 ultra4x-fast 처리기로 한 건 실행했고 완료 결과를 받았다. Firecrawl scrape는 원문 검증에 사용했으며 기본 maxAge는 3600000ms, 이름 사용의 현재 사이트 확인에는 0을 사용했다. PDF 일부는 내려받아 텍스트를 검색하고 필요한 쪽을 이미지로 확인했다. 초록·원문·규범·실험을 구분해 종합했다.

별도 에이전트가 근거 기록과 초안의 정합성을 읽기 전용으로 검토했다. 실제 학계·군사 전문가 자문은 아니다.

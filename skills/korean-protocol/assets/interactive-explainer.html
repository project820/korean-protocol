사용 조건에 따른 전력 소비량을 계산한다

소비전력·하루 사용 시간·사용 일수를 바꾸면 전력 소비량을 다시 계산한다.

이 계산은 교육용 가상 예시다. 실제 소비전력의 변화·대기 전력·전기 요금을 반영하지 않는다. 실제 설비의 관측값이나 안전·용량 보장으로 사용하지 않는다.

가정에 따른 전력 소비량

96kWh

0.8kW × 6시간/일 × 20일 = 96kWh

입력 오류가 있어 결과 계산을 보류한다. 표시한 입력 조건을 확인해야 한다.

가정: 소비전력이 일정하다.

사용 조건

0~100kW를 0.01kW 단위로 입력한다.

소비전력을 0~100kW 범위에서 0.01kW 단위로 입력해야 한다.

0~24시간을 0.25시간 단위로 입력한다.

하루 사용 시간을 0~24시간 범위에서 0.25시간 단위로 입력해야 한다.

1~366일을 정수로 입력한다.

사용 일수를 1~366일 범위의 정수로 입력해야 한다.

산출식

전력 소비량 = 소비전력 × 하루 사용 시간 × 사용 일수다. 이 식은 위의 일정 소비전력 가정에만 적용한다.

참고

예제의 입력 범위는 화면 탐색을 위해 정했다. 설비의 허용 운전 범위를 뜻하지 않는다.

가상 초기값
소비전력은 0.8kW, 하루 사용 시간은 6시간, 사용 일수는 20일로 설정했다. 실제 관측 출처는 없다.
표시 정밀도와 계산 범위
표시값은 소수점 아래 최대 네 자리로 반올림한다. 전기 요금·세금·장비 효율은 계산하지 않는다.
저장·전송 여부
입력값을 서버에 전송하거나 저장하지 않는다. 초기화하면 가상 자료의 초기값으로 돌아간다.

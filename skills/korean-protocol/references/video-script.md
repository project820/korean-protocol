# 명시 요청한 애니메이션 코드와 내레이션을 연결한다

사용자가 영상화·애니메이션 스크립트를 명시 요청할 때만 읽는다. 요청한 범위에서 Manim Python 코드와 장면별 한국어 내레이션 대본을 만든다. 코드를 만들었다는 사실은 렌더링·TTS 합성·영상 완성을 뜻하지 않는다.

## 장면과 발화를 같은 주장에 연결한다

- 장면마다 식별자를 붙이고 코드·대본에서 같은 식별자를 사용한다. 대상·수치·단위·조건·출처가 어느 장면에 나타나는지 대응시킨다. 조건·경고는 관련 행동이나 결론보다 먼저 또는 함께 제시한다.
- 내레이션은 한 문장에 중심 주장 하나를 둔다. 청자가 듣고 구별해야 하는 단위·부호·약어는 발화에서 뜻을 풀되 화면의 보호 문자열은 그대로 유지한다. 풀어 쓴 발화가 원문 수치·단위를 바꾸지 않는지 대조한다.
- 장면 전환으로 근거 없는 인과·선후·주체를 만들지 않는다. 두 사실의 병치는 화살표로 연결하지 않는다. 가정·전언·불확실성은 화면과 대본에 같은 상태로 나타낸다.
- 사용자가 요청하지 않은 화자 흉내·브랜드·스타일 자산은 추가하지 않는다. 설명에 필요한 도형·강조·움직임을 사용한다. 한국어 표시에는 설치된 한국어 글꼴과 Manim 버전을 확인하고, 확인하지 못한 환경 요건을 명시한다.

## 대본과 화면을 듣고 보기 쉽게 만든다

- 발화만 담은 TTS 입력 파일을 따로 만든다. 장면 식별자와 발화문만 둔다. 화면 설명·제작 메모·근거 위치는 별도 표나 파일에 둔다. 한 파일에 발화와 제작 메모를 섞으면 TTS에 그대로 넣을 수 없다.
- 내레이션은 높임말 없이 ‘한다’체로 쓰고 ‘대표님’ 같은 호칭을 넣지 않는다. 화면 문구는 짧은 명사구나 판단문으로 쓴다. 사용자가 어체를 정하면 그 지정을 따른다.
- 1920×1080, `frame_height = 8` 기준으로 렌더링 후 본문 글자 크기가 `font_size` 24 이상이 되게 한다. 상자에 맞추려고 글자를 축소하지 않는다. 문구가 넘치면 문구를 줄이거나 장면을 나눈다. 한 화면의 본문은 다섯 줄 안팎으로 둔다.
- 화면에 내부 파일명·경로를 표시하지 않는다. 출처는 독자가 아는 문서명과 절·쪽으로 쓴다.
- 글자 카드가 나타났다 사라지는 장면만 이어 붙이지 않는다. 바뀌는 값·비교·분기는 막대·수직선·변환 애니메이션으로 보여준다. 예를 들어 두 금액의 차이는 막대 길이와 차이 구간으로 표시한다.
- 시간표·대응표의 머리글은 ‘장면’·‘시간’·‘화면 강조’처럼 명사구로 쓴다.

## 장면별 코드를 대본과 함께 제공한다

다음 예시는 ‘소비전력은 0.8kW로 일정하다고 가정한다. 하루 6시간씩 20일 사용한 전력 소비량을 계산한다’는 가상 자료다. 실제 설비의 관측값으로 사용하지 않는다.

```python
from manim import Scene, Text, VGroup, DOWN, Write, FadeOut


class EnergyExample(Scene):
    def construct(self):
        # S01: 가정과 단위를 먼저 표시한다.
        assumption = Text("가정: 소비전력 0.8kW 일정", font_size=32)
        self.play(Write(assumption))
        self.wait(4)  # 임시 길이다. 실제 음성 길이에 맞춰 조정한다.
        self.play(FadeOut(assumption))
        # S02: 근거값·산출식·결과를 같은 장면에 둔다.
        equation = Text("0.8kW × 6시간/일 × 20일 = 96kWh", font_size=32)
        caption = Text("가정에 따른 전력 소비량: 96kWh", font_size=26)
        group = VGroup(equation, caption).arrange(DOWN)
        self.play(Write(group))
        self.wait(6)  # 실제 TTS 음성의 재생 시간은 아직 측정하지 않았다.
```

| 장면 | 내레이션 |
|---|---|
| S01 계산 가정 | “소비전력은 영 점 팔 킬로와트로 일정하다고 가정한다.” |
| S02 값·식·결과 | “하루 여섯 시간씩 이십 일 사용한다. 전력 소비량은 구십육 킬로와트시다.” |

‘96kW’나 ‘전기 요금은 96이다’로 바꾸면 계산 대상·단위가 달라진다. 가정을 생략하고 실제 소비량을 측정했다고 설명해도 실패다. 대본의 발화 표기는 TTS 입력이며 원문 보호 문자열의 교체본으로 사용하지 않는다.

## 실행 상태를 실제 확인 범위로 표시한다

코드만 요청받으면 코드와 대본을 제출한다. 렌더링이나 합성이 요청 범위에 있으면 사용 가능한 도구·환경에서 수행하고 실제 결과를 확인한다. 외부 TTS 서비스 이용·업로드는 사용자의 권한 범위를 따른다. 새 운영 의존성 추가는 기존 승인 규칙을 따른다.

문법·Manim API·한국어 글꼴·레이아웃·장면별 수치·조건을 검사한다. 렌더링했다면 장면을 실제로 보고, 합성했다면 발화와 화면의 시작·끝 시점을 확인한다. 샘플의 `wait` 값만으로 음성과 동기화됐다고 쓰지 않는다. 실행할 수 없으면 코드 생성·정적 점검·미실행 항목을 구별해 전달한다.
